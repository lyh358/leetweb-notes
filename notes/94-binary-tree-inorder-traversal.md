# 二叉树遍历学习笔记

## 中序遍历核心逻辑

中序遍历遵循 **左子树 → 根节点 → 右子树** 的访问顺序。它是二叉树最基础的遍历方式之一，尤其在二叉搜索树（BST）中，中序遍历的结果天然有序。

### 递归实现要点

1. **终止条件**：当前节点为空时直接返回。
2. **递归左子树**：先深入左子树完成遍历。
3. **访问根节点**：将当前节点值加入结果集。
4. **递归右子树**：最后遍历右子树。

### 参考代码

```cpp
void inorder(TreeNode* node, vector<int>& res) {
    if (!node) return;
    inorder(node->left, res);   // 左
    res.push_back(node->val);   // 根
    inorder(node->right, res);  // 右
}
```

> **注意**：务必使用引用传递结果容器，避免递归过程中频繁拷贝 vector 导致性能下降。

## 前序遍历拓展

前序遍历遵循 **根节点 → 左子树 → 右子树** 的访问顺序，常用于复制树结构或序列化场景。

### 递归逻辑

1. **访问根节点**：首先处理当前节点。
2. **递归左子树**：深入左子树。
3. **递归右子树**：最后遍历右子树。

### 简单示例

对于如下二叉树：

```text
    1
   / \
  2   3
 / \
4   5
```

前序遍历结果为：`[1, 2, 4, 5, 3]`

### 参考代码

```cpp
void preorder(TreeNode* node, vector<int>& res) {
    if (!node) return;
    res.push_back(node->val);   // 根
    preorder(node->left, res);  // 左
    preorder(node->right, res); // 右
}
```

## 后序遍历拓展

后序遍历遵循 **左子树 → 右子树 → 根节点** 的访问顺序，适用于释放树内存、计算目录大小等自底向上的场景。

### 递归逻辑

1. **递归左子树**：先完成左子树遍历。
2. **递归右子树**：再完成右子树遍历。
3. **访问根节点**：最后处理当前节点。

### 简单示例

对于同一棵二叉树：

```text
    1
   / \
  2   3
 / \
4   5
```

后序遍历结果为：`[4, 5, 2, 3, 1]`

### 参考代码

```cpp
void postorder(TreeNode* node, vector<int>& res) {
    if (!node) return;
    postorder(node->left, res);   // 左
    postorder(node->right, res);  // 右
    res.push_back(node->val);     // 根
}
```

## 三种遍历对比

| 遍历方式 | 访问顺序 | 典型应用场景 |
| :--- | :--- | :--- |
| 前序遍历 | 根 → 左 → 右 | 树序列化、前缀表达式 |
| 中序遍历 | 左 → 根 → 右 | BST 有序输出、表达式求值 |
| 后序遍历 | 左 → 右 → 根 | 内存释放、后缀表达式、目录大小计算 |

> **记忆技巧**：前序、中序、后序中的“前/中/后”指的是 **根节点** 在遍历序列中的相对位置。
