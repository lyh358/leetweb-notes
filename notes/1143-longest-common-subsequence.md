# 力扣 1143. 最长公共子序列 — 学习笔记

> **题目**：给定两个字符串 `text1` 和 `text2`，返回这两个字符串的**最长公共子序列**的长度。如果不存在公共子序列，返回 `0`。  
> **难度**：中等  
> **标签**：字符串、动态规划

---

## 一、什么是"子序列"？

**子序列** = 从原字符串里**挑一些字符**（不改变它们的先后顺序），组成的新字符串。

不要求连续！中间可以跳过字符。

```
原串："abcde"
子序列："ace"    ✅（按顺序挑了 a、c、e，中间跳过了 b、d）
子序列："aec"    ❌（顺序乱了，e 在 c 前面了）
子序列："acd"    ✅（按顺序挑了 a、c、d）
```

**公共子序列** = 两个字符串都拥有的子序列。

```
text1 = "abcde"
text2 = "ace"

公共子序列："ace"    ← 最长的那个，长度是 3
```

---

## 二、核心思想：两个指针一步步比对

想象你有两只手，左手指着 `text1`，右手指着 `text2`，从左到右逐个字符比对：

```
text1:  a  b  c  d  e
         ↑
text2:  a  c  e
         ↑
```

**如果当前两个字符相同**（比如都是 `a`），恭喜你，找到了一个共同字符！那就在之前的最佳结果上 `+1`。

**如果不同**（比如 `text1` 是 `b`，`text2` 是 `c`），那就**二选一**：
- 要么 `text1` 往前缩一格（忽略 `b`）
- 要么 `text2` 往前缩一格（忽略 `c`）

选哪个能让结果更长，就选哪个。

---

## 三、状态定义（dp 数组的含义）

```cpp
// dp[i][j] = text1 的前 i 个字符 和 text2 的前 j 个字符
//            的最长公共子序列长度
```

**为什么数组开 `(m+1) × (n+1)`？**

```cpp
vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
```

多开一行一列（第 0 行和第 0 列），表示**空字符串**的情况：

| | `""` | `a` | `c` | `e` |
|---|---|---|---|---|
| `""` | 0 | 0 | 0 | 0 |
| `a` | 0 | ? | ? | ? |
| `b` | 0 | ? | ? | ? |
| `c` | 0 | ? | ? | ? |
| `d` | 0 | ? | ? | ? |
| `e` | 0 | ? | ? | ? |

- `dp[0][j] = 0`：text1 是空串，和任何字符串的公共子序列长度都是 0
- `dp[i][0] = 0`：text2 是空串，同理

这样初始化非常方便，不用额外处理边界。

## 四、状态转移方程

```cpp
if (text1[i-1] == text2[j-1]) {
    // 当前字符匹配！在之前的最佳结果上 +1
    dp[i][j] = dp[i-1][j-1] + 1;
} else {
    // 当前字符不匹配，二选一：text1 缩一格 或 text2 缩一格
    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
}
```

**为什么用 `text1[i-1]` 和 `text2[j-1]`？**

因为 `dp` 的下标从 **1** 开始，而字符串下标从 **0** 开始：
- `dp[1][1]` 对应 `text1[0]` 和 `text2[0]`
- `dp[3][2]` 对应 `text1[2]` 和 `text2[1]`

## 五、核心疑问：为什么不匹配要"缩一格二选一"？

### 5.1 直观理解

两个字符不一样，它们**不可能同时出现在同一个公共子序列里**。既然不能同时用，那就只能**放弃其中一个**，看看放弃谁能让结果更长。

### 5.2 生活化比喻

想象两支队伍（`text1` 和 `text2`）站成两排，你要找**最长的共同出场顺序**（不要求挨着站）。

```
text1:  a → b → c → d
text2:  a → c → b → d
```

现在 `text1` 看到 `b`，`text2` 看到 `c`，**这俩人不一样**。

你怎么办？
- **方案 A**：`text1` 的 `b` 先退下，让 `text1` 前面的人（`a`）来和 `text2` 的 `c` 比
- **方案 B**：`text2` 的 `c` 先退下，让 `text2` 前面的人（`a` 或 `b`）来和 `text1` 的 `b` 比

两个方案都试试，**哪个找到的更长，就选哪个**。这就是 `max(dp[i-1][j], dp[i][j-1])`。

### 5.3 关键反例：为什么不能同时缩两格？

你可能会想：既然都不匹配，那**两个一起跳过**行不行？也就是用 `dp[i-1][j-1]`？

**不行！** 因为同时跳过会漏掉"只跳过一个就能匹配上"的情况。

看一个经典反例：

```
text1 = "ab"
text2 = "ba"
```

求 `dp[2][2]`：即 `"ab"` 和 `"ba"` 的最长公共子序列。

```
i=2, j=2: text1[1]='b', text2[1]='a'
'b' != 'a'，不匹配！
```

**三种选择对比**：

| 选择 | 含义 | 结果 |
|------|------|------|
| 放弃 `text1` 的 `b`（`dp[1][2]`） | `"a"` vs `"ba"` | LCS = `"a"`，长度 **1** ✅ |
| 放弃 `text2` 的 `a`（`dp[2][1]`） | `"ab"` vs `"b"` | LCS = `"b"`，长度 **1** ✅ |
| **两个都放弃**（`dp[1][1]`） | `"a"` vs `"b"` | LCS = `""`，长度 **0** ❌ |

如果你选"两个都放弃"（`dp[1][1]=0`），就会得到错误答案 **0**。

但实际上，**只放弃一个**就能得到长度 **1**（`"a"` 或 `"b"`）。

```cpp
dp[2][2] = max(dp[1][2], dp[2][1]) = max(1, 1) = 1  ✅
// 如果写成 dp[2][2] = dp[1][1] = 0  ❌ 就错了！
```

> 💡 **核心原因**：`dp[i-1][j-1]` 是"两个都放弃"，但可能 `text1` 前面某个字符刚好能和 `text2` 当前字符配上，或者反过来。只放弃一个，保留另一个，才有机会"接上"。

### 5.4 为什么不用比较 `dp[i-1][j-1]`？

其实 `dp[i-1][j-1]` 一定**不会大于**另外两个：

```
dp[i-1][j-1] <= dp[i-1][j]     // 因为 text2 少了一个字符，选择空间变小了
dp[i-1][j-1] <= dp[i][j-1]     // 同理，text1 少了一个字符
```

所以 `max(dp[i-1][j], dp[i][j-1])` 已经包含了最优解，`dp[i-1][j-1]` 不可能逆袭。

## 七、C++ 代码

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size();
        int n = text2.size();

        // dp[i][j] = text1前i个 和 text2前j个 的LCS长度
        // 多开一行一列，第0行和第0列表示空字符串，初始化为0
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1[i - 1] == text2[j - 1]) {
                    // 当前字符匹配，在之前的最佳结果上 +1
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 不匹配，二选一：text1缩一格 或 text2缩一格
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[m][n];
    }
};
```

## 九、常见错误

### ❌ 错误 1：字符串下标和 dp 下标搞混

```cpp
// ❌ 错误：dp 和字符串下标都从 0 开始
if (text1[i] == text2[j]) {
    dp[i][j] = dp[i-1][j-1] + 1;  // i=0 时越界！
}

// ✅ 正确：dp 从 1 开始，字符串从 0 开始
if (text1[i - 1] == text2[j - 1]) {
    dp[i][j] = dp[i - 1][j - 1] + 1;
}
```

### ❌ 错误 2：不匹配时写成 `dp[i-1][j-1]`

```cpp
// ❌ 错误：两个都放弃
else {
    dp[i][j] = dp[i - 1][j - 1];  // 会漏掉只放弃一个就能匹配的情况！
}

// ✅ 正确：二选一
dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
```

### ❌ 错误 3：忘记初始化 dp 数组

```cpp
// ❌ 错误：没有初始化第 0 行和第 0 列
vector<vector<int>> dp(m + 1, vector<int>(n + 1));
// 默认是随机值或 0（取决于编译器），不安全

// ✅ 正确：显式初始化为 0
vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
```

## 十、思路总结

```
┌─────────────────────────────────────────────────────────────┐
│                     动态规划四步法                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 定义状态                                                │
│     dp[i][j] = text1前i个 和 text2前j个 的最长公共子序列长度│
│                                                             │
│  2. 找状态转移                                              │
│     匹配：dp[i][j] = dp[i-1][j-1] + 1                     │
│     不匹配：dp[i][j] = max(dp[i-1][j], dp[i][j-1])        │
│                                                             │
│  3. 确定边界                                                │
│     dp[0][j] = 0, dp[i][0] = 0（空串的LCS为0）            │
│                                                             │
│  4. 遍历顺序                                                │
│     从上到下，从左到右（每个状态依赖左上、上方、左方）    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 十一、一句话总结

> **两个字符相同 → 一起往前推一格，结果 +1。两个字符不同 → 分别往前推一格，取较大的那个。**

```cpp
// 核心代码就这几行
if (text1[i-1] == text2[j-1]) {
    dp[i][j] = dp[i-1][j-1] + 1;
} else {
    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
}
```

这就是**二维 DP 最经典的模板**之一，掌握它后，很多字符串类的 DP（如编辑距离、最长重复子数组）都能举一反三。
