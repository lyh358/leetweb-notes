# 739.每日温度

# 题目描述

给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

**示例 1:**

```
输入: temperatures = [73,74,75,71,69,72,76,73]
输出: [1,1,4,2,1,1,0,0]
```

**示例 2:**

```
输入: temperatures = [30,40,50,60]
输出: [1,1,1,0]
```

**示例 3:**

```
输入: temperatures = [30,60,90]
输出: [1,1,0]
```

**提示：**

- `1 <= temperatures.length <= 105`
- `30 <= temperatures[i] <= 100`

---

# 思路：单调递减栈

- ### 预定义的变量和数据结构

  - #### 天数n

  - #### 一维动态数组res：初始化为n个0，默认找不到后面更热的日子，找到了才更新

  - #### 栈st：每天的温度先判断后==下标入栈==（防止自己跟自己配对）

- ### 每天的温度：先判断后入栈

  - #### while循环

    - ==每次弹出一个日期就说明过去的这个日期的下一次升温日期是今天==

      - ==今天–过去那天==天数差，存入ans【过去那天】==

    - ##### 因为是单调递减栈，必须保证新日期的温度入栈时底下没有更小的温度了，所以必须用while清空

  - #### 判断条件：栈内有元素，且当前的新温度大于栈顶温度

  - #### 栈顶温度下标弹出并计算与当前的下标差

- ### 单调递减栈

  - #### 由于栈顶元素遇到更大的就会弹出，所以栈内留下的元素从底到顶是单调递减的

---

#### 复杂度分析

###### 该方法只需要对数组进行一次遍历，每个元素最多被压入和弹出堆栈一次，算法复杂度是 *O*(*n*)。

---

# 完整代码

```c++
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures)
    {
        //最大天数
        int n = temperatures.size();
        //结果数组，下标是日期，值是下一个高温出现在几天后
        vector<int> res(n,0);
        
		//单调递减栈：存日期（即下标）
        stack<int> st;
		
        //for循环遍历每一天
        for(int i=0;i<n;i++)
        {
            //先判断
            //while循环保证堆里面有多个小于当前温度的日子，并对他们都作差
            while(!st.empty() && temperatures[i]>temperatures[st.top()])
            {
                int prev = st.top();//得到堆顶的日期
                st.pop();//弹出堆顶
                res[prev] = i - prev;//计算今天和当时那天的时间差
            }
            
            //天数后入栈
            st.push(i);
        }
        //返回结果
        return res;
    }
};
```
