# 最长连续序列 (Longest Consecutive Sequence)

## 题目信息

- **来源**: LeetCode 128
- **难度**: 中等
- **核心考点**: 哈希表、时间复杂度优化

## 题目大意

给定一个未排序的整数数组 `nums`，找出**数字连续的最长序列**的长度。

要求算法的时间复杂度为 **O(n)**。

---

## 核心思路

> **只从每个连续序列的"开头"开始计数，跳过中间元素。**

### 如何判断一个数是不是序列的开头？

利用**哈希表**查找 `num - 1` 是否存在：
- 如果 `num - 1` **存在** → `num` 不是开头，它是某个序列的中间元素，**直接跳过**
- 如果 `num - 1` **不存在** → `num` 是某个连续序列的**第一个元素**，从这里开始向后遍历

### 为什么复杂度是 O(n)？

表面上有两重循环（外层遍历每个元素，内层 while 向后扩展），但关键在于：

- 只有**序列开头的数**才会进入内层 while 循环
- 每个数最多被内层循环访问 **1 次**（当它是某个序列的一部分时）
- 因此总的时间复杂度是 **O(n)**，不是 O(n²)

---

## 算法步骤详解

以序列 `[100, 4, 200, 1, 3, 4, 2]` 为例：

### 第一步：去重并构建哈希集合

```
去重后的哈希集合: {100, 4, 200, 1, 3, 2}
```

### 第二步：遍历集合，判断是否为序列开头

| 当前元素 | num-1 是否存在 | 是否为开头 | 操作 |
|---------|--------------|-----------|------|
| 100 | 99 ❌ | ✅ 是 | 从 100 开始向后找，序列长度 = 1 |
| 4 | 3 ✅ | ❌ 否 | 跳过（3 存在，说明 4 不是开头） |
| 200 | 199 ❌ | ✅ 是 | 从 200 开始向后找，序列长度 = 1 |
| 1 | 0 ❌ | ✅ 是 | 从 1 开始向后找：1→2→3→4，序列长度 = 4 |
| 3 | 2 ✅ | ❌ 否 | 跳过 |
| 2 | 1 ✅ | ❌ 否 | 跳过 |

### 第三步：返回最大长度

最长连续序列是 `[1, 2, 3, 4]`，长度为 **4**。

---

## 代码实现

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        // 1. 将所有元素放入哈希集合，实现 O(1) 查找
        unordered_set<int> uset;
        for (int num : nums) {
            uset.insert(num);
        }

        int longest = 0;

        // 2. 遍历集合中的每个元素
        for (int num : uset) {          //
            // 3. 判断 num 是否是连续序列的开头
            // 只有当 num-1 不存在时，num 才是某个序列的起点
            if (!uset.count(num - 1)) {
                int cur_num = num;      // 当前遍历到的数
                int cur_long = 1;       // 当前序列长度（至少包含自己）

                // 4. 向后扩展，检查 cur_num+1, cur_num+2... 是否存在
                while (uset.count(cur_num + 1)) {
                    cur_num++;          // 移动到下一个数
                    cur_long++;         // 序列长度+1
                }

                // 5. 更新最大长度
                longest = max(longest, cur_long);
            }
        }
        return longest;
    }
};
```

## 复杂度分析

| 项目 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **O(n)** | 每个元素最多被访问 2 次（外层 1 次 + 内层作为序列成员 1 次） |
| 空间复杂度 | **O(n)** | 哈希集合存储所有元素 |

### 时间复杂度为什么是 O(n) 的详细证明

假设数组中有 `n` 个不同的数。

- **外层循环**：遍历哈希集合，共 `n` 次迭代 → O(n)
- **内层 while**：只有当一个数是**序列开头**时才会执行
  - 每个数最多属于一个连续序列
  - 每个数在内层循环中最多被访问 **1 次**
  - 所有内层 while 的总迭代次数 ≤ `n`

因此总时间复杂度 = O(n) + O(n) = **O(n)**

> ⚠️ 如果去掉 `if (!uset.count(num - 1))` 这个判断，每个数都会进入内层循环，时间复杂度会退化为 **O(n²)**，导致超时。

---

## 常见易错点

### ❌ 错误写法（死循环/超时）

```cpp
while (uset.count(num + 1)) {   // ❌ 用了外层循环变量 num
    cur_num++;                   //    num 始终不变，如果 num+1 存在就死循环
    cur_long++;
}
```

**问题**：`num` 是外层 `for` 循环的迭代变量，在每次外层循环中是**固定不变的**。如果 `num + 1` 存在于集合中，条件永远为 `true`，陷入**死循环**，最终 TLE（超时）。

### ✅ 正确写法

```cpp
while (uset.count(cur_num + 1)) {  // ✅ 用 cur_num，它在循环中会递增
    cur_num++;
    cur_long++;
}
```

`cur_num` 初始化为 `num`，然后在循环中逐步递增，每次都检查**下一个**数是否在集合中，直到序列断裂，循环正常退出。

---

## 核心要点总结

1. **哈希集合**是实现 O(1) 查找的关键，用空间换时间
2. **只从序列开头计数**是控制复杂度的核心技巧，避免重复计算
3. **判断开头的方式**：`num - 1` 不在集合中
4. **变量名要小心**：`num`（外层固定） vs `cur_num`（内层递增），写错会导致死循环
5. **去重很重要**：原数组可能有重复元素，用 `unordered_set` 自动去重
