# 456.132模式

给你一个整数数组 `nums` ，数组中共有 `n` 个整数。**132 模式的子序列** 由三个整数 `nums[i]`、`nums[j]` 和 `nums[k]` 组成，并同时满足：`i < j < k` 和 `nums[i] < nums[k] < nums[j]` 。

如果 `nums` 中存在 **132 模式的子序列** ，返回 `true` ；否则，返回 `false` 。

**示例 1：**

```
输入：nums = [1,2,3,4]
输出：false
解释：序列中不存在 132 模式的子序列。
```

**示例 2：**

```
输入：nums = [3,1,4,2]
输出：true
解释：序列中有 1 个 132 模式的子序列： [1, 4, 2] 。
```

**示例 3：**

```
输入：nums = [-1,3,2,0]
输出：true
解释：序列中有 3 个 132 模式的的子序列：[-1, 3, 2]、[-1, 3, 0] 和 [-1, 2, 0] 。
```

**提示**

- `n == nums.length`
- `1 <= n <= 2 * 105`
- `-109 <= nums[i] <= 109`

---

# 核心思路

- ## 倒序遍历

- ## 使用单调递减栈储存“3”的可能值

  - ### ‘3’没遇到更大的就往小压，遇到更大的（说明旧的当不了了）就弹出直到现在的成为最小的

  - ### “2”往大了留

# 实现流程

## （1）初始化数据结构

- ### 创建单调递减栈

- ### 获得数组长度，便于倒叙遍历

- ### 初始化“2”为最小整型

```c++
stack<int> st;    // 单调递减栈，存"3"的候选（大数）
int n = nums.size();
int k = INT_MIN;  // k 就是"2"，初始化为极小值
```

## （2）for倒叙循环，查找每一个数组元素

- ### 在循环中查找使132结构成立的“1”

```c++
 for(int i = n - 1; i >= 0; i--)// 从右往左遍历，找"1"
 {   
 
 }
```

- ### 判断成立条件：当前值可以作为1（即小于我们维护的“2”）

  - #### 返回true

```c++
 if(nums[i] < k) return true;   // 找到 1 < 2，132模式成立！ 
```

- ### 将当前元素压入栈

  - #### 在下一轮的内层while中对它进行维护

```c++
 st.push(nums[i]);              // 当前入栈，作为后面元素的"3"候选
```



## （3）在for循环内部进行while循环

- ### while的执行条件

  - #### “3”栈不为空

  - #### 当前的元素比上一个入栈的元素更适合当‘3’

- ### 在while循环中维护"2"

  - #### 把刚刚被淘汰掉的‘3’和之前的旧“2”进行对比，留下大的继续当“2”

- ### 在while循环中维护"3"

  - #### 弹出被淘汰的“3”

```c++
while(!st.empty() and st.top() < nums[i]) // 当前比栈顶大，形成"峰"
{  
	k = max(k, st.top());      // 更新"2"为更大的被弹出值
	st.pop();                  // 弹出较小的栈顶
}
```

## （4）如果一轮for循环还没找到

- ### return false

# 完整代码

```c++
class Solution {
public:
    bool find132pattern(vector<int>& nums) {
        stack<int> st;                    // 单调递减栈，存"3"的候选（大数）
        int n = nums.size(), k = INT_MIN;  // k 就是"2"，初始化为极小值
        for(int i = n - 1; i >= 0; i--){   // 从右往左遍历，找"1"
            if(nums[i] < k) return true;   // 找到 1 < 2，132模式成立！
            while(!st.empty() and st.top() < nums[i]) {  // 当前比栈顶大，形成"峰"
                k = max(k, st.top());      // 更新"2"为更大的被弹出值
                st.pop();                  // 弹出较小的栈顶
            }
            st.push(nums[i]);              // 当前入栈，作为后面元素的"3"候选
        }
        return false;                      // 遍历完没找到
    }
};
```
