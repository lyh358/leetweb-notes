# 力扣 118. 杨辉三角 — 学习笔记

> **题目**：给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。  
> **难度**：简单  
> **标签**：数组、动态规划

---

## 一、题目理解

杨辉三角（Pascal's Triangle）的规律：

```
        1           ← 第 0 行
       1 1          ← 第 1 行
      1 2 1         ← 第 2 行
     1 3 3 1        ← 第 3 行
    1 4 6 4 1       ← 第 4 行
```

**核心性质**：
- 每行的首尾元素都是 `1`
- 中间元素 = 上一行左上方元素 + 上一行正上方元素
