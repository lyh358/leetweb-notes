# 力扣 62. 不同路径 — 学习笔记

> **题目**：一个机器人位于一个 `m x n` 网格的左上角（起始点在下图中标记为 "Start"）。机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 "Finish"）。问总共有多少条不同的路径？  
> **难度**：中等  
> **标签**：数学、动态规划、组合数学

---

## 一、题目理解

```
Start
  ↓
┌───┬───┬───┐
│   │   │   │
├───┼───┼───┤
│   │   │   │
├───┼───┼───┤
│   │   │Finish│
└───┴───┴───┘
```

**规则**：
- 从左上角 `(0, 0)` 出发
- 每次只能**向下**或**向右**移动一步
- 到达右下角 `(m-1, n-1)`
- 求总共有多少条不同的路径

**示例**：`m = 3, n = 7`
```
输出: 28
```
