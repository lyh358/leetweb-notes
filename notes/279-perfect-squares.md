## 二、核心思路推导（从最小子问题出发）

### 2.1 什么是最小子问题？

假设我们要求 `f(12)` = 和为 12 的最少完全平方数个数。

**思考**：12 可以由哪些"上一个数"推导而来？

因为最终要加的是**完全平方数**，所以：
- 如果最后一个加的完全平方数是 `1² = 1`，那么上一个数是 `12 - 1 = 11`
- 如果最后一个加的完全平方数是 `2² = 4`，那么上一个数是 `12 - 4 = 8`
- 如果最后一个加的完全平方数是 `3² = 9`，那么上一个数是 `12 - 9 = 3`

```
12 = 11 + 1*1    ← 上一个数是 11，跨度是 1²
12 = 8  + 2*2    ← 上一个数是 8，  跨度是 2²
12 = 3  + 3*3    ← 上一个数是 3，  跨度是 3²
```

> **关键洞察**：当前数 `n` 的"上一个数" = `n - j*j`，其中 `j*j` 是不超过 `n` 的某个完全平方数。

### 2.2 状态转移关系

如果已知 `f(11)`、 `f(8)`、 `f(3)` 分别是多少，那么：

```
f(12) 通过 11 来：f(11) + 1（再加一个 1²）
f(12) 通过 8  来：f(8)  + 1（再加一个 2²）
f(12) 通过 3  来：f(3)  + 1（再加一个 3²）
```

三种方式都能凑出 12，选**个数最少**的那个：

```
f(12) = min( f(11)+1, f(8)+1, f(3)+1 )
```

### 2.3 抽象出状态转移方程

设 `f[i]` = 和为 `i` 的完全平方数的最少数量。

对于每个 `i`，枚举所有可能的完全平方数 `j*j`（其中 `j*j ≤ i`）：

```
f[i] = min( f[i - j*j] + 1 )    对所有满足 j*j ≤ i 的 j
```

**解释**：
- `f[i - j*j]`：凑出"上一个数" `i-j*j` 所需的最少个数
- `+ 1`：再加上当前的完全平方数 `j*j` 这一个
- `min(...)`：在所有可能的 `j` 中取最小值

---

## 三、边界条件

```cpp
f[0] = 0;
```

**解释**：和为 0 时，不需要任何完全平方数，个数为 0。

这是整个递推的起点，所有其他 `f[i]` 都从这个边界推导而来。

---

## 四、代码实现（C++）

```cpp
#include <vector>
#include <algorithm>
#include <climits>

class Solution {
public:
    int numSquares(int n) {
        // f[i] = 和为 i 的完全平方数的最少数量
        std::vector<int> f(n + 1);

        // 边界条件：f[0] = 0
        f[0] = 0;

        // 从小到大计算每个 f[i]
        for (int i = 1; i <= n; i++) {
            // 先假设一个极大值，后续用 min 更新
            f[i] = INT_MAX;

            // 枚举所有可能的完全平方数 j*j（j*j 不能超过 i）
            for (int j = 1; j * j <= i; j++) {
                // 状态转移：用 i - j*j 的最优解 + 1，更新当前最优解
                f[i] = std::min(f[i - j * j] + 1, f[i]);
            }
        }

        return f[n];
    }
};
```

## 五、代码逐行解析

| 代码 | 含义 |
|------|------|
| `std::vector<int> f(n + 1)` | 创建 dp 数组，`f[i]` 表示和为 `i` 的最少个数 |
| `f[0] = 0` | **边界条件**：和为 0 需要 0 个完全平方数 |
| `f[i] = INT_MAX` | 先设为极大值，确保第一次 `min` 能正确更新 |
| `j = 1; j * j <= i; j++` | 枚举所有不超过 `i` 的完全平方数：`1, 4, 9, 16...` |
| `f[i - j * j] + 1` | 上一个数 `i-j*j` 的最优解 + 当前这个完全平方数 |
| `std::min(..., f[i])` | 在所有可能的 `j` 中取最小值 |

| 2 | 1 | 1 | 1 | 1 | 2 | **2** |

| 4 | 2 | 4 | 0 | 0 | 1 | 同上 |
| 5 | 1 | 1 | 4 | 1 | 2 | **2** |
| 5 | 2 | 4 | 1 | 1 | 2 | 同上 |
| ... | ... | ... | ... | ... | ... | ... |
| 8 | 1 | 1 | 7 | 4 | 5 | **2**（j=2时：f[4]+1=2） |
| 8 | 2 | 4 | 4 | 1 | 2 | 同上 |

### 6.2 结果验证

```
f(12) = 3
解释：12 = 4 + 4 + 4（三个 2²）
      或 12 = 4 + 4 + 4，最少需要 3 个完全平方数
```

> 注意：虽然 `12 = 9 + 1 + 1 + 1` 也是 4 个数，但 `4 + 4 + 4` 只需要 3 个，所以答案是 3。

## 九、与经典 DP 的对比

| 题目 | 状态定义 | 状态转移 | "跨度" |
|------|---------|---------|--------|
| **198. 打家劫舍** | `dp[i]` = 前 i 间房最大金额 | `max(dp[i-1], dp[i-2]+nums[i])` | 固定为 1 或 2（相邻不能偷） |
| **279. 完全平方数** | `f[i]` = 和为 i 的最少个数 | `min(f[i-j*j] + 1)` | 变量 `j*j`（所有完全平方数） |
| **322. 零钱兑换** | `dp[i]` = 凑成金额 i 的最少硬币 | `min(dp[i-coin] + 1)` | 变量 `coin`（所有硬币面值） |

> 💡 **发现规律**：279 和 322 是同一类问题——**完全背包问题的最少数量版本**。"跨度"不是一个固定值，而是需要枚举所有可能的"步长"。

## 十、常见错误

### ❌ 错误 1：忘记初始化 f[i] 为极大值
```cpp
// ❌ 错误：f[i] 默认为 0，min 永远取 0
f[i] = std::min(f[i - j*j] + 1, f[i]);  // 如果 f[i] 初始是 0，结果永远是 0

// ✅ 正确：先设为极大值
f[i] = INT_MAX;
f[i] = std::min(f[i - j*j] + 1, f[i]);
```

### ❌ 错误 2：内层循环条件写错
```cpp
// ❌ 错误：j <= i 会导致 j*j 远大于 i
for (int j = 1; j <= i; j++)  // j=5 时，j*j=25，可能远大于 i

// ✅ 正确：j*j <= i 确保完全平方数不超过当前目标值
for (int j = 1; j * j <= i; j++)
```

### ❌ 错误 3：遍历顺序错误
```cpp
// ❌ 错误：从大到小遍历
for (int i = n; i >= 1; i--)  // f[i] 依赖更小的值，但小值还没算

// ✅ 正确：从小到大遍历
for (int i = 1; i <= n; i++)  // 确保 f[i-j*j] 已经计算完毕
```

## 十一、一句话总结

> **把 `n` 看成由某个完全平方数 `j*j` 加上"剩余部分" `n-j*j` 组成。枚举所有可能的 `j*j`，取"剩余部分的最优解 + 1"的最小值。**

```
f[n] = min( f[n - 1*1] + 1,
            f[n - 2*2] + 1,
            f[n - 3*3] + 1,
            ... )
```

这就是**完全背包**思想在动态规划中的经典应用。
