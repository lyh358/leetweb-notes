# LeetCode 416. 分割等和子集

## 题目一句话

给一个正整数数组 `nums`，问能不能把它分成两个子集，使两个子集的和相等。

例子：

```cpp
nums = [1, 5, 11, 5]
```

可以分成：

```cpp
[1, 5, 5] 和 [11]
```

两边都是 `11`，所以返回 `true`。

---

## 第一步：先看总和

如果数组能被分成两个和相等的子集，那么数组总和必须是偶数。

比如：

```cpp
nums = [1, 2, 3, 5]
sum = 11
```

`11` 是奇数，不可能平均分成两份，所以直接返回：

```cpp
false
```

代码：

```cpp
int sum = 0;
for (int x : nums) {
    sum += x;
}

if (sum % 2 == 1) {
    return false;
}
```

---

## 第二步：把题目转化一下

如果总和是偶数，假设：

```cpp
sum = 22
```

那么两个子集的目标和都应该是：

```cpp
target = sum / 2 = 11
```

所以原题就变成：

```md
能不能从 nums 里挑一些数，让它们加起来正好等于 target？
```

也就是：

```md
能不能凑出 sum / 2？
```

---

## 什么是 01 背包？

不用先记名字，先理解意思。

这题里，每个数字都有两种选择：

```md
选它
不选它
```

并且每个数字最多只能用一次。

这种“每个东西只能选一次，要凑出某个目标”的问题，就叫 **01 背包**。

`0` 表示不选，`1` 表示选。

在本题中：

```cpp
nums = [1, 5, 11, 5]
target = 11
```

可以理解成：

```md
数字 1：选或不选
数字 5：选或不选
数字 11：选或不选
数字 5：选或不选
```

注意：两个 `5` 是数组中两个不同位置的数字，可以各自用一次。

---

## dp[j] 是什么意思？

定义：

```cpp
dp[j]
```

表示：

```md
用已经看过的数字，能不能凑出和 j。
```

如果：

```cpp
dp[6] = true;
```

意思是：

```md
目前已经处理过的数字里，可以选出一些数，凑出 6。
```

如果：

```cpp
dp[6] = false;
```

意思是：

```md
目前还凑不出 6。
```

---

## “已经看过的数字”是什么意思？

代码会一个数字一个数字地处理：

```cpp
for (int num : nums) {
    ...
}
```

比如：

```cpp
nums = [1, 5, 11, 5]
```

一开始，一个数字都没看。

处理完 `1` 后：

```md
已经看过的数字是 [1]
```

这时 `dp[j]` 的意思是：

```md
只用 [1]，能不能凑出 j。
```

处理完 `1, 5` 后：

```md
已经看过的数字是 [1, 5]
```

这时 `dp[j]` 的意思是：

```md
只用 [1, 5]，能不能凑出 j。
```

处理完整个数组后：

```md
dp[j] 表示用整个 nums，能不能凑出 j。
```

最后只需要看：

```cpp
dp[target]
```

---

## 初始化

一开始还没选任何数字。

但是“不选任何数字”可以凑出 `0`。

所以：

```cpp
dp[0] = true;
```

其他位置一开始都是 `false`。

```cpp
vector<bool> dp(target + 1, false);
dp[0] = true;
```

---

## 状态转移怎么理解？

核心代码：

```cpp
dp[j] = dp[j] || dp[j - num];
```

假设当前数字是：

```cpp
num = 5
```

现在想知道能不能凑出：

```cpp
j = 8
```

有两种情况：

```md
1. 之前本来就能凑出 8
2. 之前能凑出 3，现在加上当前这个 5，就能凑出 8
```

因为：

```cpp
8 - 5 = 3
```

所以：

```cpp
dp[8] = dp[8] || dp[3];
```

翻译成人话：

```md
如果以前能凑出 8，当然还是能凑出 8。
如果以前能凑出 3，现在加上当前数字 5，也能凑出 8。
```

---

## 为什么必须倒序遍历？

代码是：

```cpp
for (int j = target; j >= num; j--) {
    dp[j] = dp[j] || dp[j - num];
}
```

关键点：

```md
更新 dp[j] 时，dp[j - num] 必须是“还没使用当前 num 之前”的状态。
```

这样当前数字 `num` 才只会被用一次。

---

## 正序遍历为什么会错？

假设：

```cpp
nums = [5]
target = 10
```

只有一个 `5`，显然不能凑出 `10`。

如果正序遍历：

```cpp
for (int j = num; j <= target; j++)
```

也就是：

```cpp
for (int j = 5; j <= 10; j++)
```

一开始：

```cpp
dp[0] = true;
dp[5] = false;
dp[10] = false;
```

当 `j = 5` 时：

```cpp
dp[5] = dp[5] || dp[0];
```

因为 `dp[0] = true`，所以：

```cpp
dp[5] = true;
```

这表示用当前这个 `5`，可以凑出 `5`。

接着当 `j = 10` 时：

```cpp
dp[10] = dp[10] || dp[5];
```

问题来了：此时 `dp[5]` 已经在本轮被当前这个 `5` 更新成了 `true`。

于是：

```cpp
dp[10] = true;
```

这相当于把同一个 `5` 用了两次：

```cpp
5 + 5 = 10
```

但数组里只有一个 `5`，所以这是错的。

---

## 倒序遍历为什么就不会错？

还是：

```cpp
nums = [5]
target = 10
```

倒序遍历：

```cpp
for (int j = 10; j >= 5; j--)
```

一开始：

```cpp
dp[0] = true;
dp[5] = false;
dp[10] = false;
```

先看 `j = 10`：

```cpp
dp[10] = dp[10] || dp[5];
```

此时 `dp[5]` 还是旧状态 `false`，因为这一轮还没有更新到 `dp[5]`。

所以：

```cpp
dp[10] = false;
```

然后看 `j = 5`：

```cpp
dp[5] = dp[5] || dp[0];
```

因为 `dp[0] = true`，所以：

```cpp
dp[5] = true;
```

这一轮结束后，只说明：

```md
用当前这个 5，可以凑出 5。
```

不会错误地凑出 `10`。

---

## 倒序遍历的本质

一句话：

```md
倒序遍历可以保证 dp[j - num] 还是上一轮的结果，没有用过当前 num。
```

所以当前数字只会被用一次。

正序遍历会让 `dp[j - num]` 可能已经在本轮用过当前数字，于是当前数字可能被重复使用。

---

## 为什么遍历范围是 j = target; j >= num？

代码：

```cpp
for (int j = target; j >= num; j--)
```

原因有两个。

### 1. 最大只需要到 target

我们的目标只是凑出：

```cpp
target = sum / 2
```

比 `target` 更大的和没有意义，不需要记录。

所以最大从：

```cpp
target
```

开始。

### 2. 最小只需要到 num

转移公式是：

```cpp
dp[j] = dp[j] || dp[j - num];
```

如果：

```cpp
j < num
```

比如：

```cpp
num = 5
j = 3
```

就会出现：

```cpp
dp[j - num] = dp[-2]
```

数组下标不能是负数。

从意义上说也很好理解：

```md
当前数字是 5，不可能用它去凑出 3。
```

所以 `j < num` 的部分不用更新。

---

## 完整 C++ 代码

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int sum = 0;

        for (int x : nums) {
            sum += x;
        }

        if (sum % 2 == 1) {
            return false;
        }

        int target = sum / 2;

        vector<bool> dp(target + 1, false);
        dp[0] = true;

        for (int num : nums) {
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num];
            }
        }

        return dp[target];
    }
};
```

---

## 复杂度

设数组长度为 `n`，目标和为 `target = sum / 2`。

```md
时间复杂度：O(n * target)
空间复杂度：O(target)
```

416 分割等和子集：
