# 📘 LeetCode 114 — 二叉树展开为链表（双解法详解）

---

## 一、题目信息

| 项目 | 内容 |
|------|------|
| 题号 | 114 |
| 难度 | 中等 |
| 标签 | 栈、树、深度优先搜索、链表、二叉树 |
| 核心思路 | 后序遍历递归 / 寻找前驱节点迭代 |

**题目要求**：给定一棵二叉树，将其**原地**展开为一个"链表"：
- 展开后的顺序是二叉树的**前序遍历**顺序
- 所有节点的 `left` 指针都置为 `nullptr`
- 所有节点的 `right` 指针指向下一个节点
- 不能创建新节点，只能调整指针

```
输入：
    1
   / \
  2   5
 / \   \
3   4   6

前序遍历：1 → 2 → 3 → 4 → 5 → 6

输出（链表形式）：
1
   2
       3
           4
               5
                   6

即：1->right=2, 2->right=3, 3->right=4, 4->right=5, 5->right=6
    所有 left = nullptr
```

## 二、解法一：递归法（后序遍历 + 前驱指针）

### 2.1 核心思想

> **从后往前搭积木。**
>
> 前序遍历顺序是：`根 → 左 → 右`，也就是 `1 → 2 → 3 → 4 → 5 → 6`。
>
> 如果我们**从后往前**处理（`6 → 5 → 4 → 3 → 2 → 1`），每次把当前节点接到"已经搭好的链表"前面，就能拼出正确的顺序。

### 2.2 完整代码（含详细注释）

```cpp
class Solution {
public:
    // preNode：指向"已经处理好的链表"的头节点
    // 初始为 nullptr，表示链表末尾的空
    TreeNode* preNode = nullptr;

    void flatten(TreeNode* root) {
        // 递归出口：空节点不需要处理
        if (root == nullptr) return;

        // ===== 后序遍历：右 → 左 → 根 =====
        // 注意！这里先处理右子树，再处理左子树！
        // 因为我们要"从后往前"搭建链表

        flatten(root->right);  // ① 先把右子树展开成链表
        flatten(root->left);   // ② 再把左子树展开成链表

        // ===== 处理当前节点 =====
        // 此时：
        // - 右子树已经展开成链表，头节点是 preNode
        // - 左子树已经展开成链表，头节点也是 preNode（因为左子树处理完后更新了 preNode）

        root->left = nullptr;       // ③ 左指针置空（题目要求）
        root->right = preNode;      // ④ 右指针指向"已经搭好的链表"的头
        preNode = root;             // ⑤ 更新 preNode，当前节点成为新链表的头
    }
};
```

### 2.3 为什么遍历顺序是"右 → 左 → 根"？

前序遍历顺序：`1 → 2 → 3 → 4 → 5 → 6`

我们要搭建的链表也是这个顺序：`1 → 2 → 3 → 4 → 5 → 6`

如果从**后往前**处理，就是：`6 → 5 → 4 → 3 → 2 → 1`

而"右 → 左 → 根"的后序遍历，恰好访问顺序是：
```
        1
       / \
      2   5
     / \   \
    3   4   6

右-左-根遍历顺序：6 → 5 → 4 → 3 → 2 → 1
```

**完美匹配！** 这就是为什么要先递归右子树，再递归左子树。

### 2.5 核心逻辑一句话总结

> **`preNode` 是"已经处理好的链表的头节点"。从最后一个节点开始，每个节点都把 `right` 指向 `preNode`，然后自己成为新的 `preNode`。就像从后往前穿珠子，一颗一颗串起来。**

## 三、解法二：迭代法（寻找前驱节点 / Morris 思想）

### 3.1 核心思想

> **把左子树"塞"到右子树前面。**
>
> 前序遍历顺序：`根 → 左 → 右`
>
> 对于每个节点，如果它有左子树：
> 1. 找到左子树的"最右下角"节点（这个节点是左子树前序遍历的最后一个）
> 2. 把这个最右下角节点的右指针，指向当前节点的右子树
> 3. 把当前节点的左子树整体搬到右边
> 4. 当前节点的左指针置空
> 5. 当前节点向右移动，继续处理下一个

### 3.2 为什么找"左子树的最右下角"？

```
    1
   / \
  2   5
 / \   \
3   4   6
```

节点 1 的左子树是：
```
  2
 / \
3   4
```

这个左子树的前序遍历是：`2 → 3 → 4`

**最后一个节点是 4**，也就是左子树的**最右下角**节点。

前序遍历中，1 的左子树遍历完后，下一个该访问的是 1 的右子树（即 5）。

所以：**4 的右边应该接上 5**，这样顺序就连起来了！

### 3.3 完整代码（含详细注释）

```cpp
class Solution {
public:
    void flatten(TreeNode* root) {
        TreeNode *curr = root;  // curr：当前正在处理的节点

        while (curr != nullptr) {
            // 如果当前节点有左子树，需要处理
            if (curr->left != nullptr) {

                // ===== 步骤 1：找到左子树的最右下角节点 =====
                // 这个节点是左子树前序遍历的最后一个节点
                auto next = curr->left;           // next：左子树的根，即将成为新的右子树
                auto predecessor = next;          // predecessor：用于寻找最右下角

                // 一路向右下走，找到左子树的最右节点
                while (predecessor->right != nullptr) {
                    predecessor = predecessor->right;
                }

                // ===== 步骤 2：把当前右子树接到最右下角 =====
                // 这样左子树遍历完后，就能顺藤摸瓜走到原来的右子树
                predecessor->right = curr->right;

                // ===== 步骤 3：把左子树搬到右边 =====
                curr->left = nullptr;     // 左指针置空
                curr->right = next;       // 右指针指向原来的左子树
            }

            // ===== 步骤 4：curr 向右移动，处理下一个节点 =====
            // 此时 curr->right 已经是"左子树 + 原右子树"的拼接结果
            curr = curr->right;
        }
    }
};
```

### 3.5 核心逻辑一句话总结

> **把左子树整体"搬到"右边，然后把原来右子树接到左子树的"尾巴"上。就像把一根绳子（左子树）插到另一根绳子（右子树）前面，接头处绑紧（最右下角节点指向原右子树）。**

## 四、两种方法对比

| 对比项 | 解法一：递归后序 | 解法二：迭代前驱 |
|--------|---------------|---------------|
| **核心思想** | 从后往前串链表 | 从左往右"搬家" |
| **遍历方向** | 右 → 左 → 根（后序） | 根 → 左 → 右（前序） |
| **数据结构** | 递归栈 | 无额外空间 |
| **空间复杂度** | $O(h)$，递归栈深度 | $O(1)$，只用几个指针 |
| **时间复杂度** | $O(n)$ | $O(n)$ |
| **代码量** | 简洁 | 稍多 |
| **直观度** | 需要理解"从后往前串" | 需要理解"找最右下角" |
| **面试推荐** | ⭐⭐⭐ 好写，易解释 | ⭐⭐⭐⭐⭐ 空间最优，加分项 |

## 五、易错点总结

### 解法一易错点

| 坑点 | 说明 |
|------|------|
| ❌ 遍历顺序写成左 → 右 → 根 | 必须是**右 → 左 → 根**，才能从后往前串 |
| ❌ `preNode` 初始值不对 | 必须初始化为 `nullptr`，表示链表末尾 |
| ❌ 忘记 `root->left = nullptr` | 题目要求所有 `left` 都置空 |
| ❌ `preNode` 定义位置错误 | 必须是成员变量或全局变量，不能在函数内定义，否则递归间无法共享状态 |

### 解法二易错点

| 坑点 | 说明 |
|------|------|
| ❌ 找前驱时走 `left` | 必须一路走 **`right`**，找的是最右下角 |
| ❌ 先接右子树再搬家 | 必须先 `predecessor->right = curr->right`，再 `curr->right = next`，顺序不能反 |
| ❌ 忘记 `curr->left = nullptr` | 搬家后左指针必须置空 |
| ❌ `curr` 更新时机错误 | 必须在处理完当前节点后，`curr = curr->right`，不要提前走 |

---

## 六、一句话总结

> **递归法像"从后往前穿珠子"，后序遍历（右-左-根）+ `preNode` 指针，把每个节点串到已处理好的链表前面。迭代法像"搬家"，找到左子树的最右下角作为"接头"，把左子树插到右子树前面，原地完成重组。两种方法最终都按前序遍历顺序展开成链表。**
