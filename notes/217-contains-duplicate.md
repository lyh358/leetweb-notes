## 思路（两种常用方案）

### 方案 1：哈希集合（推荐，直观）

**核心思想**：遍历数组，把元素放进集合，集合自动去重。

- 每拿到一个元素，**先检查集合里有没有这个数**
  - 已有 → 找到重复，直接返回 true
  - 没有 → 插入集合继续遍历
- 遍历结束都没重复 → 返回 false
**数据结构**：unordered_set（哈希集合）
时间：(O(n))，平均；空间：(O(n))

### 方案 2：排序

**核心思想**：数组排序后，相同元素一定相邻。遍历比较相邻两个数即可。
**数据结构**：vector 原地排序
时间：(O(n\log n))；空间：(O(\log n))（排序栈开销）

## 伪代码（哈希集合）

```javascript
function containsDuplicate(nums):
    创建空集合 s
    for num in nums:
        if num 在 s 中:
            return true
        将 num 插入 s
    return false
```
