## 给你一个整数数组 `nums` 。如果任一值在数组中出现 至少两次 ，返回 `true` ；如果数组中每个元素互不相同，返回 `false` 。

**示例 1：**

**输入：**nums = [1,2,3,1]

**输出：**true

**解释：**

元素 1 在下标 0 和 3 出现。

**示例 2：**

**输入：**nums = [1,2,3,4]

**输出：**false

**解释：**

所有元素都不同。

**示例 3：**

**输入：**nums = [1,1,1,3,3,4,3,2,4,2]

**输出：**true

## 思路（两种常用方案）

### 方案 1：哈希集合（推荐，直观）

**核心思想**：遍历数组，把元素放进集合，集合自动去重。

- 每拿到一个元素，**先检查集合里有没有这个数**
  - 已有 → 找到重复，直接返回 true
  - 没有 → 插入集合继续遍历
- 遍历结束都没重复 → 返回 false
**数据结构**：unordered_set（哈希集合）
时间：(O(n))，平均；空间：(O(n))

### 方案 2：排序

**核心思想**：数组排序后，相同元素一定相邻。遍历比较相邻两个数即可。
**数据结构**：vector 原地排序
时间：(O(n\log n))；空间：(O(\log n))（排序栈开销）

> 面试优先掌握哈希集合版本，下面给哈希版本伪代码 + C++ 完整代码

## 伪代码（哈希集合）

```javascript
function containsDuplicate(nums):
    创建空集合 s
    for num in nums:
        if num 在 s 中:
            return true
        将 num 插入 s
    return false
```
