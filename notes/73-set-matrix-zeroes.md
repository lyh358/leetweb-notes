# LeetCode 73. 矩阵置零 —— 标记数组解法学习笔记

> **题目**: [73. Set Matrix Zeroes](https://leetcode.cn/problems/set-matrix-zeroes/)  
> **核心**: 给定 `m × n` 的矩阵 `matrix`，如果一个元素为 `0`，则将其**所在行和列**的所有元素都设为 `0`。  
> **要求**: 必须使用**原地**算法（但本题解使用 $O(m+n)$ 额外空间，进阶要求 $O(1)$）。  
> **示例**:  
> ```
> 输入:          输出:
> [1,1,1]       [1,0,1]
> [1,0,1]  →    [0,0,0]
> [1,1,1]       [1,0,1]
> ```

---

## 一、核心思想：先标记，后清零

### 1.1 为什么不能边扫边清零？
如果遍历到一个 `0` 就立即把它的行和列全置 `0`，会导致**误判**：

```
原始矩阵:      扫描到 [1][1]=0 立即清零行和列:
[1, 1, 1]      [1, 0, 1]
[1, 0, 1]  →   [0, 0, 0]   ← 新产生的 0 会误导后续扫描！
[1, 1, 1]      [1, 0, 1]
```

新产生的 `0` 会让程序误以为原始矩阵中这些位置本来就是 `0`，从而错误地清零更多行和列。

### 1.2 正确策略：两遍扫描
1. **第一遍**：只"看"不"改"——遍历整个矩阵，用标记数组记录哪些行和列包含原始 `0`；
2. **第二遍**：根据标记数组，把对应行和列的所有元素置 `0`。

---

## 二、代码实现（带完整注释）

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        // ========== 步骤1：获取矩阵维度 ==========
        int n = matrix.size();           // n = 矩阵的行数 (number of rows)
        int m = matrix[0].size();        // m = 矩阵的列数 (number of columns)

        // ========== 步骤2：创建标记数组 ==========
        // row[i] = true 表示第 i 行包含原始 0，需要整行清零
        // col[j] = true 表示第 j 列包含原始 0，需要整列清零
        vector<bool> row(n, false);      // 初始化 n 个 false，代表 n 行
        vector<bool> col(m, false);      // 初始化 m 个 false，代表 m 列

        // ========== 步骤3：第一遍扫描 —— 标记含0的行和列 ==========
        // 遍历矩阵中的每一个元素，找到所有原始 0 的位置
        for (int i = 0; i < n; i++) {           // i 遍历每一行
            for (int j = 0; j < m; j++) {       // j 遍历每一列
                if (matrix[i][j] == 0) {        // 发现原始 0
                    row[i] = true;              // 标记：第 i 行需要清零
                    col[j] = true;              // 标记：第 j 列需要清零
                }
            }
        }

        // ========== 步骤4：第二遍扫描 —— 根据标记置零 ==========
        // 再次遍历矩阵，如果当前位置所在行或列被标记，则置为 0
        for (int i = 0; i < n; i++) {           // i 遍历每一行
            for (int j = 0; j < m; j++) {       // j 遍历每一列
                // 逻辑或：只要所在行或所在列被标记过，就置 0
                if (row[i] || col[j]) {
                    matrix[i][j] = 0;
                }
            }
        }

        // 函数返回 void，matrix 已通过引用原地修改
    }
};
```

## 三、逐步推演示例

### 示例 1：基础情况
```
原始矩阵:
[1, 1, 1]
[1, 0, 1]
[1, 1, 1]
```

**第一遍扫描 —— 标记：**

| i | j | matrix[i][j] | 操作 | row 状态 | col 状态 |
|:-:|:-:|:-:|:----:|:--------:|:--------:|
| 0 | 0 | 1 | 无 | `[F,F,F]` | `[F,F,F]` |
| 0 | 1 | 1 | 无 | `[F,F,F]` | `[F,F,F]` |
| 0 | 2 | 1 | 无 | `[F,F,F]` | `[F,F,F]` |
| 1 | 0 | 1 | 无 | `[F,F,F]` | `[F,F,F]` |
| 1 | 1 | **0** | `row[1]=T, col[1]=T` | `[F,T,F]` | `[F,T,F]` |
| 1 | 2 | 1 | 无 | `[F,T,F]` | `[F,T,F]` |
| 2 | 0 | 1 | 无 | `[F,T,F]` | `[F,T,F]` |
| 2 | 1 | 1 | 无 | `[F,T,F]` | `[F,T,F]` |
| 2 | 2 | 1 | 无 | `[F,T,F]` | `[F,T,F]` |

标记结果：`row = [F, T, F]`，`col = [F, T, F]`

**第二遍扫描 —— 置零：**

| i | j | row[i] | col[j] | row[i]\|\|col[j] | matrix[i][j] |
|:-:|:-:|:-:|:-:|:-:|:-:|
| 0 | 0 | F | F | F | 1（不变） |
| 0 | 1 | F | **T** | **T** | **0** |
| 0 | 2 | F | F | F | 1（不变） |
| 1 | 0 | **T** | F | **T** | **0** |
| 1 | 1 | **T** | **T** | **T** | **0** |
| 1 | 2 | **T** | F | **T** | **0** |
| 2 | 0 | F | F | F | 1（不变） |
| 2 | 1 | F | **T** | **T** | **0** |
| 2 | 2 | F | F | F | 1（不变） |

**最终结果：**
```
[1, 0, 1]
[0, 0, 0]
[1, 0, 1]
```

### 示例 2：多个 0 分散在不同行列
```
原始矩阵:
[0, 1, 2, 0]
[3, 4, 5, 2]
[1, 3, 1, 5]
```

**第一遍扫描 —— 标记：**
- `[0][0] = 0` → `row[0]=T, col[0]=T`
- `[0][3] = 0` → `row[0]=T, col[3]=T`

标记结果：`row = [T, F, F]`，`col = [T, F, F, T]`

**第二遍扫描 —— 置零：**
- 第 0 行全部置 0（因为 `row[0]=T`）
- 第 0 列全部置 0（因为 `col[0]=T`）
- 第 3 列全部置 0（因为 `col[3]=T`）

**最终结果：**
```
[0, 0, 0, 0]
[0, 4, 5, 0]
[0, 3, 1, 0]
```

### 示例 3：全零矩阵
```
原始矩阵:

**第一遍扫描：** 所有位置都是 0，`row = [T, T]`，`col = [T, T]`

**第二遍扫描：** 所有位置都满足 `row[i] || col[j]`，全部置 0

**结果**：仍然是全零矩阵 ✓

### 示例 4：无零矩阵

## 四、复杂度分析

| 维度 | 结果 |
|------|------|
| **时间复杂度** | $O(m \times n)$ —— 两次遍历矩阵，每次 $O(mn)$ |
| **空间复杂度** | $O(m + n)$ —— 两个布尔数组，`row` 占 $O(n)$，`col` 占 $O(m)$ |

> 题目进阶要求使用 **$O(1)$ 额外空间**，见下方第五节。

---

## 五、进阶：$O(1)$ 空间解法（第一行/第一列做标记）

### 5.1 核心思想
标记数组的本质是记录"哪些行/列需要清零"。如果能把标记信息**存储在矩阵本身**中，就能省去额外空间。

具体做法：
1. **用第一行标记各列**：如果第 `j` 列需要清零，则把 `matrix[0][j]` 置 `0`；
2. **用第一列标记各行**：如果第 `i` 行需要清零，则把 `matrix[i][0]` 置 `0`；
3. 需要两个额外变量记录**第一行和第一列本身**是否包含原始 `0`（因为它们既是标记区又是数据区）。

### 5.2 代码实现

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int n = matrix.size();       // 行数
        int m = matrix[0].size();    // 列数

        // 步骤1：记录第一行和第一列本身是否含 0
        bool firstRowHasZero = false;
        bool firstColHasZero = false;

        for (int j = 0; j < m; j++) {
            if (matrix[0][j] == 0) firstRowHasZero = true;
        }
        for (int i = 0; i < n; i++) {
            if (matrix[i][0] == 0) firstColHasZero = true;
        }

        // 步骤2：用第一行和第一列做标记
        // matrix[i][0] 标记第 i 行是否需要清零
        // matrix[0][j] 标记第 j 列是否需要清零
        for (int i = 1; i < n; i++) {
            for (int j = 1; j < m; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;  // 标记第 i 行
                    matrix[0][j] = 0;  // 标记第 j 列
                }
            }
        }

        // 步骤3：根据标记，清零非第一行/列的元素
        for (int i = 1; i < n; i++) {
            for (int j = 1; j < m; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }

        // 步骤4：最后处理第一行和第一列（因为它们被当作标记区，最后才清零）
        if (firstRowHasZero) {
            for (int j = 0; j < m; j++) matrix[0][j] = 0;
        }
        if (firstColHasZero) {
            for (int i = 0; i < n; i++) matrix[i][0] = 0;
        }
    }
};
```

### 5.3 为什么需要 `firstRowHasZero` 和 `firstColHasZero`？
因为第一行和第一列**身兼两职**：
- 作为**数据区**：它们自己的元素可能被置零；
- 作为**标记区**：它们存储其他行/列的标记信息。

如果不提前记录它们本身是否含 `0`，在步骤 2 中用它们做标记时，会丢失"第一行/列本身需要清零"这个信息。

### 5.4 复杂度对比

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|:----:|:---------:|:---------:|:--------:|
| 标记数组法（你的代码） | $O(mn)$ | $O(m+n)$ | 面试基础思路，逻辑清晰 |
| 第一行/列标记法 | $O(mn)$ | $O(1)$ | 面试进阶，展示空间优化能力 |

## 六、易错点与面试 Tips

### ❌ 错误 1：边扫边清零
```cpp
// 错误！遍历时直接修改会导致误判
if (matrix[i][j] == 0) {
    // 把第 i 行和第 j 列全置 0  ← 新产生的 0 会干扰后续判断
}
```
**必须两遍扫描**，先标记后清零。

### ❌ 错误 2：标记数组维度写反
```cpp
vector<bool> row(n, false);  // n 行 → n 个元素
vector<bool> col(m, false);  // m 列 → m 个元素
// 不要写成 row(m) 和 col(n)！
```

### ❌ 错误 3：$O(1)$ 空间解法中先清零第一行/列
```cpp
// 错误！如果先清零第一行，会丢失所有列的标记信息
// 必须先处理完内部元素，最后再处理第一行和第一列
```

### ❌ 错误 4：$O(1)$ 空间解法中忘记检查第一行/列本身
```cpp
// 如果 matrix[0][0] == 0，它既代表第 0 行有 0，也代表第 0 列有 0
// 必须用两个独立变量 firstRowHasZero 和 firstColHasZero 区分
```

### ✅ 面试回答框架
1. **基础版（你的代码）**：两遍扫描 + 标记数组，$O(mn)$ 时间，$O(m+n)$ 空间；
2. **进阶版**：用第一行和第一列做标记，$O(1)$ 额外空间；
3. **强调关键点**：为什么不能边扫边清零？因为新产生的 0 会造成连锁误判。

---

## 七、一句话总结

> **先看后改**：第一遍只做"侦察兵"，用标记数组记录哪里有 0；第二遍再做"工兵"，根据标记把对应行列全部炸平。如果面试官追问空间优化，就把第一行和第一列"征用"为标记区，省掉额外数组。

| 要点 | 内容 |
|------|------|
| 核心策略 | 两遍扫描：先标记，后清零 |
| 标记数组 | `row[n]` 记录行，`col[m]` 记录列 |
| 为什么不能边扫边改 | 新产生的 0 会被误判为原始 0，导致过度清零 |
| 空间优化 | 用矩阵第一行/列做标记，仅需 2 个额外变量 |
| 时间复杂度 | $O(m \times n)$ |
| 空间复杂度 | $O(m+n)$（基础版）/ $O(1)$（进阶版） |
