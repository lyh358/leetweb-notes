# 动态规划（DP）问题总结

## 一、核心思想

动态规划的本质是**用空间换时间**，通过记录子问题的解来避免重复计算。它适用于具有**最优子结构**和**重叠子问题**性质的问题。

---

## 二、解题四步法

| 步骤 | 内容 | 关键问题 |
|------|------|----------|
| **1. 定义状态** | 确定 `dp[i]` 或 `dp[i][j]` 的含义 | "到什么位置/状态下，最优值是多少？" |
| **2. 状态转移** | 写出递推公式 | "当前状态如何从之前的状态推导而来？" |
| **3. 初始化** | 确定边界条件的值 | "最小子问题的解是什么？" |
| **4. 遍历顺序** | 确定计算每个状态的先后次序 | "计算当前状态时，依赖的状态是否已计算？" |

---

## 三、常见类型与模板

### 1. 线性 DP（一维）
**适用**：最大子数组和、爬楼梯、打家劫舍、最长递增子序列

```python
# 模板框架
dp = [0] * (n + 1)      # 1. 定义并初始化数组
dp[0] = base_case        # 2. 边界初始化

for i in range(1, n + 1):
    dp[i] = max/min(     # 3. 状态转移
        dp[i-1] + ... ,  # 从前一个状态转移
        ...              # 其他可能的选择
    )

return dp[n]             # 4. 返回目标状态
```

**典型例题**：
- 爬楼梯：`dp[i] = dp[i-1] + dp[i-2]`
- 打家劫舍：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

---

### 2. 背包问题（二维/滚动数组）
**适用**：0-1 背包、完全背包、多重背包

#### 0-1 背包（每个物品选或不选）
```python
# dp[i][j] = 前i个物品，容量为j时的最大价值
dp = [[0] * (W + 1) for _ in range(n + 1)]

for i in range(1, n + 1):
    for j in range(W + 1):
        if j < weight[i]:           # 装不下
            dp[i][j] = dp[i-1][j]
        else:                        # 装得下，选或不选
            dp[i][j] = max(
                dp[i-1][j],                     # 不选第i个
                dp[i-1][j-weight[i]] + value[i] # 选第i个
            )

# 空间优化（一维倒序遍历）
dp = [0] * (W + 1)
for i in range(n):
    for j in range(W, weight[i]-1, -1):   # 必须倒序！
        dp[j] = max(dp[j], dp[j-weight[i]] + value[i])
```

#### 完全背包（每个物品无限个）
```python
# 与0-1背包的区别：正序遍历（可以重复选）
for i in range(n):
    for j in range(weight[i], W + 1):     # 正序！
        dp[j] = max(dp[j], dp[j-weight[i]] + value[i])
```

**核心区别**：
| 类型 | 内层循环方向 | 原因 |
|------|-------------|------|
| 0-1 背包 | **倒序** | 防止同一物品被重复选取 |
| 完全背包 | **正序** | 允许同一物品被重复选取 |

### 3. 区间 DP
**适用**：石子合并、矩阵链乘、回文子串、括号匹配

```python
# dp[i][j] = 区间[i,j]上的最优解
n = len(s)
dp = [[0] * n for _ in range(n)]

# 区间长度从小到大枚举
for length in range(2, n + 1):           # 区间长度
    for i in range(n - length + 1):      # 起点
        j = i + length - 1                # 终点
        dp[i][j] = ...                    # 状态转移
        for k in range(i, j):            # 枚举分割点
            dp[i][j] = max/min(dp[i][j], dp[i][k] + dp[k+1][j] + cost)
```

**关键点**：区间长度从小到大枚举，确保小区间先计算。

---

### 4. 树形 DP
**适用**：树上最大独立集、树的直径、打家劫舍III

```python
# 后序遍历
def dfs(node):
    if not node:
        return (0, 0)  # (选当前节点的最大值, 不选的最大值)
    
    left = dfs(node.left)
    right = dfs(node.right)
    
    # 选当前节点，则子节点不能选
    select = node.val + left[1] + right[1]
    
    # 不选当前节点，则子节点可选可不选
    not_select = max(left) + max(right)
    
    return (select, not_select)
```

### 5. 状态压缩 DP
**适用**：旅行商问题（TSP）、棋盘覆盖、集合子集问题

```python
# dp[mask][i] = 已访问集合mask，当前在节点i的最短距离
n = len(graph)
dp = [[inf] * n for _ in range(1 << n)]
dp[1][0] = 0                    # 从节点0出发

for mask in range(1 << n):
    for i in range(n):
        if not (mask & (1 << i)): continue    # i不在mask中
        for j in range(n):
            if mask & (1 << j): continue      # j已访问过
            new_mask = mask | (1 << j)
            dp[new_mask][j] = min(
                dp[new_mask][j],
                dp[mask][i] + graph[i][j]
            )
```

## 四、实用技巧

### 1. 空间优化
- **滚动数组**：当状态只依赖前一行/前一列时，可将二维降为一维
- **状态压缩**：用二进制位表示集合状态

### 2. 初始化技巧
| 问题类型 | 初始化方式 |
|----------|-----------|
| 求最大值 | `dp = [0] + [-inf] * n` 或全0 |
| 求最小值 | `dp = [0] + [inf] * n` |
| 计数问题 | `dp[0] = 1`，其余为0 |
| 存在性问题 | `dp[0] = True`，其余为False |

### 3. 常见转移方程模式
```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])      # 相邻限制选择
dp[i] = min(dp[j] + cost) for j in [0,i)     # 枚举前一个状态
dp[i][j] = dp[i-1][j] + dp[i][j-1]           # 网格路径
dp[i][j] = dp[i-1][j-1] + 1 if match         # 最长公共子序列
```

## 五、快速判断流程

```
问题是否满足：
├─ 最优子结构？（大问题的最优解包含子问题的最优解）
├─ 重叠子问题？（递归时会重复计算相同子问题）
└─ 无后效性？（当前决策不影响之前的状态）

  ├─ 是 → 考虑动态规划
  │       ├─ 选择有限（选/不选）→ 背包类
  │       ├─ 序列相关 → 线性DP / LIS / LCS
  │       ├─ 区间相关 → 区间DP
  │       ├─ 树结构 → 树形DP
  │       └─ 集合相关 → 状态压缩DP
  │
  └─ 否 → 考虑贪心、回溯或分治
```

## 六、经典题目对照表

| 题目 | 类型 | 状态定义 |
|------|------|----------|
| 爬楼梯 | 线性DP | `dp[i]` = 到第i阶的方法数 |
| 最长递增子序列 | 线性DP | `dp[i]` = 以i结尾的最长长度 |
| 最长公共子序列 | 二维DP | `dp[i][j]` = s1前i与s2前j的LCS |
| 编辑距离 | 二维DP | `dp[i][j]` = 转换的最小操作数 |
| 0-1背包 | 背包DP | `dp[i][j]` = 前i个物品容量j的最大价值 |
| 股票买卖 | 状态机DP | `dp[i][0/1]` = 第i天持有/不持有的最大利润 |
| 矩阵链乘 | 区间DP | `dp[i][j]` = 区间[i,j]的最小代价 |
| 打家劫舍III | 树形DP | 每个节点返回（选，不选）两个值 |

---

**一句话总结**：DP = **定义清楚状态** + **找到转移方程** + **填好表格**。多练几道题熟悉状态定义的方式，就能快速识别题型。
