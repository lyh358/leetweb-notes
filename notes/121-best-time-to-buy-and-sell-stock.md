# LeetCode 121. 买卖股票的最佳时机 —— 贪心/动态规划学习笔记

> **题目**: [121. Best Time to Buy and Sell Stock](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)  
> **核心**: 给定一个数组 `prices`，其中 `prices[i]` 表示某股票第 `i` 天的价格。你只能选择**某一天买入**这只股票，并选择在**未来的某一天卖出**。设计一个算法来计算你所能获取的**最大利润**。如果你不能获取任何利润，返回 `0`。  
> **示例**:  
> ```
> prices = [7, 1, 5, 3, 6, 4]  →  5（第 2 天买入 1，第 5 天卖出 6）
> prices = [7, 6, 4, 3, 1]     →  0（价格一直跌，不买最赚）
> ```

---

## 一、核心思想：历史最低价 + 当前最大利润

### 1.1 暴力思路的问题
如果枚举所有"买入日 + 卖出日"的组合，需要 $O(n^2)$ 时间。对于 $n = 10^5$ 的数据会超时。

### 1.2 贪心洞察
对于第 `i` 天卖出，最大利润 = `prices[i] - 之前最低价格`。  
因此，我们只需要在遍历过程中：
1. 维护一个变量 `buy`，记录**截至目前的最低价格**（最佳买入时机）；
2. 维护一个变量 `sell`，记录**截至目前能获得的最大利润**；
3. 每天更新这两个值即可。

```
 prices: [7, 1, 5, 3, 6, 4]

 第0天:  price=7, buy=min(∞,7)=7, sell=max(0,7-7)=0
 第1天:  price=1, buy=min(7,1)=1, sell=max(0,1-1)=0
 第2天:  price=5, buy=min(1,5)=1, sell=max(0,5-1)=4
 第3天:  price=3, buy=min(1,3)=1, sell=max(0,3-1)=2 → 保持 4
 第4天:  price=6, buy=min(1,6)=1, sell=max(4,6-1)=5
 第5天:  price=4, buy=min(1,4)=1, sell=max(5,4-1)=3 → 保持 5
```

### 1.3 为什么贪心是正确的？

**关键观察**：对于任意一天 `i`，如果要在第 `i` 天或之前卖出，最优的买入日一定是**第 0 天到第 i-1 天中价格最低的那一天**。

- `buy` 始终维护 `[0, i]` 范围内的最小值；
- `sell` 始终维护以第 `i` 天或之前某天卖出时的最大利润；
- 每一天都尝试"如果今天卖出"的利润，取历史最大值。

由于利润只依赖于"历史最低买入价"和"当前卖出价"，不存在后效性，因此贪心策略成立。

## 二、代码实现（带完整注释）

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        // ========== 贪心策略：最小价格买入，最大收益卖出 ==========

        // buy: 记录遍历到目前为止遇到的最低股价（最佳买入价）
        // 初始化为一个极大值，确保第一个价格一定能更新它
        int buy = 1e9;

        // sell: 记录遍历到目前为止能获得的最大利润
        // 初始化为 0，表示"不交易"的利润为 0
        int sell = 0;

        // ========== 遍历每一天的股价 ==========
        for (int price : prices) {
            // 步骤1：更新历史最低买入价
            // 如果今天的价格比之前记录的最低买入价还低，就更新
            // 这意味着"如果之后某天卖出，今天买入更划算"
            buy = min(buy, price);

            // 步骤2：计算"如果今天卖出"的利润，并更新最大利润
            // 今天卖出的利润 = 今天价格 - 历史最低买入价
            // 如果这个利润比之前记录的最大利润还大，就更新
            sell = max(sell, price - buy);
        }

        // ========== 返回结果 ==========
        // 如果最大利润大于 0，返回该利润；否则返回 0
        // （题目要求：如果不能获取利润，返回 0，即不进行交易）
        return sell > 0 ? sell : 0;
    }
};
```

## 四、关键机制深度解析

### 4.1 为什么 `buy` 和 `sell` 的更新顺序不影响结果？

```cpp
buy = min(buy, price);
sell = max(sell, price - buy);
```

同一天内，先更新 `buy` 再算 `sell`，意味着：
- 如果今天的价格是历史新低，`buy` 会更新为今天的价格；
- 然后 `price - buy = price - price = 0`，今天卖出利润为 0。

**这是否会导致遗漏？** 不会。因为如果今天是最低价，那今天买入、今天卖出的利润一定是 0，不可能是最优解（除非所有价格都是 0）。真正的最优卖出一定在未来的某天。

### 4.2 为什么 `sell` 初始化为 0？

题目要求"如果不能获取利润，返回 0"，即允许不交易。`sell = 0` 表示"不交易"是一个合法的基准方案。

如果初始化为 `-1e9`，当价格一直下跌时，最后需要额外判断，不如初始化为 0 简洁。

### 4.3 贪心 vs 动态规划

这道题既可以用贪心，也可以用动态规划：

**DP 视角**：
- 状态：`dp[i]` 表示前 `i` 天的最大利润；
- 转移：`dp[i] = max(dp[i-1], prices[i] - minPrice)`；
- 其中 `minPrice = min(minPrice, prices[i])`。

**贪心视角**：
- 不需要数组，只用两个变量滚动更新；
- 本质上是 DP 的空间优化版（状态压缩）。

两者时间复杂度都是 $O(n)$，但贪心空间更优（$O(1)$）。

### 4.4 与 LeetCode 122（买卖股票的最佳时机 II）的区别

| 对比项 | 本题 LeetCode 121 | LeetCode 122 |
|:------:|:-----------------:|:------------:|
| **交易次数** | 只能买卖 **1 次** | 可以买卖 **无限次** |
| **核心策略** | 找全局最大差值 | 累加所有正利润段 |
| **代码** | 维护一个 minBuy | `sum += max(0, prices[i] - prices[i-1])` |
| **贪心可行性** | ✅ 只需一次交易 | ✅ 每次上涨都参与 |

## 六、易错点与面试 Tips

### ❌ 错误 1：`buy` 初始化为 0
```cpp
int buy = 0;  // ❌ 错误！如果第一个价格大于 0，buy 不会被更新
// 正确
int buy = INT_MAX;  // 或 1e9
```

### ❌ 错误 2：先算 `sell` 再更新 `buy`
```cpp
// 错误顺序
sell = max(sell, price - buy);  // 用的是旧的 buy
buy = min(buy, price);

// 正确顺序（本题中其实不影响最终结果，但逻辑上应该先更新买入价）
buy = min(buy, price);
sell = max(sell, price - buy);
```

### ❌ 错误 3：返回负利润
```cpp
return sell;  // ❌ 如果价格一直跌，sell 可能为 0，但如果初始化为负数...

// 正确
return sell > 0 ? sell : 0;  // ✅ 确保不返回负数
```

### ❌ 错误 4：数组为空未处理
```cpp
// 虽然本题测试数据保证非空，但严谨写法：
if (prices.empty()) return 0;
```

### ✅ 面试回答框架
1. **思路**：遍历数组，维护历史最低买入价和当前最大利润；
2. **每天操作**：更新最低买入价 → 计算今天卖出的利润 → 更新最大利润；
3. **正确性**：对于任意卖出日，最优买入日一定是此前的最低价，贪心无后效性；
4. **复杂度**：时间 $O(n)$，空间 $O(1)$。

### ✅ 追问准备
- **问**：如果可以交易多次，代码怎么改？  
  **答**：LeetCode 122，累加所有相邻正差值：`profit += max(0, prices[i] - prices[i-1])`。

- **问**：如果最多交易 k 次呢？  
  **答**：LeetCode 188，需要用 DP，`dp[i][k][0/1]` 表示第 `i` 天最多 `k` 次交易、持有/不持有股票的最大利润。

- **问**：如果卖出后必须冷却一天才能再买入？  
  **答**：LeetCode 309，DP 状态需要增加"冷却期"维度。

## 七、一句话总结

> **一路走一路看，遇到更低价就记下来（这可能是未来的最佳买入点），遇到能卖更高价就算算能赚多少（用今天价格减去记下来的最低价），把最大的那个利润揣兜里。全程只记两个数：最低买入价和最大利润。**

| 要点 | 内容 |
|------|------|
| 核心策略 | 维护历史最低价 `buy`，每天计算 `price - buy` 更新最大利润 `sell` |
| `buy` 的含义 | 截至目前的最低股价（最佳买入时机） |
| `sell` 的含义 | 截至目前能获得的最大利润 |
| 更新顺序 | 先 `buy = min(buy, price)`，再 `sell = max(sell, price - buy)` |
| 返回值 | `sell > 0 ? sell : 0`（无利润则返回 0） |
| 时间复杂度 | $O(n)$ |
| 空间复杂度 | $O(1)$ |
