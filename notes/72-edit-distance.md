## 二、核心思路：对齐两个字符串，逐个比对

想象你在用" diff 工具"比对两个字符串，从左到右逐个字符看：

```
word1:  h  o  r  s  e
         ↓
word2:  r  o  s
         ↓
```

**如果当前字符相同**（比如都是 `o`），太好了，不用操作，直接看下一个。

**如果不同**（比如 `word1` 是 `h`，`word2` 是 `r`），你有**三种选择**：
1. **替换**：把 `h` 换成 `r`，然后继续比对后面的
2. **删除**：删掉 `word1` 的 `h`，让 `word1` 后面的字符来和 `word2` 的 `r` 比
3. **插入**：在 `word1` 这里插入一个 `r`，让 `word1` 的 `h` 去和 `word2` 后面的 `o` 比

三种方案都试试，**哪个用的步数最少，就选哪个**。

## 三、状态定义

```cpp
// dp[i][j] = 把 word1 的前 i 个字符 转换成 word2 的前 j 个字符
//            所需要的最少操作数
```

**为什么数组开 `(m+1) × (n+1)`？**

```cpp
vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
```

多开一行一列（第 0 行和第 0 列），表示**空字符串**的情况：

| | `""` | `r` | `o` | `s` |
|---|---|---|---|---|
| `""` | 0 | 1 | 2 | 3 |
| `h` | 1 | ? | ? | ? |
| `o` | 2 | ? | ? | ? |
| `r` | 3 | ? | ? | ? |
| `s` | 4 | ? | ? | ? |
| `e` | 5 | ? | ? | ? |

- `dp[i][0] = i`：`word1` 前 `i` 个字符变成空串，需要 **i 次删除**
- `dp[0][j] = j`：空串变成 `word2` 前 `j` 个字符，需要 **j 次插入**

## 四、三种操作对应的状态转移

### 4.1 当前字符相同（`word1[i-1] == word2[j-1]`）

```
word1:  a b c
            ↑
word2:  x b y
            ↑
```

中间这个 `b` 和 `b` 相同，**不需要任何操作**，直接继承之前的结果：

```cpp
dp[i][j] = dp[i-1][j-1]   // 不需要操作，直接继承左上角
```

### 4.2 当前字符不同（`word1[i-1] != word2[j-1]`）

你有三种选择，每种选择都**花费 1 步**：

| 操作 | 含义 | 对应 dp 状态 | 公式 |
|------|------|-------------|------|
| **删除** | 删掉 `word1[i-1]` | `word1` 缩一格，`word2` 不动 | `dp[i-1][j] + 1` |
| **插入** | 在 `word1` 中插入 `word2[j-1]` | `word1` 不动，`word2` 缩一格 | `dp[i][j-1] + 1` |
| **替换** | 把 `word1[i-1]` 换成 `word2[j-1]` | 两个都缩一格 | `dp[i-1][j-1] + 1` |

```cpp
dp[i][j] = min(dp[i-1][j] + 1,    // 删除 word1[i-1]
               dp[i][j-1] + 1,    // 插入 word2[j-1]
               dp[i-1][j-1] + 1); // 替换 word1[i-1] 为 word2[j-1]
```

### 4.3 为什么"插入"对应 `dp[i][j-1]`？

很多人困惑：插入明明是在 `word1` 里加字符，为什么看的是 `dp[i][j-1]`（`word2` 缩一格）？

**换个角度想**：在 `word1` 里插入一个字符，等价于**跳过 `word2` 当前这个字符**。

```
word1:  ho        word2:  ros
            ↑                ↑
         当前是 'o'       当前是 'r'

在 word1 的 'o' 前面插入 'r'：
  word1 变成:  h r o
  现在 word1 的 'r' 对上了 word2 的 'r'
  word1 的 'o' 去对 word2 的 'o'

相当于：word2 的 'r' 被"解决"了，word2 缩一格
```

所以插入操作对应 `dp[i][j-1] + 1`。

## 五、最终通过的代码（带详细注释）

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        int m = word1.size();
        int n = word2.size();

        // 边界处理：如果有一个字符串为空
        // 空串变成另一个串，只需要插入/删除全部字符
        if (n * m == 0) return n + m;

        // dp[i][j] = word1前i个字符 转成 word2前j个字符 的最少操作数
        // 多开一行一列，第0行和第0列表示空字符串
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

        // 初始化第一列：word1前i个字符 转成 空串
        // 只能一路删除，操作数 = i
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }

        // 初始化第一行：空串 转成 word2前j个字符
        // 只能一路插入，操作数 = j
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }

        // 填表：从上到下，从左到右
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {

                if (word1[i - 1] == word2[j - 1]) {
                    // 当前字符相同，不需要操作
                    // 但代码里写了三种取最小，其中 dp[i-1][j-1] 不+1
                    // 所以结果自然取不+1的那个（即 dp[i-1][j-1]）
                    dp[i][j] = min({dp[i - 1][j] + 1,      // 删除
                                    dp[i][j - 1] + 1,       // 插入
                                    dp[i - 1][j - 1]});     // 不操作（字符相同）
                } else {
                    // 当前字符不同，三种操作都试一遍，取最小
                    dp[i][j] = min({dp[i - 1][j] + 1,      // 删除 word1[i-1]
                                    dp[i][j - 1] + 1,       // 插入 word2[j-1]
                                    dp[i - 1][j - 1] + 1}); // 替换 word1[i-1] 为 word2[j-1]
                }
            }
        }

        // 返回答案：word1全部m个 转成 word2全部n个 的最少操作数
        return dp[m][n];
    }
};
```

## 六、代码中的关键技巧详解

### 6.1 匹配时的写法分析

```cpp
if (word1[i - 1] == word2[j - 1]) {
    dp[i][j] = min({dp[i - 1][j] + 1, dp[i][j - 1] + 1, dp[i - 1][j - 1]});
}
```

**为什么匹配时也写三种选择？**

其实匹配时最优解就是 `dp[i-1][j-1]`（不需要操作）。但代码里把三种都放进来比较：
- `dp[i-1][j] + 1` = 删除（多此一举）
- `dp[i][j-1] + 1` = 插入（多此一举）
- `dp[i-1][j-1]` = 不操作（最优）

因为 `dp[i-1][j-1]` **一定小于等于**另外两个+1的值，所以 `min` 的结果自然就是 `dp[i-1][j-1]`。

**更标准的写法**（分开写更清晰）：
```cpp
if (word1[i - 1] == word2[j - 1]) {
    dp[i][j] = dp[i - 1][j - 1];  // 字符相同，不需要操作
} else {
    dp[i][j] = min({dp[i - 1][j] + 1, dp[i][j - 1] + 1, dp[i - 1][j - 1] + 1});
}
```

但你的写法也是正确的，只是稍微冗余。

### 6.2 为什么用 `min({a, b, c})`？

C++11 支持用花括号初始化列表一次比较多个值：
```cpp
min({a, b, c})  // 返回 a, b, c 中的最小值
```

如果不支持，可以写成嵌套：
```cpp
min(a, min(b, c))
```

## 十、常见错误

### ❌ 错误 1：边界初始化成 0
```cpp
// ❌ 错误
for (int i = 0; i <= m; i++) dp[i][0] = 0;
// 空串变空串是 0 步，但 "h" 变空串需要 1 步删除！

// ✅ 正确
for (int i = 0; i <= m; i++) dp[i][0] = i;  // 删除 i 次
for (int j = 0; j <= n; j++) dp[0][j] = j;  // 插入 j 次
```

### ❌ 错误 2：匹配时多加了 1
```cpp
// ❌ 错误：匹配时也 +1
if (word1[i-1] == word2[j-1]) {
    dp[i][j] = dp[i-1][j-1] + 1;  // 字符相同不需要操作！
}

// ✅ 正确
dp[i][j] = dp[i-1][j-1];  // 不操作，直接继承
```

### ❌ 错误 3：三种操作对应错 dp 状态
```cpp
// ❌ 错误：删除和插入写反了
// 删除 word1[i-1] 对应 dp[i][j-1]  ← 错了！
// 插入对应 dp[i-1][j]              ← 也错了！

// ✅ 正确记忆：
// 删除 word1[i-1] → word1 缩一格 → dp[i-1][j]
// 插入 word2[j-1] → word2 缩一格 → dp[i][j-1]
// 替换            → 两个都缩    → dp[i-1][j-1]
```

## 十二、一句话总结

> **字符相同 → 直接继承左上角。字符不同 → 删除、插入、替换三种方案都试一遍，取步数最少的那个。**

```cpp
// 核心代码
if (word1[i-1] == word2[j-1]) {
    dp[i][j] = dp[i-1][j-1];           // 相同，不操作
} else {
    dp[i][j] = min({dp[i-1][j] + 1,   // 删除
                     dp[i][j-1] + 1,    // 插入
                     dp[i-1][j-1] + 1}); // 替换
}
```
