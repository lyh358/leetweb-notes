# LeetCode 54. 螺旋矩阵 —— 边界收缩法学习笔记

> **题目**: [54. Spiral Matrix](https://leetcode.cn/problems/spiral-matrix/)  
> **核心**: 给定一个 `m × n` 的矩阵，按**顺时针螺旋顺序**返回矩阵中的所有元素。  
> **示例**:  
> ```
> 输入: matrix = [[1, 2, 3],
>                 [4, 5, 6],
>                 [7, 8, 9]]
> 输出: [1, 2, 3, 6, 9, 8, 7, 4, 5]
> ```

---

## 一、核心思想：设定边界，顺时针收缩

### 1.1 螺旋遍历的本质
螺旋遍历 = **按圈遍历**，从外到内一圈一圈地"剥洋葱"：

```
第 1 圈（最外层）:  顶行 → 右列 → 底行 → 左列
第 2 圈（次外层）:  顶行 → 右列 → 底行 → 左列
第 3 圈（最内层）:  ...
```

### 1.2 边界收缩法
用四个变量定义当前"未遍历区域"的边界：
- `u` (up)：上边界，初始为 `0`
- `d` (down)：下边界，初始为 `m - 1`
- `l` (left)：左边界，初始为 `0`
- `r` (right)：右边界，初始为 `n - 1`

每遍历完一条边，就**收缩对应的边界**，表示这一行/列已经被"吃掉"了：
- 遍历完顶行 → `u++`（上边界下移）
- 遍历完右列 → `r--`（右边界左移）
- 遍历完底行 → `d--`（下边界上移）
- 遍历完左列 → `l++`（左边界右移）

当某两条边界**交错**（如 `u > d` 或 `l > r`），说明所有元素已遍历完毕。

## 二、代码实现（带完整注释）

```cpp
class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        vector<int> ans;  // 存储螺旋遍历的结果

        // ========== 边界情况处理 ==========
        // 若矩阵为空（行数为0），直接返回答案
        if (matrix.empty()) return ans;

        // ========== 初始化四个边界 ==========
        int u = 0;                          // u = up，上边界，从第0行开始
        int d = matrix.size() - 1;          // d = down，下边界，最后一行
        int l = 0;                          // l = left，左边界，从第0列开始
        int r = matrix[0].size() - 1;       // r = right，右边界，最后一列

        // ========== 螺旋遍历主循环 ==========
        while (true) {
            // ---- Step 1: 向右遍历顶行 ----
            // 从当前左边界 l 走到右边界 r，行固定为 u（顶行）
            for (int i = l; i <= r; ++i) {
                ans.push_back(matrix[u][i]);
            }
            // 顶行遍历完毕，上边界下移一行
            // 同时检查：若上边界超过下边界，说明遍历完成，跳出循环
            if (++u > d) break;

            // ---- Step 2: 向下遍历右列 ----
            // 从当前上边界 u 走到下边界 d，列固定为 r（右列）
            for (int i = u; i <= d; ++i) {
                ans.push_back(matrix[i][r]);
            }
            // 右列遍历完毕，右边界左移一列
            // 同时检查：若右边界小于左边界，说明遍历完成，跳出循环
            if (--r < l) break;

            // ---- Step 3: 向左遍历底行 ----
            // 从当前右边界 r 走回左边界 l，行固定为 d（底行）
            for (int i = r; i >= l; --i) {
                ans.push_back(matrix[d][i]);
            }
            // 底行遍历完毕，下边界上移一行
            // 同时检查：若下边界小于上边界，说明遍历完成，跳出循环
            if (--d < u) break;

            // ---- Step 4: 向上遍历左列 ----
            // 从当前下边界 d 走回上边界 u，列固定为 l（左列）
            for (int i = d; i >= u; --i) {
                ans.push_back(matrix[i][l]);
            }
            // 左列遍历完毕，左边界右移一列
            // 同时检查：若左边界超过右边界，说明遍历完成，跳出循环
            if (++l > r) break;
        }

        return ans;
    }
};
```

## 三、逐步推演示例

### 示例 1：3×3 矩阵（奇数边长）
```
初始矩阵:
[1, 2, 3]
[4, 5, 6]
[7, 8, 9]
```

**初始边界**: `u=0, d=2, l=0, r=2`

| 步骤 | 方向 | 遍历范围 | 加入 ans | 边界更新 | 新边界 |
|:----:|:----:|:--------:|:--------:|:--------:|:------:|
| 1 | 向右 | matrix[0][0..2] | 1,2,3 | `u++` → 1 | u=1,d=2,l=0,r=2 |
| 2 | 向下 | matrix[1..2][2] | 6,9 | `r--` → 1 | u=1,d=2,l=0,r=1 |
| 3 | 向左 | matrix[2][1..0] | 8,7 | `d--` → 1 | u=1,d=1,l=0,r=1 |
| 4 | 向上 | matrix[1][0] | 4 | `l++` → 1 | u=1,d=1,l=1,r=1 |
| 5 | 向右 | matrix[1][1] | 5 | `u++` → 2 | u=2,d=1 → **u>d，跳出** |

**结果**: `[1, 2, 3, 6, 9, 8, 7, 4, 5]` ✓

## 四、边界检查的时机与必要性

### 4.1 为什么每次遍历后都要检查？
因为在非方阵或奇数/偶数边长的情况下，**一圈不一定恰好遍历完所有元素**。可能在某一步之后，剩余的未遍历区域已经不存在了。

以 3×3 矩阵为例：
- 第 1 圈遍历了 8 个元素（外圈）
- 还剩中间 1 个元素 `[5]`
- 第 2 圈向右只走 1 步就取到了 `5`，然后 `u++` 导致 `u > d`，结束

如果不检查，会继续执行 `for (int i = u; i <= d; ++i)`，此时 `u=2, d=1`，循环不执行但也不会出错。然而对于更复杂的情况（如 1×N 或 N×1），不检查会导致**重复遍历**或**数组越界**。

### 4.2 四个检查条件的含义

| 检查条件 | 含义 | 何时触发 |
|:--------:|:----:|:--------:|
| `++u > d` | 上边界下移后超过下边界 | 只剩一行或遍历完毕 |
| `--r < l` | 右边界左移后小于左边界 | 只剩一列或遍历完毕 |
| `--d < u` | 下边界上移后小于上边界 | 只剩一行或遍历完毕 |
| `++l > r` | 左边界右移后超过右边界 | 只剩一列或遍历完毕 |

## 五、复杂度分析

| 维度 | 结果 |
|------|------|
| **时间复杂度** | $O(m \times n)$ —— 每个元素恰好被访问一次 |
| **空间复杂度** | $O(1)$ —— 只使用了 `u, d, l, r` 四个变量（答案数组 `ans` 不算额外空间） |

> 本题不需要记录已访问路径（如 visited 矩阵），因此时间和空间开销都很小。

## 六、易错点与面试 Tips

### ❌ 错误 1：边界更新与检查顺序颠倒
```cpp
// 错误写法：先检查再更新
if (u > d) break;  // 此时 u 还没+1，判断的是旧边界！
u++;
```
**正确写法**：先更新边界（`++u`），再用新边界判断（`> d`）。

### ❌ 错误 2：忘记处理空矩阵
```cpp
if (matrix.empty()) return ans;  // 必须加！否则 matrix[0] 会越界
```
如果矩阵为空，`matrix[0].size()` 会触发运行时错误。

### ❌ 错误 3：遍历方向写反
```cpp
// 向左遍历应该是 i--
for (int i = r; i >= l; --i)  // ✅ 从右到左
for (int i = l; i <= r; ++i)  // ❌ 这变成从左到右了！
```

### ❌ 错误 4：四个方向的遍历范围写错
```cpp
// 向右：行固定为 u，列从 l 到 r
for (int i = l; i <= r; ++i) ans.push_back(matrix[u][i]);

// 向下：列固定为 r，行从 u 到 d
for (int i = u; i <= d; ++i) ans.push_back(matrix[i][r]);

// 向左：行固定为 d，列从 r 到 l
for (int i = r; i >= l; --i) ans.push_back(matrix[d][i]);

// 向上：列固定为 l，行从 d 到 u
for (int i = d; i >= u; --i) ans.push_back(matrix[i][l]);
```
每步都要注意：**哪个坐标固定，哪个坐标变化，变化方向是什么**。

### ❌ 错误 5：用 `while (u <= d && l <= r)` 代替 `while(true)` + `break`
```cpp
// 这种写法也可以，但需要在循环内部额外判断
while (u <= d && l <= r) {
    // ... 四个方向遍历
}
```
两种写法等价，但 `while(true) + break` 更直观——每次遍历一条边后立即检查，避免在循环末尾统一判断时漏掉边界情况。

### ✅ 面试回答框架
1. **思路**：用四个边界定义未遍历区域，顺时针一圈一圈"剥皮"；
2. **关键**：每遍历完一条边就收缩对应边界，并检查是否交错；
3. **复杂度**：时间 $O(mn)$，空间 $O(1)$；
4. **优势**：不需要 visited 数组，空间开销极小。

## 七、一句话总结

> **设定上下左右四条边界，顺时针走一圈（右→下→左→上），每走完一边就收缩对应的边界，直到边界交错，说明"皮"剥完了。**

| 要点 | 内容 |
|------|------|
| 核心技巧 | 四边界收缩法 |
| 遍历顺序 | 右 → 下 → 左 → 上（顺时针） |
| 边界更新 | 右完 `u++`，下完 `r--`，左完 `d--`，上完 `l++` |
| 终止条件 | `u>d` 或 `l>r`（边界交错） |
| 时间复杂度 | $O(m \times n)$ |
| 空间复杂度 | $O(1)$ |
| 优势 | 无需记录已访问路径 |
