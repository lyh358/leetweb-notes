# 力扣 152. 乘积最大子数组 — 学习笔记

> **题目**：给你一个整数数组 `nums`，请你找出数组中乘积最大的**非空连续子数组**（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。  
> **难度**：中等  
> **标签**：数组、动态规划

---

## 一、题目理解

**示例 1**：
```
输入: nums = [2, 3, -2, 4]
输出: 6
解释: 子数组 [2, 3] 有最大乘积 6
```

**示例 2**：
```
输入: nums = [-2, 0, -1]
输出: 0
解释: 结果不能为 2，因为 [-2, -1] 不是子数组（不连续）
```

---

## 二、为什么不能用"最大子数组和"的思路？

力扣 53（最大子数组和）的转移方程是：
```cpp
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

如果直接改成乘法：
```cpp
dp[i] = max(nums[i], dp[i-1] * nums[i])  // ❌ 错误！
```

**反例**：`nums = [-2, 3, -4]`

| i | nums[i] | dp[i-1] | dp[i-1]*nums[i] | 按错误公式 dp[i] | 实际最优 |
|---|---------|---------|-----------------|------------------|---------|
| 0 | -2 | — | — | -2 | -2 |
| 1 | 3 | -2 | -6 | **3** | 3 |
| 2 | -4 | 3 | -12 | **-4** | ❌ |

**问题**：当 `nums[2] = -4` 时，前一个状态 `dp[1] = 3` 是正数，`3 * (-4) = -12` 是负数。但如果我们知道前一个状态的最小乘积是 `-6`（`[-2, 3]` 的乘积），那么 `(-6) * (-4) = 24`，这才是正确答案！

> **核心洞察**：负数 × 负数 = 正数。当前最小值遇到负数，可能"逆袭"变成最大值。因此**必须同时维护最大值和最小值**。

---

## 三、核心思路推导

### 3.1 双状态定义

设：
- `maxF[i]` = **以 `nums[i]` 结尾**的连续子数组的**最大乘积**
- `minF[i]` = **以 `nums[i]` 结尾**的连续子数组的**最小乘积**

> 注意：这里的 dp 定义是"以 i 结尾"，不是"前 i 个中的最大值"。因为乘积具有连续性，必须知道以每个位置结尾的情况，最后再取全局最大。

### 3.2 状态转移分析

对于 `nums[i]`，以它结尾的连续子数组的最大乘积有**三种来源**：

| 来源 | 表达式 | 含义 | 什么时候最优 |
|------|--------|------|-------------|
| ① 只选自己 | `nums[i]` | 前面的乘积是负数，不如重新开始 | `nums[i]` 是正数，前面是负数 |
| ② 乘以前面最大 | `maxF[i-1] * nums[i]` | 前面是正数，越乘越大 | `nums[i]` 是正数，前面也是正数 |
| ③ 乘以前面最小 | `minF[i-1] * nums[i]` | 前面是负数，负数×负数=正数（逆袭） | `nums[i]` 是负数，前面也是负数 |

```
maxF[i] = max( nums[i], maxF[i-1] * nums[i], minF[i-1] * nums[i] )
minF[i] = min( nums[i], maxF[i-1] * nums[i], minF[i-1] * nums[i] )
```

**为什么最小值也要三种情况？**
- 如果 `nums[i]` 是正数，前面的最大值 × 正数 = 可能变得更大，但也可能成为新的最小值（如果前面最大是负数）
- 前面的最小值（负数）× 正数 = 更小的负数
- 所以最小值同样需要考虑三种来源

## 四、代码实现（C++）

### 4.1 清晰写法（推荐）

把三种候选先算出来，再用 C++11 的初始化列表取最大/最小：

```cpp
#include <vector>
#include <algorithm>

class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int n = nums.size();

        // 初始化：第一个元素既是最大也是最小
        int maxF = nums[0];
        int minF = nums[0];
        int ans = nums[0];   // 全局最大值

        for (int i = 1; i < n; i++) {
            // 必须先保存上一轮的最大/最小值！
            // 因为计算新的 maxF 和 minF 时，需要用到旧的值
            int mx = maxF, mn = minF;

            // 三种候选值
            int cand1 = nums[i];           // ① 只选自己，重新开始
            int cand2 = mx * nums[i];      // ② 乘以前面的最大值
            int cand3 = mn * nums[i];      // ③ 乘以前面的最小值（负数逆袭）

            // 状态转移：三种来源取最大/最小
            maxF = std::max({cand1, cand2, cand3});
            minF = std::min({cand1, cand2, cand3});

            // 更新全局最大值
            ans = std::max(ans, maxF);
        }

        return ans;
    }
};
```

### 4.2 为什么要先保存 `mx` 和 `mn`？

```cpp
// ❌ 错误写法：直接用 maxF 和 minF
maxF = max({nums[i], maxF * nums[i], minF * nums[i]});
minF = min({nums[i], maxF * nums[i], minF * nums[i]});
// 问题：计算 minF 时，maxF 已经在第一行被更新了！用的是新值而不是旧值

// ✅ 正确写法：先用临时变量保存旧值
int mx = maxF, mn = minF;
maxF = max({nums[i], mx * nums[i], mn * nums[i]});
minF = min({nums[i], mx * nums[i], mn * nums[i]});
```

> **关键**：计算 `minF` 时需要用到**旧的** `maxF`，但如果不先保存，`maxF` 在第一行已经被更新了。

### 4.3 嵌套 max 的等价写法

如果你不能用 C++11 的初始化列表，也可以写成嵌套形式（效果一样，但可读性稍差）：

```cpp
maxF = max(mx * nums[i], max(nums[i], mn * nums[i]));
minF = min(mn * nums[i], min(nums[i], mx * nums[i]));
```

**为什么有两层 `max()`？** 因为 C++ 的 `max(a, b)` 一次只能比较两个数。三个候选要先比两个，再和第三个比：

```
max(a, b, c)  →  max(a, max(b, c))
```

## 五、填表演示

### 5.1 示例 1：`nums = [2, 3, -2, 4]`

| i | nums[i] | mx(旧maxF) | mn(旧minF) | cand1 | cand2 | cand3 | maxF | minF | ans |
|---|---------|-----------|-----------|-------|-------|-------|------|------|-----|
| 0 | 2 | — | — | — | — | — | 2 | 2 | **2** |
| 1 | 3 | 2 | 2 | 3 | 6 | 6 | **6** | **3** | **6** |
| 2 | -2 | 6 | 3 | -2 | -12 | -6 | **-2** | **-12** | 6 |
| 3 | 4 | -2 | -12 | 4 | -8 | -48 | **4** | **-48** | **6** |

**结果**：`ans = 6` ✅（子数组 `[2, 3]`）

### 5.2 示例 2：`nums = [-2, 3, -4]`（展示负数逆袭）

| i | nums[i] | mx | mn | cand1 | cand2 | cand3 | maxF | minF | ans |
|---|---------|-----|-----|-------|-------|-------|------|------|-----|
| 0 | -2 | — | — | — | — | — | -2 | -2 | -2 |
| 1 | 3 | -2 | -2 | 3 | -6 | -6 | **3** | **-6** | **3** |
| 2 | -4 | 3 | -6 | -4 | -12 | **24** | **24** | **-12** | **24** |

**分析第 2 步（i=2, nums[i]=-4）**：
- `cand1 = -4`（只选自己）
- `cand2 = 3 * (-4) = -12`（乘以前面最大值）
- `cand3 = (-6) * (-4) = 24`（乘以前面最小值，负数逆袭！）

`maxF = max({-4, -12, 24}) = 24` ✅

> 注意：如果没有 `cand3`（即不维护最小值），只会得到 `max(-4, -12) = -4`，完全错误！

## 七、与 53. 最大子数组和的对比

| 维度 | 53. 最大子数组和 | 152. 乘积最大子数组 |
|------|-----------------|-------------------|
| **核心难点** | 负数会让和变小，直接舍弃 | 负数×负数=正数，可能逆袭 |
| **状态数** | 1 个（最大和） | **2 个**（最大乘积 + 最小乘积） |
| **转移方程** | `dp[i] = max(num, dp[i-1]+num)` | `maxF = max({cand1, cand2, cand3})` |
| **空间优化** | 滚动变量 O(1) | 滚动变量 O(1) |
| **关键区别** | 加法单调，遇到负数直接断 | 乘法不单调，最小值可能变最大 |

## 八、踩过的坑（真实案例）

### ❌ 坑：minF 的候选写错，漏了 lastMax

```cpp
// ❌ 错误代码（真实踩坑）
minF = min({nums[i], lastMin * nums[i], lastMin * nums[i]});
//                           ↑ 这里应该是 lastMax！

// 问题：两个候选都是 lastMin * nums[i]，漏掉了 lastMax * nums[i]
```

**后果**：
- 当 `lastMax * nums[i]` 是一个很小的负数时（比如 `lastMax` 是很大的正数，`nums[i]` 是负数），代码会漏掉这个真正的最小值
- `minF` 计算错误 → 下一轮迭代中"负数逆袭"不正确 → 最终答案可能出错

**反例验证**：`nums = [3, -1, -4]`

| i | nums[i] | lastMax | lastMin | 错误 minF（漏了 lastMax） | 正确 minF |
|---|---------|---------|---------|------------------------|-----------|
| 0 | 3 | — | — | — | — |
| 1 | -1 | 3 | 3 | `min(-1, -3, -3) = -3` | `min(-1, -3, -3) = -3` |
| 2 | -4 | 3 | -3 | `min(-4, 12, 12) = -4` ❌ | `min(-4, -12, 12) = -12` ✅ |

第 2 步：
- **错误**：`cand2 = lastMin * (-4) = (-3) * (-4) = 12`，漏了 `lastMax * (-4) = 3 * (-4) = -12`
- 错误结果：`minF = -4`，下一轮 `maxF = max({-4, ...})` 无法正确逆袭
- **正确**：`minF = -12`，下一轮 `maxF = max({..., (-12)*下一个数})` 才能正确逆袭

```cpp
// ✅ 正确写法
minF = min({nums[i], lastMax * nums[i], lastMin * nums[i]});
// maxF 和 minF 的三种候选是同一组，只是取 max/min 不同
```

> 💡 **记忆口诀**：`maxF` 和 `minF` 的三种候选**一模一样**，都是 `{自己, 乘以前面最大, 乘以前面最小}`，区别只是外层用 `max` 还是 `min`。

## 九、常见错误

### ❌ 错误 1：只维护一个 dp 状态
```cpp
// ❌ 错误：只维护最大值
maxF = max(nums[i], maxF * nums[i]);
// 遇到负数时，前面的最小值（负数）× 负数 = 正数，这个信息丢失了！
```

### ❌ 错误 2：没有临时变量保存旧值
```cpp
// ❌ 错误：maxF 先被更新，导致 minF 计算时用了新值
maxF = max({nums[i], maxF * nums[i], minF * nums[i]});
minF = min({nums[i], maxF * nums[i], minF * nums[i]});  
// 这里的 maxF 已经是新的了！
```

### ❌ 错误 3：忘记更新全局最大值
```cpp
// ❌ 错误：只返回最后一个 maxF
return maxF;
// 问题：最大乘积子数组不一定以最后一个元素结尾

// ✅ 正确：遍历过程中不断更新全局最大值
ans = max(ans, maxF);
return ans;
```

### ❌ 错误 4：三种候选漏了"只选自己"
```cpp
// ❌ 错误：漏了 nums[i]
maxF = max(mx * nums[i], mn * nums[i]);
// 问题：如果前面乘积是负数，不如从当前元素重新开始

// ✅ 正确：三种都要考虑
maxF = max({nums[i], mx * nums[i], mn * nums[i]});
```

### ❌ 错误 5：minF 的候选写错（见第八节）
```cpp
// ❌ 错误：minF 的两个候选都是 lastMin
minF = min({nums[i], lastMin * nums[i], lastMin * nums[i]});

// ✅ 正确：三种候选和 maxF 一样
minF = min({nums[i], lastMax * nums[i], lastMin * nums[i]});
```

## 十、思路总结

```
┌─────────────────────────────────────────────────────────────┐
│                     动态规划四步法                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 定义状态（双状态！）                                    │
│     maxF = 以当前元素结尾的连续子数组的最大乘积             │
│     minF = 以当前元素结尾的连续子数组的最小乘积             │
│                                                             │
│  2. 找状态转移                                              │
│     当前元素 nums[i] 有三种选择：                           │
│     • cand1 = nums[i]              （只选自己）            │
│     • cand2 = maxF_old * nums[i]   （乘以前面最大）        │
│     • cand3 = minF_old * nums[i]   （乘以前面最小，逆袭）  │
│                                                             │
│     maxF = max({cand1, cand2, cand3})                     │
│     minF = min({cand1, cand2, cand3})   ← 候选和maxF一样 │
│                                                             │
│  3. 确定边界                                                │
│     maxF = minF = ans = nums[0]                           │
│                                                             │
│  4. 遍历顺序                                                │
│     从左到右，一次遍历。注意先保存旧值再更新！              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 十一、一句话总结

> **乘法不像加法那么"老实"——负数遇到负数会翻盘。所以必须同时盯着最大值和最小值，因为今天的最小值，明天乘个负数就可能变成最大值。**

```cpp
// 核心代码（清晰写法）
int mx = maxF, mn = minF;
int cand1 = nums[i];
int cand2 = mx * nums[i];
int cand3 = mn * nums[i];
maxF = max({cand1, cand2, cand3});
minF = min({cand1, cand2, cand3});   // ← 候选和 maxF 一模一样！
ans = max(ans, maxF);
```
