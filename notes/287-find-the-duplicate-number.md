# 力扣 287. 寻找重复数 — 学习笔记

## 一、题目概述

给定一个包含 `n + 1` 个整数的数组 `nums`，其数字都在 `[1, n]` 范围内（包含边界），**假设只有一个重复的整数**，返回这个重复的数。

> **关键约束**：
> - 数组长度 = `n + 1`，取值范围 = `[1, n]`
> - 根据**鸽巢原理**，至少有一个数是重复的
> - **不能更改原数组**（假设数组是只读的）
> - 只能使用额外的 $O(1)$ 的空间（如果追求最优解）

---

## 二、哈希表解法（你提供的代码）

### 核心思想

利用哈希集合记录已经出现过的数字，如果遇到已经存在的数字，即为重复数。

### 代码分析

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        unordered_set<int> set;
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            // 如果当前数字已经在集合中，说明是重复数
            if (set.count(nums[i])) {
                return nums[i];
            }
            // 否则加入集合
            set.insert(nums[i]);
        }
        return -1;  // 理论上不会执行到这里
    }
};
```

### 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| **时间复杂度** | $O(n)$ | 一次线性遍历 |
| **空间复杂度** | $O(n)$ | 哈希集合最多存储 $n$ 个元素 |
| **是否修改原数组** | ❌ 否 | 只读遍历 |

### 优缺点

- ✅ 思路直观，代码简洁，容易理解
- ❌ 需要 $O(n)$ 额外空间，不符合题目对空间优化的要求

## 三、最优解法：Floyd 判圈算法（快慢指针）

### 核心思想

将数组看作一个**链表**：
- 数组下标 `i` 看作节点 `i`
- `nums[i]` 看作从节点 `i` 指向的下一个节点

由于数字范围是 `[1, n]`，而数组长度是 `n + 1`，根据鸽巢原理，至少有一个数字出现两次。这意味着链表一定存在**环**，而环的入口就是**重复的数字**。

### 为什么可以看作链表？

以 `nums = [1, 3, 4, 2, 2]` 为例：

```
下标:  0    1    2    3    4
数值:  1    3    4    2    2

链表结构：0 → 1 → 3 → 2 → 4 → 2 → 4 → 2 → ...
                              ↑___________|
```

- 从 `0` 出发：`nums[0] = 1`，走到 `1`
- `nums[1] = 3`，走到 `3`
- `nums[3] = 2`，走到 `2`
- `nums[2] = 4`，走到 `4`
- `nums[4] = 2`，走到 `2`（已经来过！）

节点 `2` 就是环的入口，也是重复的数字。

### 代码实现

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        // ========== 第一阶段：快慢指针找相遇点 ==========
        // slow 每次走 1 步，fast 每次走 2 步
        int slow = nums[0];
        int fast = nums[nums[0]];

        while (slow != fast) {
            slow = nums[slow];        // 慢指针走一步
            fast = nums[nums[fast]];  // 快指针走两步
        }

        // ========== 第二阶段：找环的入口（重复数） ==========
        // 相遇后，让一个新指针从起点出发，和 slow 同步前进
        // 两者相遇的位置就是环的入口
        int ptr = 0;
        while (ptr != slow) {
            ptr = nums[ptr];
            slow = nums[slow];
        }

        return ptr;  // 环的入口即为重复数
    }
};
```

### 复杂度分析

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| **时间复杂度** | $O(n)$ | 快慢指针在环内相遇，第二阶段再遍历一次 |
| **空间复杂度** | $O(1)$ | 仅使用三个指针变量 |
| **是否修改原数组** | ❌ 否 | 只读访问 |

### 为什么第二阶段能找到环入口？

设：
- 起点到环入口的距离为 `a`
- 环入口到相遇点的距离为 `b`
- 相遇点回到环入口的距离为 `c`

快慢指针相遇时：
- 慢指针走了 `a + b` 的距离
- 快指针走了 `a + b + k(b + c)` 的距离（`k` 为绕环圈数）
- 因为快指针速度是慢指针的 2 倍：`2(a + b) = a + b + k(b + c)`
- 化简得：`a = (k - 1)(b + c) + c`

这意味着：**从起点走 `a` 步 = 从相遇点走 `c` 步 + 若干整圈**。所以让一个新指针从起点出发，和慢指针同步前进，它们一定会在环入口相遇。

## 四、其他解法对比

### 方法一：排序

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] == nums[i - 1]) {
                return nums[i];
            }
        }
        return -1;
    }
};
```

- **时间**：$O(n \log n)$ | **空间**：$O(\log n)$（排序栈空间）
- ✅ 代码极简
- ❌ **修改了原数组**；时间复杂度非最优

---

### 方法二：二分查找（值域二分）

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int left = 1, right = nums.size() - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;

            // 统计数组中小于等于 mid 的数字个数
            int count = 0;
            for (int num : nums) {
                if (num <= mid) count++;
            }

            // 如果 count > mid，说明重复数在 [left, mid] 中
            // 因为如果没有重复，[1, mid] 最多只有 mid 个数
            if (count > mid) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }
};
```

- **时间**：$O(n \log n)$ | **空间**：$O(1)$
- ✅ 不修改原数组，空间 $O(1)$
- ❌ 时间复杂度不如 Floyd 算法

> 原理：对**值域** `[1, n]` 进行二分。如果数组中 `<= mid` 的数超过 `mid` 个，说明重复数在左半区间。

---

### 方法三：数组标记（修改原数组）

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        for (int i = 0; i < nums.size(); i++) {
            int index = abs(nums[i]);
            if (nums[index] < 0) {
                return index;  // 已经被标记过，是重复数
            }
            nums[index] = -nums[index];  // 标记为负数
        }
        return -1;
    }
};
```

- **时间**：$O(n)$ | **空间**：$O(1)$
- ✅ 时间和空间都最优
- ❌ **修改了原数组**，不符合题目"只读"要求

> 原理：利用数组下标作为"哈希表"。遍历到数字 `x` 时，将 `nums[x]` 标记为负数。如果下次再遇到 `x`，发现 `nums[x]` 已经是负数，说明 `x` 是重复的。

## 五、解法对比总结

| 解法 | 时间复杂度 | 空间复杂度 | 是否修改原数组 | 核心思想 |
|------|-----------|-----------|---------------|---------|
| **Floyd 判圈（最优）** | $O(n)$ | $O(1)$ | ❌ 否 | 数组看作链表，找环入口 |
| 哈希表（你的解法） | $O(n)$ | $O(n)$ | ❌ 否 | 集合记录已出现数字 |
| 排序 | $O(n \log n)$ | $O(\log n)$ | ✅ 是 | 排序后相邻比较 |
| 二分查找 | $O(n \log n)$ | $O(1)$ | ❌ 否 | 值域二分 + 计数 |
| 数组标记 | $O(n)$ | $O(1)$ | ✅ 是 | 下标作为哈希表标记 |

---

## 六、关键收获

1. **Floyd 判圈算法是这道题的精髓**。将数组抽象为链表，把"找重复数"转化为"找环入口"，是算法思维的典范。
2. **鸽巢原理是存在性保证**。`n + 1` 个数字放在 `[1, n]` 范围内，必然有重复，这是所有解法的前提。
3. **哈希表解法虽然直观，但空间不是最优**。面试时如果要求 $O(1)$ 空间，必须能写出 Floyd 算法。
4. **二分查找的另一种思路**：不是对数组下标二分，而是对**值域**二分，这种"值域二分"技巧在很多题目中都有应用。
5. **数组标记法**展示了如何利用数组本身作为哈希表，虽然这道题不允许修改数组，但这种技巧在其他题目中非常有用。
