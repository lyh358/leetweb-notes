## 二、核心思路（四步法）

### Step 1：定义状态

```cpp
dp[i] = 凑出金额 i 所需的最少硬币个数
```

### Step 2：找状态转移

凑出金额 `i` 的最后一步，一定是**放了一枚硬币** `coins[j]`。

那么在这枚硬币之前，已经凑出了 `i - coins[j]` 元。

```
dp[i] = min( dp[i - coins[j]] + 1 )    对所有满足 coins[j] <= i 的 j
         ↑凑出上一个金额   ↑加上当前这枚
```

### Step 3：确定边界

```cpp
dp[0] = 0;              // 凑 0 元，不需要任何硬币
dp[1..amount] = 极大值;  // 初始假设"凑不出"，后续用 min 更新
```

### Step 4：遍历顺序

- 外层从小到大遍历金额 `i`（确保小金额先算出来，大金额依赖小金额）
- 内层遍历所有硬币面额
- 这是**完全背包**问题，正序遍历即可

## 三、踩过的三个坑

### ❌ 坑 1：INT_MAX + 1 溢出

```cpp
// ❌ 错误写法
vector<int> dp(amount + 1, INT_MAX);  // 2147483647
dp[i] = min(dp[i], dp[i - coins[j]] + 1);  // INT_MAX + 1 = 溢出！
```

**报错**：`runtime error: signed integer overflow: 2147483647 + 1 cannot be represented in type 'int'`

**原因**：当某个金额暂时凑不出时，`dp[i-coins[j]]` 保持为 `INT_MAX`。此时 `INT_MAX + 1` 超出 `int` 范围，变成负数，然后 `min(正数, 负数)` 会错误地选到负数，导致后续全部计算错乱。

**修复**：
```cpp
// ✅ 方案一：用 1e6 代替 INT_MAX（足够大，+1 不会溢出）
vector<int> dp(amount + 1, 1e6);

// ✅ 方案二：保留 INT_MAX，但加 1 前先判断
if (dp[i - coins[j]] != INT_MAX) {
    dp[i] = min(dp[i], dp[i - coins[j]] + 1);
}
```

> 💡 **经验**：DP 求最小值时，如果状态转移涉及 `+1`，要么不用 `INT_MAX`，要么加之前先判断。

---

### ❌ 坑 2：去掉 `if (coins[j] <= i)` 导致数组越界

```cpp
// ❌ 错误写法（去掉了条件判断）
for (int j = 0; j < coins.size(); j++) {
    dp[i] = min(dp[i], dp[i - coins[j]] + 1);  // coins[j] 可能大于 i！
}
```

**报错**：数组越界访问（`i - coins[j]` 为负数）

**原因**：比如 `coins = [5]`，`i = 3` 时，`i - 5 = -2`，访问 `dp[-2]` 是非法的。

**修复**：
```cpp
// ✅ 必须保留判断：只有硬币面额不超过当前金额，才能转移
if (coins[j] <= i) {
    dp[i] = min(dp[i], dp[i - coins[j]] + 1);
}
```

> 💡 **经验**：背包 DP 中，`dp[i - weight]` 必须保证 `i >= weight`，否则数组越界。

---

### ❌ 坑 3：返回判断不够直观

```cpp
// 你的写法（正确但不够通用）
return dp[amount] > amount ? -1 : dp[amount];

// 更标准的写法（语义更清晰）
return dp[amount] == 1e6 ? -1 : dp[amount];
// 或
return dp[amount] == INT_MAX ? -1 : dp[amount];  // 如果用 INT_MAX 的话
```

**两种写法的区别**：
- `dp[amount] > amount`：利用了"最小硬币是 1，最多只需要 amount 枚"的数学性质，正确但依赖题意。
- `dp[amount] == 初始值`：直接判断"是否从未被更新过"，更通用，适用于所有类似问题。

> 💡 **经验**：返回判断建议用 `== 初始值`，语义最清晰，不依赖题目特殊条件。

## 六、与 279. 完全平方数的对比

| 维度 | 322. 零钱兑换 | 279. 完全平方数 |
|------|-------------|---------------|
| **问题类型** | 完全背包（最少数量） | 完全背包（最少数量） |
| "物品"集合 | `coins` 数组（给定） | `1, 4, 9, 16...`（自动生成） |
| 状态转移 | `dp[i] = min(dp[i-coin]+1)` | `f[i] = min(f[i-j*j]+1)` |
| 初始化 | `dp[0]=0`，其余极大值 | `f[0]=0`，其余极大值 |
| **核心思想** | **完全相同**：都是"凑目标值的最少元素个数" |

> 💡 **本质相同**：322 和 279 是同一类题，只是"可选的元素"不同。掌握一个就等于掌握两个。

## 七、一句话总结

> **凑出金额 `i` 的最少硬币数 = 所有"凑出 i-coin 的最少硬币数 + 1"中的最小值。**

```
dp[i] = min( dp[i - coin₁] + 1,
             dp[i - coin₂] + 1,
             dp[i - coin₃] + 1,
             ... )
```

**三个防坑要点**：
1. ✅ 初始化用 `1e6` 或判断后再 `+1`，避免 `INT_MAX` 溢出
2. ✅ 保留 `if (coins[j] <= i)`，防止数组越界
3. ✅ 返回时判断 `dp[amount]` 是否还是初始值，凑不出返回 `-1`
