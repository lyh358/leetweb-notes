# 3.无重复字符的最长子串

# 题目描述

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串** 的长度。

**示例 1:**

```
输入: s = "abcabcbb"
输出: 3 
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。
```

**示例 2:**

```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3:**

```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。
```

**提示：**

- `0 <= s.length <= 5 * 104`
- `s` 由英文字母、数字、符号和空格组成

# 核心思路：ASCII码数组+滑动窗口（左指针跳转，右指针遍历）

![图片.png](https://pic.leetcode.cn/8b7cac826e572c65f8b77e0f380eaa93ab665857a8e916bc4ea36b7765eafc55-%E5%9B%BE%E7%89%87.png)

## 滑动窗口：两个指针夹着一个窗口

- ### 左指针：head=0（跳转）

- ### 右指针：i=0（遍历）

```plain
字符串:  a b c a b c b b
         ↑
         head(左边界)
           ↑
           i(右边界，正在遍历)
```

**规则**：窗口内不能有重复字符。当`i`发现字符已经在窗口里出现过，就把`head`向右跳到重复字符的**下一个位置**，把那个重复字符"踢出"窗口。

------

## 关键难点：创建一个桶`vector<int>(128,0)`

## 那个"桶"到底存了什么？

```cpp
vector<int> m(128, 0);
```

- #### 初始化存的是128个0，下标对应ASCII码0~127的字符，值是下次遇到这个字符应该跳转到的位置（i+1）

- #### **作用：**"如果又遇到这个字符，左边界应该跳到哪里"**（也就是上次出现位置+1）

| 字符             | 桶里存的值 | 含义                           |
| :--------------- | :--------- | :----------------------------- |
| 'a'              | 0          | 还没出现过，左边界不用动       |
| 遇到'a'在位置0后 | 1          | 下次再见到'a'，左边界至少得到1 |

---

## 左指针跳转

- #### 一句话真相：m[]存的是位置

- #### 左边界跳不跳转，**不是看是不是0**，而是看**桶里的值是否大于当前head**。

  > **这次跳到哪 = 看桶里存的上次位置+1**
  > **存什么给下次 = 当前位置i+1**

```c++
for (int i = 0; i < s.size(); i++) 
{
    //判断左边界是否更新
	head = max(head,m[s[i]);
    //标记下一次遇到s[i]这个字符，左边界应该跳转到的位置
    m[s[i]] = i + 1;
    //更新最大值
    maxlen = max(maxlen, i - head + 1);
}
//返回最大值
return maxlen;
```

# 完整代码

```c++
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        // 创建桶(数组)，设定128个下标对应0-127ASCII码值
        // 每格都存对应字符的后一个位置，比如a的位置是i，那么数组里就存i+1
        // 用来在又碰见这个字符的时候把左边界直接更新到前一个该字符的下一个位置
        vector<int> m(128, 0);//m[s[i]]是下次右边界遇到重复字符s[i]时左边界head应该收缩到位置
        //存最大长度
        int maxlen = 0;
        //head表示窗口左边界位置
        int head = 0;
        //遍历字符串
        for (int i = 0; i < s.size(); i++) {
            //修改左边界，每次选最大的就相当于更新了
            head = max(head, m[s[i]]);
            //当前字母对应的ASCII码桶里存下一个位置(i+1)，用于更新左边界
            m[s[i]] = i + 1;
            //更新长度
            maxlen = max(maxlen, i - head + 1);
        }
        return maxlen;
    }
};
```

## 完整思路：

#### 1.创建桶数组` vector<int> m(128, 0);`

#### 2.初始化最大长度`maxlen=0`和左边界`head=0`

#### 3.`for`循环遍历右边界

#### 4先判断左边界是否跳转`head = max(head, m[s[i]]);`，在更新下一次遇到当前字符s[i]时左边界的跳转位置`m[s[i]] = i + 1;`

#### 5.更新当前长度` maxlen = max(maxlen, i - head + 1);`

#### 6.循环结束输出当前`maxlen`
