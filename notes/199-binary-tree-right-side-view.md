## 二、核心原理

> **站在右边看，每层只能看到最右边的那个节点。**
>
> 因此，问题转化为：**层序遍历，取每层的最后一个元素。**

```
第 1 层：[1]        → 取最后一个：1
第 2 层：[2, 3]     → 取最后一个：3
第 3 层：[5, 4]     → 取最后一个：4

结果：[1, 3, 4]
```

---

## 三、完整代码（含详细注释）

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        // 空树特判：直接返回空数组
        if(!root) return {};

        vector<int> ans;          // 答案数组：存储每层最右边的节点值
        queue<TreeNode*> q;       // 标准队列，用于 BFS 层序遍历
        q.push(root);             // 根节点入队，启动遍历

        // 当队列不为空时，继续遍历下一层
        while(!q.empty())
        {
            vector<int> vals;     // 收集当前层所有节点的值

            // 关键：i = q.size() 在循环开始前确定当前层的节点数量
            // 这样 for 循环只处理当前层的节点，不会混入下一层
            for(int i = q.size(); i--;)
            {
                TreeNode* node = q.front();  // 取出队首节点
                q.pop();                     // 出队
                vals.push_back(node->val);   // 记录当前节点的值

                // 将左右子节点入队，为下一层遍历做准备
                if(node->left)  q.push(node->left);
                if(node->right) q.push(node->right);
            }

            // 当前层遍历完毕，vals.back() 就是这一层最右边的节点
            ans.push_back(vals.back());
        }

        return ans;
    }
};
```

## 四、逐行代码解析

### 4.1 空树特判

```cpp
if(!root) return {};
```

空树没有节点，自然也没有右视图，返回空数组。

### 4.2 初始化队列

```cpp
vector<int> ans;
queue<TreeNode*> q;
q.push(root);
```

- `ans`：存储最终结果
- `q`：BFS 标准队列，FIFO（先进先出）
- 根节点入队，作为第 1 层的起点

### 4.3 外层 while 循环

```cpp
while(!q.empty())
```

只要队列中还有节点，就说明还有层没有遍历完，继续循环。

### 4.4 内层 for 循环（核心！）

```cpp
for(int i = q.size(); i--;)
```

这是层序遍历的**灵魂技巧**：
- `q.size()` 在 for 循环**开始前**就确定了当前层的节点数量
- `i--` 是后置递减，先判断后减，等价于 `for(int i = q.size(); i > 0; i--)`
- 这样 for 循环**只处理当前层的节点**，不会把下一层刚入队的节点也处理掉

### 4.5 节点出队与记录

```cpp
TreeNode* node = q.front();
q.pop();
vals.push_back(node->val);
```

取出队首节点，记录它的值到 `vals` 中。

### 4.6 子节点入队

```cpp
if(node->left)  q.push(node->left);
if(node->right) q.push(node->right);
```

将当前节点的左右子节点入队。**注意：先左后右**，这样同一层的节点在队列中的顺序就是从左到右。

### 4.7 取每层最后一个

```cpp
ans.push_back(vals.back());
```

`vals` 按从左到右的顺序收集了当前层所有节点的值，`vals.back()` 就是**最右边**的那个节点，也就是右视图中能看到的节点。

## 五、执行流程图解

以如下二叉树为例：

```
        1
       / \
      2   3
       \   \
        5   4
```

### 第 1 层

```
初始化：q = [1]

for i = q.size() = 1; i--;
  i = 1: node = 1, q.pop() → q = []
         vals = [1]
         左子 2 入队 → q = [2]
         右子 3 入队 → q = [2, 3]

vals = [1]
ans.push_back(vals.back()) → ans = [1]
```

### 第 2 层

```
当前：q = [2, 3]

for i = q.size() = 2; i--;
  i = 2: node = 2, q.pop() → q = [3]
         vals = [2]
         左子 null，不入队
         右子 5 入队 → q = [3, 5]

  i = 1: node = 3, q.pop() → q = [5]
         vals = [2, 3]
         左子 null，不入队
         右子 4 入队 → q = [5, 4]

vals = [2, 3]
ans.push_back(vals.back()) → ans = [1, 3]
```

### 第 3 层

```
当前：q = [5, 4]

for i = q.size() = 2; i--;
  i = 2: node = 5, q.pop() → q = [4]
         vals = [5]
         左右子都为空，不入队

  i = 1: node = 4, q.pop() → q = []
         vals = [5, 4]
         左右子都为空，不入队

vals = [5, 4]
ans.push_back(vals.back()) → ans = [1, 3, 4]
```

### 结束

```
q 为空，while 循环结束

最终结果：ans = [1, 3, 4] ✅
```

## 六、为什么 `vals.back()` 就是最右边的节点？

### 关键原因：BFS 的入队顺序

BFS 使用队列（FIFO），处理节点的顺序是：
1. 先处理父节点
2. 父节点的左子节点先入队
3. 父节点的右子节点后入队

因此，**同一层的节点在队列中的顺序就是从左到右**：

```
第 2 层：父节点 1 处理完后
        左子 2 先入队 → 右子 3 后入队
        q = [2, 3]  ← 2 在左，3 在右

第 3 层：父节点 2 处理完后，5 入队
        父节点 3 处理完后，4 入队
        q = [5, 4]  ← 5 在左，4 在右
```

`vals` 按这个顺序收集，所以 `vals.back()` 永远是该层**最右边**的节点。

## 七、复杂度分析

| 复杂度 | 值 | 说明 |
|--------|------|------|
| **时间** | $O(n)$ | 每个节点恰好访问一次 |
| **空间** | $O(w)$ | $w$ 为树的最大宽度，即最宽一层的节点数。队列最多同时存储一层的节点 |

> 最坏情况下（完全二叉树最底层），$w = n/2$，空间复杂度为 $O(n)$。

## 八、另一种解法：DFS（对比学习）

### 8.1 核心思路

DFS 按照 **根 → 右 → 左** 的顺序遍历，**每一层第一个访问到的节点**就是右视图中能看到的节点。

```cpp
class Solution {
public:
    vector<int> ans;

    void dfs(TreeNode* root, int depth) {
        if(!root) return;

        // 如果这是该层第一个访问的节点，记录它
        if(depth == ans.size()) {
            ans.push_back(root->val);
        }

        // 先递归右子树！确保每层先访问最右边的节点
        dfs(root->right, depth + 1);
        dfs(root->left, depth + 1);
    }

    vector<int> rightSideView(TreeNode* root) {
        dfs(root, 0);
        return ans;
    }
};
```

### 8.2 为什么先递归右子树？

```
        1
       / \
      2   3
       \   \
        5   4

DFS(根→右→左) 访问顺序：
  1 (depth=0, 第1层第一个 → 记录)
  3 (depth=1, 第2层第一个 → 记录)
  4 (depth=2, 第3层第一个 → 记录)
  5 (depth=2, 第3层已记录，跳过)
  2 (depth=1, 第2层已记录，跳过)

结果：[1, 3, 4] ✅
```

### 8.3 BFS vs DFS 对比

| 对比项 | BFS（你的解法） | DFS（替代解法） |
|--------|---------------|---------------|
| **核心思想** | 层序遍历，取每层最后一个 | 根→右→左，取每层第一个 |
| **数据结构** | 队列（Queue） | 递归栈 |
| **空间复杂度** | $O(w)$，最宽一层 | $O(h)$，树的高度 |
| **代码量** | 稍多 | 更简洁 |
| **直观度** | 非常直观，"站在右边看" | 需要理解"每层第一个" |
| **推荐场景** | 面试稳妥，易解释 | 代码简洁，适合快速手写 |

## 九、易错点总结

| 坑点 | 说明 |
|------|------|
| ❌ `for` 循环写成 `i < q.size()` | `q.size()` 在循环中会变化（子节点入队），必须用 `int i = q.size()` 先固定 |
| ❌ 忘记空树特判 | `if(!root) return {};` 必须写 |
| ❌ 子节点入队顺序错误 | 必须先 `left` 后 `right`，这样 `vals` 才是从左到右的顺序，`back()` 才是最右 |
| ❌ 用 `vals.front()` | 取的是最左边的节点，不是右视图 |
| ❌ DFS 版先递归左子树 | 必须先右后左，否则先访问到的是左边的节点 |

## 十一、一句话总结

> **右视图 = 层序遍历取每层最后一个。** BFS 用队列保证从左到右的顺序，`vals.back()` 天然就是最右节点。`for(int i = q.size(); i--)` 是层序遍历的灵魂，先固定当前层数量再处理，避免层与层混在一起。DFS 版则反过来，先走右子树，每层第一个访问到的就是答案。
