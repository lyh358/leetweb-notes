# LeetCode 142 - 环形链表 II（Linked List Cycle II）

> **标签**：链表、双指针、哈希表  
> **难度**：中等  
> **核心考点**：Floyd 判圈算法找环入口

---

## 一、题目描述

给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回 `null`。

**不允许修改**链表。

**示例**：
```
输入: head = [3, 2, 0, -4], pos = 1
输出: 返回索引为 1 的节点（值为 2 的节点）
解释: 链表中有一个环，其尾部连接到第二个节点

输入: head = [1, 2], pos = 0
输出: 返回索引为 0 的节点（值为 1 的节点）

输入: head = [1], pos = -1
输出: 返回 null（无环）
```

---

## 二、核心思路

### 2.1 两种方法

| 方法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 哈希表法 | O(n) | O(n) | 遍历存入集合，第一个重复的就是入口 |
| 快慢指针法 ⭐ | O(n) | O(1) | Floyd 判圈，数学推导找入口 |

### 2.2 快慢指针法原理

**第一步**：判断是否有环（同 LC 141）
- 快慢指针相遇，说明有环

**第二步**：找环入口

```
假设:
- 头节点到环入口距离: a
- 环入口到相遇点距离: b
- 相遇点回到环入口距离: c

慢指针走的距离: a + b
快指针走的距离: a + b + n(b + c) = 2(a + b)  （快是慢的2倍）

推导:
a + b + n(b + c) = 2a + 2b
n(b + c) = a + b
a = n(b + c) - b
a = (n-1)(b + c) + c

当 n = 1 时（最常见）:
a = c

结论：
- 一个指针从 head 出发走 a
- 一个指针从相遇点出发走 c
- 两者会在环入口相遇！
```

## 三、代码实现

### 3.1 哈希表法（你的代码）

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        unordered_set<ListNode*> uset;
        ListNode* cur = head;

        while (cur != nullptr) {
            // 如果当前节点已经在集合中，说明是环入口
            if (uset.count(cur)) {
                return cur;
            }
            // 存入集合，继续遍历
            uset.insert(cur);
            cur = cur->next;
        }

        // 遍历到末尾，无环
        return nullptr;
    }
};
```

### 3.2 快慢指针法 ⭐ 最优

```cpp
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;

        // 第一步：判断是否有环，找到相遇点
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;          // 慢指针走1步
            fast = fast->next->next;    // 快指针走2步

            if (slow == fast) {         // 相遇，有环
                break;
            }
        }

        // 快指针到达末尾，无环
        if (fast == nullptr || fast->next == nullptr) {
            return nullptr;
        }

        // 第二步：找环入口
        // 一个指针回到头，两个指针同步走，再次相遇即入口
        ListNode* ptr = head;
        while (ptr != slow) {
            ptr = ptr->next;
            slow = slow->next;
        }

        return ptr;  // 环入口
    }
};
```

## 四、执行流程可视化

### 哈希表法

```
链表: 3 → 2 → 0 → -4
          ↑_________|

步骤1: 遍历链表，存入集合
  3: 不在集合，存入
  2: 不在集合，存入
  0: 不在集合，存入
  -4: 不在集合，存入
  2: 在集合中！返回 2

结果: 返回值为 2 的节点
```

### 快慢指针法

```
链表: 3 → 2 → 0 → -4
          ↑_________|

步骤1: 找相遇点
  初始: slow=3, fast=3

  轮次1: slow=2, fast=0
  轮次2: slow=0, fast=2
  轮次3: slow=-4, fast=-4  ← 相遇！

步骤2: 找入口
  ptr = head = 3
  slow = -4

  轮次1: ptr=2, slow=2  ← 相遇！

返回: 2（环入口）
```

| 哈希表法 | **O(n)** | **O(n)** | 需要存储所有节点 |
| 快慢指针法 | **O(n)** | **O(1)** | ⭐ 最优 |

## 六、易错点 & 注意

| 坑点 | 说明 |
|------|------|
| **第一步终止条件** | `fast != nullptr && fast->next != nullptr`，和 LC 141 一样 |
| **判断无环** | 第一步结束后必须判断 `fast` 是否为 `nullptr`，不能省略 |
| **找入口的同步走** | `ptr` 从 `head` 出发，`slow` 从相遇点出发，**都走1步** |
| **不要修改链表** | 题目要求不能修改，快慢指针法满足要求 |
