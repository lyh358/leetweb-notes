# BFS

广度优先搜索（BFS, Breadth-First Search）是一种**逐层扩散**的搜索算法，像水波纹一样从起点向外一圈圈蔓延。

------

## 核心思想：先近后远

```plain
起点 → 邻居 → 邻居的邻居 → 邻居的邻居的邻居...
 第0层    第1层      第2层           第3层
```

**保证**：找到的路径一定是**最短路径**（边权相同的情况下）

------

## 经典类比：病毒传染

```plain
Day 0: 你感染了（起点）
Day 1: 你传染了同桌、室友（距离1）
Day 2: 同桌传染了他们的朋友（距离2）
Day 3: 继续扩散...
```

**先被感染的一定是距离近的人！**

------

## 代码模板（背这个）

```cpp
#include <queue>
#include <vector>
#include <unordered_set>

int bfs(起点, 目标) {
    queue<节点> q;           // 核心：队列，保证先近后远
    unordered_set<节点> visited;  // 防重复访问
    
    q.push(起点);
    visited.insert(起点);
    int step = 0;            // 记录当前层数（距离）
    
    while (!q.empty()) {
        int size = q.size(); // 当前层的节点数
        
        for (int i = 0; i < size; i++) {  // 逐层处理！
            auto cur = q.front(); q.pop();
            
            if (cur == 目标) return step;  // 找到了！
            
            // 把邻居加入队列
            for (auto neighbor : cur的邻居们) {
                if (!visited.count(neighbor)) {
                    q.push(neighbor);
                    visited.insert(neighbor);
                }
            }
        }
        step++;  // 一层处理完，距离+1
    }
    return -1;  // 没找到
}
```

## 可视化：迷宫找最短路径

```plain
# # # # # # #
# S . . # . E    S=起点, E=终点, .=路, #=墙
# . # . # . #
# . . . . . #
# # # # # # #

BFS扩散顺序（数字=第几轮访问）：
# # # # # # #
# 0 1 2 # . E    第0轮：S
# 1 # 3 # . #    第1轮：S的邻居
# 2 3 4 5 6 #    第2轮：距离为2的点...
# # # # # # #    ...

第6轮到达E，最短路径长度=6
```

## BFS vs DFS

|                | BFS                    | DFS                      |
| :------------- | :--------------------- | :----------------------- |
| **数据结构**   | ==队列（Queue）==      | ==栈（Stack）或递归==    |
| **搜索顺序**   | ==一层层向外==         | ==一条路走到底==         |
| **最短路径**   | ==✅ 保证最短==         | ==❌ 不保证==             |
| **空间复杂度** | 高（存整层节点）       | 低（只存一条路径）       |
| **适用场景**   | ==最短路径、最少步数== | ==所有路径、连通性判断== |

------

## 经典应用场景

| 题目类型 | 例子             |
| :------- | :--------------- |
| 最短路径 | 迷宫、地图导航   |
| 最少步数 | 密码锁、单词接龙 |
| 层级遍历 | 树的层序遍历     |
| 拓扑排序 | 课程表、任务调度 |
| 连通块   | 岛屿数量、朋友圈 |

------

## 一句话总结

> **BFS = 队列 + 逐层扩散 + 先遇到的目标一定最近**

像雷达扫描，一圈圈往外找，第一次扫到就是最优解！
