# LeetCode 189. 轮转数组 —— 三种解法学习笔记

> **题目**: [189. Rotate Array](https://leetcode.cn/problems/rotate-array/)  
> **核心**: 给定整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。  
> **要求**: 必须在**原地**修改输入数组（空间复杂度 $O(1)$）  
> **示例**: `nums = [1,2,3,4,5,6,7], k = 3` → `[5,6,7,1,2,3,4]`  
> **进阶**: 使用**空间复杂度 $O(1)$** 的**原地**算法

---

## 一、方法一：使用额外数组（Extra Array）

### 1.1 核心思想
把每个元素放到它最终应该在的位置。向右轮转 `k` 位意味着：
- 原索引 `i` 的元素 → 新索引 `(i + k) % n`
- 新索引 `i` 的元素 → 来自原索引 `(i - k + n) % n`

### 1.2 代码实现

```cpp
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k = k % n;  // 处理 k >= n 的情况
        vector<int> temp(n);

        for (int i = 0; i < n; i++) {
            temp[(i + k) % n] = nums[i];  // 元素放到新位置
        }

        nums = temp;  // 拷贝回原数组
    }
};
```

### 1.3 逐步推演
`nums = [1,2,3,4,5,6,7], k = 3, n = 7`

| 原索引 i | nums[i] | 新索引 (i+k)%n | temp 赋值 |
|:--------:|:-------:|:--------------:|:---------:|
| 0 | 1 | (0+3)%7 = 3 | temp[3] = 1 |
| 1 | 2 | (1+3)%7 = 4 | temp[4] = 2 |
| 2 | 3 | (2+3)%7 = 5 | temp[5] = 3 |
| 3 | 4 | (3+3)%7 = 6 | temp[6] = 4 |
| 4 | 5 | (4+3)%7 = 0 | temp[0] = 5 |
| 5 | 6 | (5+3)%7 = 1 | temp[1] = 6 |
| 6 | 7 | (6+3)%7 = 2 | temp[2] = 7 |

**结果**: `temp = [5,6,7,1,2,3,4]` ✓

### 1.4 复杂度分析
| 维度 | 结果 |
|------|------|
| 时间复杂度 | $O(n)$ —— 遍历一次数组 |
| 空间复杂度 | $O(n)$ —— 需要一个额外数组 |

### 1.5 适用场景
- 面试中作为**基础思路**提及，展示对取模运算的理解；
- 不严格要求空间 $O(1)$ 时，这是最简单、最不容易出错的写法。

## 二、方法二：环状替换（Cyclic Replacements）

### 2.1 核心思想
不借助额外数组，**直接在原数组上"转圈"移动元素**。  
从某个位置出发，把该位置的元素放到它该去的位置，被覆盖的元素再继续放到它该去的位置……直到回到起点，形成一个环。

如果一次环没有覆盖所有元素，就换一个起点继续，直到所有元素都被访问过。

### 2.2 为什么一个环可能不够？
当 `n` 和 `k` 不互质时（即 `gcd(n, k) > 1`），一次环只能覆盖 `n / gcd(n, k)` 个元素，需要 `gcd(n, k)` 次环才能覆盖全部。

### 2.3 代码实现

```cpp
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k = k % n;

        int count = 0;  // 记录已经放置正确的元素个数
        for (int start = 0; count < n; start++) {
            int current = start;
            int prev = nums[start];  // 待放置的元素

            do {
                int next = (current + k) % n;  // 当前元素应该去的位置
                int temp = nums[next];          // 暂存被覆盖的元素
                nums[next] = prev;              // 放置元素
                prev = temp;                    // 被覆盖的元素成为下一个待放置的
                current = next;                 // 移动到下一个位置
                count++;                        // 完成一次放置
            } while (current != start);          // 回到起点，环结束
        }
    }
};
```

### 2.4 逐步推演
`nums = [1,2,3,4,5,6,7], k = 3, n = 7`

**gcd(7, 3) = 1**，所以只需 1 个环就能覆盖所有 7 个元素。

| 步数 | current | next=(current+3)%7 | prev(待放) | nums[next]原值 | 操作 | count |
|:----:|:-------:|:------------------:|:----------:|:--------------:|:-----|:-----:|
| 初始 | — | — | nums[0]=1 | — | — | 0 |
| 1 | 0 | 3 | 1 | nums[3]=4 | nums[3]=1, prev=4 | 1 |
| 2 | 3 | 6 | 4 | nums[6]=7 | nums[6]=4, prev=7 | 2 |
| 3 | 6 | 2 | 7 | nums[2]=3 | nums[2]=7, prev=3 | 3 |
| 4 | 2 | 5 | 3 | nums[5]=6 | nums[5]=3, prev=6 | 4 |
| 5 | 5 | 1 | 6 | nums[1]=2 | nums[1]=6, prev=2 | 5 |
| 6 | 1 | 4 | 2 | nums[4]=5 | nums[4]=2, prev=5 | 6 |
| 7 | 4 | 0 | 5 | nums[0]=1 | nums[0]=5, prev=1 | 7 |
| — | 0 | — | — | — | current == start，环结束 | — |

**结果**: `nums = [5,6,7,1,2,3,4]` ✓

### 2.5 多环情况推演
`nums = [1,2,3,4,5,6], k = 2, n = 6`

**gcd(6, 2) = 2**，需要 2 个环，每个环覆盖 3 个元素。

**第 1 个环**（start = 0）：
- 0 → 2 → 4 → 0，覆盖索引 0, 2, 4

| 步数 | current | next | prev | 操作 | count |
|:----:|:-------:|:----:|:----:|:-----|:-----:|
| 1 | 0 | 2 | 1 | nums[2]=1, prev=3 | 1 |
| 2 | 2 | 4 | 3 | nums[4]=3, prev=5 | 2 |
| 3 | 4 | 0 | 5 | nums[0]=5, prev=1 | 3 |
| — | 0 | — | — | 回到起点 | — |

此时 `nums = [5,2,1,4,3,6]`，`count = 3 < 6`，继续下一个环。

**第 2 个环**（start = 1）：
- 1 → 3 → 5 → 1，覆盖索引 1, 3, 5

| 步数 | current | next | prev | 操作 | count |
|:----:|:-------:|:----:|:----:|:-----|:-----:|
| 1 | 1 | 3 | 2 | nums[3]=2, prev=4 | 4 |
| 2 | 3 | 5 | 4 | nums[5]=4, prev=6 | 5 |
| 3 | 5 | 1 | 6 | nums[1]=6, prev=2 | 6 |
| — | 1 | — | — | 回到起点，count==n，结束 | — |

**最终结果**: `nums = [5,6,1,2,3,4]` ✓

### 2.6 复杂度分析
| 维度 | 结果 |
|------|------|
| 时间复杂度 | $O(n)$ —— 每个元素只被访问一次 |
| 空间复杂度 | $O(1)$ —— 只使用了常数额外变量 |

### 2.7 关键点总结
- **`k % n`**：必须处理 `k >= n` 的情况；
- **`count` 计数器**：记录已放置的元素个数，避免重复访问；
- **`do-while` 循环**：确保至少执行一次（起点元素也要被放置）；
- **`gcd(n, k)` 决定环数**：互质时 1 个环，不互质时需要多个环。

## 三、方法三：数组翻转/反转（Array Reversal）⭐ 最优解

### 3.1 核心思想
利用**三次翻转**实现原地轮转，这是本题最优雅、最经典的解法。

**翻转规律**：
1. **整体翻转**：`[1,2,3,4,5,6,7]` → `[7,6,5,4,3,2,1]`
2. **翻转前 k 个**：`[7,6,5,4,3,2,1]` → `[5,6,7,4,3,2,1]`
3. **翻转后 n-k 个**：`[5,6,7,4,3,2,1]` → `[5,6,7,1,2,3,4]` ✓

### 3.2 为什么三次翻转有效？

设原数组为 `A = [a₁, a₂, ..., aₙ₋ₖ, aₙ₋ₖ₊₁, ..., aₙ]`

| 步骤 | 操作 | 结果 |
|:----:|:-----|:-----|
| 1 | 整体翻转 | `[aₙ, aₙ₋₁, ..., aₙ₋ₖ₊₁, aₙ₋ₖ, ..., a₁]` |
| 2 | 翻转前 k 个 | `[aₙ₋ₖ₊₁, ..., aₙ, aₙ₋ₖ, ..., a₁]` |
| 3 | 翻转后 n-k 个 | `[aₙ₋ₖ₊₁, ..., aₙ, a₁, ..., aₙ₋ₖ]` |

最终结果就是向右轮转 `k` 位！

### 3.3 代码实现

```cpp
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k = k % n;  // 处理 k >= n

        // 三次翻转
        reverse(nums.begin(), nums.end());           // 1. 整体翻转
        reverse(nums.begin(), nums.begin() + k);     // 2. 翻转前 k 个
        reverse(nums.begin() + k, nums.end());       // 3. 翻转后 n-k 个
    }
};
```

### 3.4 逐步推演
`nums = [1,2,3,4,5,6,7], k = 3, n = 7`

```
初始:     [1, 2, 3, 4, 5, 6, 7]
           ↑              ↑
          前部           后部

Step 1 — 整体翻转:
          [7, 6, 5, 4, 3, 2, 1]
           ↑           ↑
         前k个       后n-k个

Step 2 — 翻转前 k=3 个:
          [5, 6, 7, 4, 3, 2, 1]
                  ↑
              分界点

Step 3 — 翻转后 n-k=4 个:
          [5, 6, 7, 1, 2, 3, 4]  ✓
```

### 3.5 边界情况推演

#### 情况 1：k = 0（不轮转）
`k % n = 0`
- 整体翻转 → 再翻转前 0 个（无操作）→ 再翻转后 n 个（整体翻回来）
- 结果不变 ✓

#### 情况 2：k = n（轮转一圈）
`k % n = 0`，同上，结果不变 ✓

#### 情况 3：k > n
`nums = [1,2,3], k = 4` → `k % 3 = 1`
- 等价于轮转 1 位 → `[3,1,2]` ✓

#### 情况 4：n = 1
`nums = [1], k = 任意`
- 整体翻转还是 `[1]`，前 k%1=0 个不翻转，后 1 个翻转还是 `[1]` ✓

### 3.6 复杂度分析
| 维度 | 结果 |
|------|------|
| 时间复杂度 | $O(n)$ —— 三次翻转，每次 $O(n)$，总计 $O(n)$ |
| 空间复杂度 | $O(1)$ —— 原地翻转，无额外数组 |

### 3.7 翻转函数的手动实现（面试可能需要）
如果面试官要求不能调用 `reverse`：

```cpp
void reverse(vector<int>& nums, int start, int end) {
    while (start < end) {
        swap(nums[start], nums[end]);
        start++;
        end--;
    }
}

void rotate(vector<int>& nums, int k) {
    int n = nums.size();
    k = k % n;
    reverse(nums, 0, n - 1);      // 整体翻转
    reverse(nums, 0, k - 1);      // 翻转前 k 个
    reverse(nums, k, n - 1);      // 翻转后 n-k 个
}
```

## 五、易错点与面试 Tips

### ❌ 错误 1：忘记 `k % n`
```cpp
k = k % n;  // 必须处理！否则 k > n 时会越界
```
当 `k = 10, n = 7` 时，实际只需轮转 `3` 位。

### ❌ 错误 2：翻转边界写错
```cpp
reverse(nums.begin(), nums.begin() + k);     // ✅ 前 k 个: [0, k-1]
reverse(nums.begin() + k, nums.end());       // ✅ 后 n-k 个: [k, n-1]
```
注意 `reverse` 是**左闭右开**区间 `[first, last)`，第二个参数是 `end()` 或 `begin() + k`。

### ❌ 错误 3：环状替换中 `count` 条件写错
```cpp
for (int start = 0; count < n; start++)  // ✅ 用 count < n 控制
```
不要用 `start < n` 控制，因为 `start` 递增但 `count` 可能还没满（多环情况）。

### ❌ 错误 4：额外数组法中忘记拷贝回去
```cpp
nums = temp;  // 必须拷贝回原数组！
```

### ✅ 面试建议
- **如果被问到"最优解"**：直接写三次翻转，解释"翻转前部、翻转后部、整体翻转"的直觉；
- **如果被追问"有没有其他方法"**：提环状替换，解释 gcd 和环的概念；
- **时间充裕时**：三种都讲，形成完整的知识图谱。

## 六、一句话总结

| 方法 | 一句话概括 |
|------|-----------|
| **额外数组** | 新开一块地，按公式 `(i+k)%n` 把元素搬到新家 |
| **环状替换** | 元素们手拉手转圈，一个带一个回到自己的位置 |
| **三次翻转** | 先整体颠倒，再把前后两部分各自颠倒——颠倒的颠倒就是轮转 |

> **终极推荐**：三次翻转法——代码最短、空间最优、面试最加分。
