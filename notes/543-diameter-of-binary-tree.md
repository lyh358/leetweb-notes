# 力扣 543：二叉树的直径学习笔记

## 一、题目核心解析

**题目描述**：给定一棵二叉树，计算它的直径长度。二叉树的直径是指树中任意两个节点之间最长路径的长度。这条路径可能穿过根节点，也可能不穿过。

**核心定义**：路径长度以**边数**表示。例如，节点 A 到节点 B 经过 3 条边，路径长度即为 3。

**关键示例**：

对于二叉树，其结构如下：

```
      1
     / \
    2   3
   / \
  4   5
```

最长路径为 `4 → 2 → 1 → 3` 或 `5 → 2 → 1 → 3`，共经过 3 条边，因此直径为 3。

---

## 二、核心思想：如何透彻理解递归？

这道题是二叉树递归中非常经典的**"自底向上"**（后序遍历）应用。结合代码，我们可以完美地用**"黑盒思维"**来拆解它。

### 1. 定义"黑盒"：我到底写了一个什么函数？

- **函数名**：`depth`
- **输入（Input）**：当前节点 `rt`
- **输出（Output）**：一个整数 `int`
- **功能（Function）**：计算以 `rt` 为根的子树的**最大深度**

### 2. 核心心法：无条件相信这个"黑盒"

按照黑盒思维，我们在写代码时，**绝对不要**去想象 `depth` 函数内部是怎么一层层往下递归的。我们只需要站在当前这一层，像调用一个已经写好的完美工具一样去调用它：

- 当我写下 `int L = depth(rt->left);` 时，我**完全相信**它能帮我算出左子树的最大深度，并乖乖地把结果交给我。
- 当我写下 `int R = depth(rt->right);` 时，我也**完全相信**它能算出右子树的深度并返回给我。

既然这两个工具都能完美工作，那么当前层需要做什么？

### 3. 当前层需要干什么？（处理边界 + 收割结果）

**第一步：处理边界（黑盒无法处理的特殊情况）**

- 如果 `rt == NULL`，说明走到了叶子节点之外，深度为 0，直接返回 0。

**第二步：收割结果（更新全局答案）**

- 既然我已经拿到了左子树的深度 `L` 和右子树的深度 `R`，那么**穿过当前节点 `rt` 的最长路径**，就是 `L + R`（左边往下走的边数 + 右边往下走的边数）。
- 我们用全局变量 `ans` 记录遍历过程中出现的最大 `L + R`：`ans = max(ans, L + R);`

**第三步：向上返回（履行黑盒承诺）**

- 当前节点处理完毕后，我需要向我的父节点汇报我的深度。
- 汇报公式：`return max(L, R) + 1;`（取左右子树中较深的那个，加上我自己这一层）。

> **顿悟时刻**：这个递归函数的主要职责（Return）是计算并返回深度，供父节点使用；但它在返回之前，顺手做了一件"副业"（Side Effect）——计算经过当前节点的路径长度，并尝试更新全局最大直径。这就是这道题最巧妙的地方！

## 三、完整代码实现 (C++)

```cpp
class Solution {
    int ans = 0; // 全局变量，记录最大直径
public:
    // 【黑盒】：计算以 rt 为根的子树的最大深度
    int depth(TreeNode* rt) {
        // 1. 递归出口：空节点深度为 0
        if (rt == NULL) {
            return 0;
        }

        // 2. 相信黑盒：分别获取左右子树的深度
        int L = depth(rt->left);
        int R = depth(rt->right);

        // 3. 收割结果：更新全局最大直径（左深度 + 右深度）
        ans = max(ans, L + R);

        // 4. 履行承诺：返回当前节点为根的子树的最大深度
        return max(L, R) + 1;
    }

    int diameterOfBinaryTree(TreeNode* root) {
        ans = 0;          // 初始化
        depth(root);      // 启动黑盒
        return ans;       // 返回最终结果
    }
};
```

## 四、复杂度分析

- **时间复杂度：** $O(n)$
  其中 $n$ 为二叉树的节点总数。在递归过程中，每个节点都恰好被访问一次。我们在求深度的过程中"顺手"更新了直径，避免了暴力解法中对每个节点重复求深度的 $O(n^2)$ 复杂度。

- **空间复杂度：** $O(h)$
  其中 $h$ 为二叉树的高度。空间消耗主要来自于递归调用栈的深度。最坏情况下（树退化为链表），空间复杂度为 $O(n)$。

## 五、学习总结

1. **自底向上的思维**：二叉树的很多路径问题（如直径、最大路径和），都需要在"自底向上"返回信息的过程中，顺便更新全局答案。

2. **黑盒思维的完美应用**：
   - 不要试图在脑海中模拟整棵树的深度计算过程。
   - 牢记 `depth` 函数的唯一使命是**返回深度**。
   - `ans = max(ans, L + R)` 只是我们在完成使命前，顺便在当前节点"收割"一下答案。

3. **举一反三**：掌握了这个套路，力扣 124（二叉树中的最大路径和）、687（最长同值路径）等 Hard/Medium 题目，其核心递归逻辑与本题如出一辙，仅仅是"收割"时的计算规则变了而已。
