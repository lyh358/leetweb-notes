# LeetCode 48. 旋转图像 —— 两种解法学习笔记

> **题目**: [48. Rotate Image](https://leetcode.cn/problems/rotate-image/)  
> **核心**: 给定一个 `n × n` 的二维矩阵 `matrix`，将其**顺时针旋转 90 度**。**必须在原地修改**，不能直接拷贝一个新矩阵。  
> **示例**:  
> ```
> 输入:          输出:
> [1,2,3]       [7,4,1]
> [4,5,6]  →    [8,5,2]
> [7,8,9]       [9,6,3]
> ```

---

## 一、方法一：额外数组映射法（非原地）

### 1.1 核心思想
直接利用**旋转坐标公式**，把每个元素放到它旋转后的目标位置，借助一个同等大小的新数组暂存结果，最后拷贝回去。

### 1.2 旋转坐标公式推导
顺时针旋转 90° 后，原矩阵中位置 `(i, j)` 的元素会移动到：

$$\text{新位置} = (j, \; n - i - 1)$$

**直观理解**：
- 第 `i` 行变成第 `n-i-1` 列（从右往左数第 `i+1` 列）；
- 第 `j` 列变成第 `j` 行。

**验证几个关键点**：
- 左上角 `(0, 0)` → `(0, n-1)`，即右上角 ✓
- 右上角 `(0, n-1)` → `(n-1, n-1)`，即右下角 ✓
- 右下角 `(n-1, n-1)` → `(n-1, 0)`，即左下角 ✓
- 左下角 `(n-1, 0)` → `(0, 0)`，即左上角 ✓

### 1.3 代码实现（带注释）

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();              // n = 矩阵维度（n × n）
        auto new_matrix = matrix;           // 深拷贝：创建一个 n×n 的新矩阵
                                            // 用于暂存旋转后的结果

        // 遍历原矩阵的每一个元素
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                // 核心映射：原(i,j) → 新(j, n-i-1)
                // 解释：
                //   j      → 新行号（原列号变成新行号）
                //   n-i-1  → 新列号（原行号倒序变成新列号）
                new_matrix[j][n - i - 1] = matrix[i][j];
            }
        }

        matrix = new_matrix;                // 将新矩阵赋值回原矩阵
                                            // 注意：这不是严格意义上的原地操作
    }
};
```

### 1.4 逐步推演
`matrix = [[1,2,3],[4,5,6],[7,8,9]], n = 3`

| (i,j) | matrix[i][j] | 新位置 (j, n-i-1) | new_matrix 赋值 |
|:-----:|:------------:|:-----------------:|:---------------:|
| (0,0) | 1 | (0, 2) | new[0][2] = 1 |
| (0,1) | 2 | (1, 2) | new[1][2] = 2 |
| (0,2) | 3 | (2, 2) | new[2][2] = 3 |
| (1,0) | 4 | (0, 1) | new[0][1] = 4 |
| (1,1) | 5 | (1, 1) | new[1][1] = 5 |
| (1,2) | 6 | (2, 1) | new[2][1] = 6 |
| (2,0) | 7 | (0, 0) | new[0][0] = 7 |
| (2,1) | 8 | (1, 0) | new[1][0] = 8 |
| (2,2) | 9 | (2, 0) | new[2][0] = 9 |

**new_matrix 结果**:
```
[7, 4, 1]
[8, 5, 2]
[9, 6, 3]
```

### 1.5 复杂度分析
| 维度 | 结果 |
|------|------|
| **时间复杂度** | $O(n^2)$ —— 遍历所有 $n^2$ 个元素 |
| **空间复杂度** | $O(n^2)$ —— 需要一个额外的 n×n 数组 |

> ⚠️ **不符合题目进阶要求**：题目明确要求"原地"算法，此方法需要额外 $O(n^2)$ 空间。仅作为基础思路。

## 二、方法二：反转 + 转置法（原地）⭐

### 2.1 核心思想
将"顺时针旋转 90°"这个复杂操作，拆解为两个**基础矩阵操作**的复合：
1. **转置**（沿主对角线翻转）：行变列，列变行；
2. **水平翻转**（每行左右反转）：左右对称交换。

### 2.2 数学原理深度推导

设原矩阵中某个元素的位置为 $(i, j)$，其中 $i$ 为行号，$j$ 为列号，$0 \leq i, j < n$。

#### 步骤一：转置（Transpose）
转置操作将矩阵沿**主对角线**（从左上到右下）翻转：

$$T(i, j) = (j, i)$$

即第 `i` 行第 `j` 列的元素，转置后位于第 `j` 行第 `i` 列。

#### 步骤二：水平翻转（Horizontal Flip）
对每一行进行左右反转，即沿**垂直中轴线**翻转：

$$H(j, i) = (j, \; n - 1 - i)$$

即第 `j` 行第 `i` 列的元素，水平翻转后位于第 `j` 行第 `n-1-i` 列。

#### 复合操作
将两步复合：先转置，再水平翻转：

$$(H \circ T)(i, j) = H(T(i, j)) = H(j, i) = (j, \; n - 1 - i)$$

这正是**顺时针旋转 90°**的坐标变换公式！

$$\boxed{\text{顺时针 90°} = \text{水平翻转} \circ \text{转置}}$$

#### 直观几何解释
```
原矩阵:          转置后:         水平翻转后 (= 顺时针90°):
[1,2,3]          [1,4,7]          [7,4,1]
[4,5,6]    →     [2,5,8]    →     [8,5,2]
[7,8,9]          [3,6,9]          [9,6,3]
     ↑               ↑                ↑
   原图           沿对角线翻转      每行左右翻转
```

### 2.3 代码实现（带注释）

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();          // 行数（n × n 矩阵）
        int m = matrix[0].size();       // 列数（对于方阵，m == n）

        // ========== 步骤1：转置（沿主对角线翻转）==========
        // 交换 matrix[i][j] 和 matrix[j][i]
        // 注意：j 从 i 开始，避免重复交换和自交换
        for (int i = 0; i < n; i++) {
            for (int j = i; j < m; j++) {
                // swap 交换两个元素
                // 当 i == j 时（对角线元素），swap 自身交换，无影响
                swap(matrix[i][j], matrix[j][i]);
            }
        }

        // ========== 步骤2：水平翻转（每行左右反转）==========
        // 对每一行调用 reverse，实现左右对称翻转
        for (int i = 0; i < n; i++) {
            reverse(matrix[i].begin(), matrix[i].end());
        }
    }
};
```

### 2.4 逐步推演
`matrix = [[1,2,3],[4,5,6],[7,8,9]]`

**Step 1 — 转置** (`swap(matrix[i][j], matrix[j][i])`):

| (i,j) | 操作 | 交换后 matrix |
|:-----:|:----:|:-------------:|
| (0,0) | swap(1,1) | 无变化（对角线） |
| (0,1) | swap(2,4) | `[1,4,3]` / `[2,5,6]` / `[7,8,9]` |
| (0,2) | swap(3,7) | `[1,4,7]` / `[2,5,6]` / `[3,8,9]` |
| (1,1) | swap(5,5) | 无变化（对角线） |
| (1,2) | swap(6,8) | `[1,4,7]` / `[2,5,8]` / `[3,6,9]` |
| (2,2) | swap(9,9) | 无变化（对角线） |

**转置结果**:
```
[1, 4, 7]
[2, 5, 8]
[3, 6, 9]
```

**Step 2 — 水平翻转** (`reverse` 每行):
- 第 0 行: `[1,4,7]` → `[7,4,1]`
- 第 1 行: `[2,5,8]` → `[8,5,2]`
- 第 2 行: `[3,6,9]` → `[9,6,3]`

**最终结果**:
```
[7, 4, 1]
[8, 5, 2]
[9, 6, 3]
```

### 2.5 复杂度分析
| 维度 | 结果 |
|------|------|
| **时间复杂度** | $O(n^2)$ —— 转置遍历上三角约 $n^2/2$，翻转每行总计 $O(n^2)$ |
| **空间复杂度** | $O(1)$ —— 原地操作，只用了常数额外空间 |

## 三、反转 + 转置法的泛用性分析 ⭐⭐⭐

这是本解法的精髓所在：一旦理解了"旋转 = 基础变换的复合"，就可以推导出**任意角度旋转**的实现方法。

### 3.1 通用公式体系

设 $T$ = 转置（沿主对角线翻转），$H$ = 水平翻转（每行 reverse），$V$ = 垂直翻转（每列 reverse）。

| 旋转角度 | 坐标变换公式 | 操作组合 | 代码实现 |
|:--------:|:-----------:|:--------:|:--------:|
| **顺时针 90°** | $(i,j) \to (j, \; n-1-i)$ | $H \circ T$ | 转置 + 每行 reverse |
| **顺时针 180°** | $(i,j) \to (n-1-i, \; n-1-j)$ | $H \circ V$ 或 $V \circ H$ | 每行 reverse + 每列 reverse |
| **顺时针 270°** | $(i,j) \to (n-1-j, \; i)$ | $V \circ T$ | 转置 + 每列 reverse |
| **逆时针 90°** | $(i,j) \to (n-1-j, \; i)$ | $T \circ H$ 或 $V \circ T$ | 每行 reverse + 转置 |

### 3.2 各角度详细推导

#### ① 顺时针 180°
顺时针 180° 等价于旋转两次 90°，或中心对称：

$$(i, j) \to (n-1-i, \; n-1-j)$$

**实现方法**：
```cpp
// 方法A：先水平翻转，再垂直翻转
for (int i = 0; i < n; i++) 
    reverse(matrix[i].begin(), matrix[i].end());  // 水平翻转
for (int j = 0; j < n / 2; j++) {               // 垂直翻转
    for (int i = 0; i < n; i++) 
        swap(matrix[i][j], matrix[i][n-1-j]);
}
```

#### ② 顺时针 270°（= 逆时针 90°）

$$R_{270}(i, j) = (n-1-j, \; i)$$

**推导**：$R_{270} = R_{90}^{-1}$，即 $R_{90}$ 的逆操作。

由于 $R_{90} = H \circ T$，则：
$$R_{270} = (H \circ T)^{-1} = T^{-1} \circ H^{-1} = T \circ H$$

（转置和水平翻转都是自身的逆操作）

**实现方法**：
```cpp
// 方法A：先每行 reverse，再转置
for (int i = 0; i < n; i++) 
    reverse(matrix[i].begin(), matrix[i].end());  // 先水平翻转
for (int i = 0; i < n; i++) 
    for (int j = i; j < n; j++) 
        swap(matrix[i][j], matrix[j][i]);         // 再转置
```

```cpp
// 方法B：先转置，再每列 reverse（垂直翻转）
for (int i = 0; i < n; i++) 
    for (int j = i; j < n; j++) 
        swap(matrix[i][j], matrix[j][i]);         // 转置
for (int j = 0; j < n / 2; j++)                  // 垂直翻转（每列 reverse）
    for (int i = 0; i < n; i++) 
        swap(matrix[i][j], matrix[i][n-1-j]);
```

#### ③ 逆时针 90° 验证
逆时针 90° 的坐标变换：
- 左上角 `(0,0)` → 左下角 `(n-1, 0)`
- 右上角 `(0,n-1)` → 左上角 `(0, 0)`

用"先水平翻转再转置"验证：
```
原矩阵:          水平翻转后:      转置后 (= 逆时针90°):
[1,2,3]          [3,2,1]          [3,6,9]
[4,5,6]    →     [6,5,4]    →     [2,5,8]
[7,8,9]          [9,8,7]          [1,4,7]

验证：原(0,0)=1 → 新(2,0)=1 ✓（左下角）
      原(0,2)=3 → 新(0,0)=3 ✓（左上角）
```

### 3.3 记忆口诀

```
顺时针 90°：先转置，后行翻（转置 + 每行 reverse）
顺时针180°：行翻列翻都要干（水平 + 垂直翻转）
顺时针270°：先转置，后列翻（转置 + 每列 reverse）
逆时针 90°：先行翻，后转置（每行 reverse + 转置）
```

### 3.4 非方阵的情况
本题限定 `n × n` 方阵。如果是 `m × n` 非方阵：
- **转置**后变成 `n × m`，形状改变；
- 转置 + 翻转的组合**不能直接套用**；
- 需要先用额外数组做坐标映射，或采用分层旋转法。

所以"反转 + 转置法"的泛用性**仅限于方阵**。对于非方阵的旋转，必须使用其他方法。

## 五、易错点与面试 Tips

### ❌ 错误 1：转置时双重循环范围写错
```cpp
// 错误：j 从 0 开始，导致重复交换，最终矩阵不变
for (int j = 0; j < m; j++) 
    swap(matrix[i][j], matrix[j][i]);

// 正确：j 从 i 开始，只遍历上三角（含对角线）
for (int j = i; j < m; j++) 
    swap(matrix[i][j], matrix[j][i]);
```

### ❌ 错误 2：转置和翻转的顺序颠倒
```cpp
// 错误：先翻转再转置
reverse(matrix[i].begin(), matrix[i].end());  // ❌
// 再转置...

// 正确：先转置，再每行翻转
// 顺序不能颠倒，因为矩阵操作不满足交换律！
```

### ❌ 错误 3：忘记处理非方阵（虽然本题是方阵）
```cpp
int n = matrix.size();
int m = matrix[0].size();
// 转置时 i < n, j < m，但如果 n != m，转置后矩阵形状会改变
// 本题保证 n == m，所以没问题
```

### ❌ 错误 4：额外数组法中 `matrix = new_matrix` 的理解
```cpp
matrix = new_matrix;  // 这是赋值操作，不是原地修改
// 在 LeetCode 中，由于 matrix 是引用传参，
// 这个赋值会改变外部变量指向，但内部确实创建了新数组
// 严格来说不符合"原地"要求
```

### ✅ 面试回答框架
1. **最优解**：反转 + 转置法，时间 $O(n^2)$，空间 $O(1)$；
2. **原理**：顺时针 90° = 转置 + 水平翻转，可用坐标变换公式证明；
3. **扩展**：能推导出 180°、270°、逆时针 90° 的变换组合；
4. **注意**：转置时 `j` 从 `i` 开始，避免重复交换。

## 六、一句话总结

> **额外数组法**：按公式 `(i,j) → (j, n-i-1)` 把元素搬到新家，简单直接但费空间。  
> **反转转置法**：先沿对角线翻（转置），再沿中轴线翻（水平翻转），两次原地操作就能拼出顺时针 90°——这是矩阵基础变换的复合艺术，掌握后可一通百通。

| 方法 | 核心操作 | 空间 | 面试建议 |
|------|:--------:|:----:|:--------:|
| 额外数组 | 坐标映射 + 深拷贝 | $O(n^2)$ | 基础思路，快速提及 |
| 反转转置 | 转置 + 每行 reverse | $O(1)$ | ⭐ 首选，重点阐述 |
