# LeetCode 238. 除自身以外数组的乘积 —— 双指针单次遍历解法学习笔记

> **题目**: [238. Product of Array Except Self](https://leetcode.cn/problems/product-of-array-except-self/)  
> **核心**: 给定整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。  
> **约束**: 必须在 $O(n)$ 时间复杂度内完成，且**不能使用除法**。  
> **示例**: `nums = [1, 2, 3, 4]` → `answer = [24, 12, 8, 6]`

---

## 一、核心思想：左右前缀积 + 双指针

### 1.1 问题拆解
对于任意位置 `i`，`answer[i]` 可以拆成两部分：

$$
`answer[i] = \underbrace{nums[0] \times nums[1] \times \cdots \times nums[i-1]}_{\text{左侧所有元素的乘积}} \times \underbrace{nums[i+1] \times \cdots \times nums[n-1]}_{\text{右侧所有元素的乘积}}`
$$

如果能同时知道每个位置的**左侧累积积**和**右侧累积积**，就能直接相乘得到答案。

### 1.2 常规思路（两次遍历）
1. **第一次从左到右**：计算每个位置的左侧累积积，存到 `answer[i]`；
2. **第二次从右到左**：计算每个位置的右侧累积积，乘到 `answer[i]` 上。

### 1.3 本题解的巧妙之处（单次遍历）
用**双指针** `left` 和 `right` 从数组两端同时向中间靠拢：
- `lp`（left product）：维护 `nums[0..left-1]` 的乘积；
- `rp`（right product）：维护 `nums[right+1..n-1]` 的乘积。

每次循环同时完成两件事：
1. 把当前 `rp` 乘到 `answer[right]`（填充右侧积）；
2. 把当前 `lp` 乘到 `answer[left]`（填充左侧积）；
3. 更新 `lp` 和 `rp`，指针向中间移动。

---

## 二、代码实现

```cpp
std::vector<int> productExceptSelf2(std::vector<int>& nums) {
    std::vector<int> answer(nums.size(), 1);
    int left = 0, right = nums.size() - 1;
    int lp = 1, rp = 1;

    while (right >= 0 && left < nums.size()) {
        answer[right] *= rp;      // 右侧累积积乘入 answer[right]
        answer[left] *= lp;       // 左侧累积积乘入 answer[left]
        lp *= nums[left++];       // 更新左侧积，left 右移
        rp *= nums[right--];      // 更新右侧积，right 左移
    }

    return answer;
}
```

## 三、逐步推演示例

以 `nums = [1, 2, 3, 4]` 为例：

| 轮次 | left | right | lp | rp | `answer[right] *= rp` | `answer[left] *= lp` | `lp *= nums[left]` | `rp *= nums[right]` | answer 状态 |
|:----:|:----:|:-----:|:--:|:--:|:----------------------:|:--------------------:|:------------------:|:-------------------:|:-----------:|
| 初始 | 0 | 3 | 1 | 1 | — | — | — | — | `[1, 1, 1, 1]` |
| 1 | 0→1 | 3→2 | 1 | 1 | `ans[3]*=1` → 1 | `ans[0]*=1` → 1 | `1*1=1` | `1*4=4` | `[1, 1, 1, 1]` |
| 2 | 1→2 | 2→1 | 1 | 4 | `ans[2]*=4` → 4 | `ans[1]*=1` → 1 | `1*2=2` | `4*3=12` | `[1, 1, 4, 1]` |
| 3 | 2→3 | 1→0 | 2 | 12 | `ans[1]*=12` → 12 | `ans[2]*=2` → 8 | `2*3=6` | `12*2=24` | `[1, 12, 8, 1]` |
| 4 | 3→4 | 0→-1 | 6 | 24 | `ans[0]*=24` → 24 | `ans[3]*=6` → 6 | `6*4=24` | `24*1=24` | `[24, 12, 8, 6]` |

**最终结果**: `[24, 12, 8, 6]` ✓

## 四、关键不变式（Loop Invariant）

在 `while` 循环的每一次迭代开始时，以下两个条件恒成立：

> **Invariant 1**: `lp == nums[0] × nums[1] × ... × nums[left-1]`  
> （`lp` 恰好是 `left` 位置左侧所有元素的乘积）

> **Invariant 2**: `rp == nums[right+1] × nums[right+2] × ... × nums[n-1]`  
> （`rp` 恰好是 `right` 位置右侧所有元素的乘积）

### 为什么这个不变式能保证正确性？

以第 3 轮为例（`left=2, right=1`）：
- `lp = 2 = nums[0] × nums[1] = 1 × 2` → 恰好是 `nums[2]` 左侧的乘积
- `rp = 12 = nums[2] × nums[3] = 3 × 4` → 恰好是 `nums[1]` 右侧的乘积

此时：
- `answer[1] *= rp` → `answer[1]` 得到了右侧积 `12`
- `answer[2] *= lp` → `answer[2]` 得到了左侧积 `2`

虽然 `answer[1]` 和 `answer[2]` 在这一轮只被填充了一半（分别只乘了右侧积和左侧积），但**它们会在另一轮被另一半填充**：
- `answer[1]` 的左侧积 `1` 在第 2 轮已经乘入；
- `answer[2]` 的右侧积 `4` 在第 2 轮已经乘入。

每个 `answer[i]` 最终都会被**左侧遍历**和**右侧遍历**各访问一次，两次乘积相乘即得最终结果。

## 五、与常规两次遍历写法的对比

### 写法 A：常规两次遍历
```cpp
vector<int> answer(n, 1);
// 第一次：从左到右，填左侧积
for (int i = 1; i < n; i++) {
    answer[i] = answer[i-1] * nums[i-1];
}
// 第二次：从右到左，乘右侧积
int rp = 1;
for (int i = n-1; i >= 0; i--) {
    answer[i] *= rp;
    rp *= nums[i];
}
```

### 写法 B：本题解（双指针单次遍历）
```cpp
// 左右指针同时向中间移动，同时填充两侧
while (right >= 0 && left < n) {
    answer[right] *= rp;
    answer[left] *= lp;
    lp *= nums[left++];
    rp *= nums[right--];
}
```

| 对比维度 | 常规两次遍历 | 双指针单次遍历 |
|:--------:|:-----------:|:-------------:|
| 遍历次数 | 2 次 | **1 次** |
| 代码行数 | 约 8 行 | **约 6 行** |
| 可读性 | ⭐⭐⭐ 逻辑清晰，容易理解 | ⭐⭐ 紧凑但需理解不变式 |
| 时间复杂度 | $O(n)$ | $O(n)$ |
| 空间复杂度 | $O(1)$（除答案数组） | $O(1)$（除答案数组） |

> **结论**：双指针写法是"炫技型"优化，面试中展示对指针和不变式的深刻理解；工程实践中常规两次遍历更易维护。

## 六、边界情况分析

### 6.1 数组长度为 1
`nums = [5]`：
- 循环条件 `right >= 0 && left < 1` 成立（`right=0, left=0`）。
- `answer[0] *= rp(1)` → 1；`answer[0] *= lp(1)` → 1。
- 更新后 `left=1, right=-1`，循环结束。
- 结果 `[1]`，符合题意（除自身外无其他元素，乘积为 1）。

### 6.2 数组包含 0
`nums = [0, 2, 3]`：

| 轮次 | left | right | lp | rp | ans[right] | ans[left] | 更新后 lp/rp |
|:----:|:----:|:-----:|:--:|:--:|:----------:|:---------:|:------------:|
| 1 | 0→1 | 2→1 | 1 | 1 | `ans[2]=1` | `ans[0]=1` | lp=0, rp=3 |
| 2 | 1→2 | 1→0 | 0 | 3 | `ans[1]=3` | `ans[1]*=0`→0 | lp=0, rp=6 |
| 3 | 2→3 | 0→-1 | 0 | 6 | `ans[0]=6` | `ans[2]*=0`→0 | lp=0, rp=6 |

结果: `[6, 0, 0]` ✓（`answer[0]=2×3=6`，`answer[1]=0×3=0`，`answer[2]=0×2=0`）

### 6.3 数组包含多个 0
`nums = [0, 0, 3]` → 结果应为 `[0, 0, 0]`，算法同样正确。

## 七、复杂度分析

| 维度 | 结果 |
|------|------|
| **时间复杂度** | $O(n)$ —— `left` 和 `right` 各移动 $n$ 步，总共 $n$ 次迭代 |
| **空间复杂度** | $O(1)$ —— 只使用了 `lp, rp, left, right` 四个额外变量（答案数组不算额外空间） |

## 八、易错点与面试 Tips

### ❌ 常见错误 1：循环条件写错
```cpp
// 错误写法
while (left < right)  // 漏了 left == right 的情况！
```
当 `n` 为奇数时，中间元素会被跳过，导致其 `answer[mid]` 只有左侧积或右侧积，结果错误。

**正确写法**：`while (right >= 0 && left < nums.size())`

### ❌ 常见错误 2：先更新 lp/rp 再乘入 answer
```cpp
// 错误顺序
lp *= nums[left++];   // 先更新
answer[left] *= lp;   // 此时 lp 已经包含了 nums[left]，不是"左侧积"
```
必须先乘入 `answer`，再更新 `lp`/`rp`，否则当前元素会被错误地包含进自己的乘积。

### ❌ 常见错误 3：忘记初始化 answer 为 1
```cpp
vector<int> answer(nums.size());  // 默认初始化为 0！
```
如果 `answer` 初始为 0，后续任何乘法都会保持 0。必须显式初始化为 1。

### ✅ 面试建议
1. **先讲常规两次遍历**：这是面试官期望的标准答案，逻辑清晰，容易解释。
2. **再提双指针优化**：展示你对空间/时间优化的敏感度，以及不变式的理解。
3. **如果面试官追问**：可以解释"双指针本质上是把两次遍历的索引合并到了同一个循环中，利用了对称性"。

## 九、一句话总结

> **双指针从两端向中间靠拢，`lp` 和 `rp` 分别携带左侧积与右侧积，在相遇前把各自的"另一半"乘到对方位置上——一次遍历，两边同时完工。**

| 要点 | 内容 |
|------|------|
| 核心技巧 | 双指针 + 前缀积滚动更新 |
| 关键不变式 | `lp` 始终是 `left` 的左侧积，`rp` 始终是 `right` 的右侧积 |
| 更新顺序 | **先乘入 answer，再更新 lp/rp** |
| 适用场景 | 需要在 $O(n)$、$O(1)$ 空间内同时获取每个位置的左右累积信息 |
