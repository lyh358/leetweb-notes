# 力扣 136. 只出现一次的数字 — 学习笔记

## 一、题目概述

给定一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，**其余每个元素均出现两次**。找出那个只出现了一次的元素。

> **关键约束**：其余元素均出现**恰好两次**。这个条件决定了可以使用异或的巧妙解法。

---

## 二、最优解法：位运算（异或 XOR）

### 核心思路

利用异或运算的**三大性质**：

| 性质 | 表达式 | 说明 |
|------|--------|------|
| 自反性 | `a ^ a = 0` | 相同的数异或为 0 |
| 恒等性 | `a ^ 0 = a` | 任何数与 0 异或不变 |
| 交换律 & 结合律 | `a ^ b ^ a = a ^ a ^ b = b` | 顺序不影响结果 |

因为数组中除了目标元素外，其他元素都出现两次，它们两两异或后会全部抵消为 0，最后剩下的就是只出现一次的数字。

### 代码分析

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;
        for (auto num : nums) {
            ans ^= num;   // 异或累积
        }
        return ans;
    }
};
```

- **时间复杂度**：$O(n)$，只需遍历一次数组
- **空间复杂度**：$O(1)$，仅使用一个变量 `ans`
- **是否修改原数组**：否

---

## 三、其他解法对比（均使用额外空间）

### 方法一：哈希表（HashSet / HashMap）

**思路**：遍历数组，用哈希集合记录每个数字的出现次数，最后找出出现次数为 1 的数字。

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        unordered_map<int, int> freq;
        for (int num : nums) {
            freq[num]++;
        }
        for (auto& [num, count] : freq) {
            if (count == 1) return num;
        }
        return -1; // 理论上不会执行到这里
    }
};
```

- **时间复杂度**：$O(n)$
- **空间复杂度**：$O(n)$，哈希表最多存储 $(n+1)/2$ 个不同的键
- **优点**：思路直观，容易理解；**可扩展性强**（如果改成"其余出现三次"，只需改判断条件）
- **缺点**：需要额外空间

---

### 方法二：数学公式（集合去重）

**思路**：利用数学恒等式：

$$2 \times (a + b + c) - (a + a + b + b + c) = c$$

即：**2 倍的去重元素之和** 减去 **原数组总和** = 只出现一次的元素

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        unordered_set<int> unique(nums.begin(), nums.end());
        long long sumUnique = 0, sumAll = 0;
        for (int num : unique) sumUnique += num;
        for (int num : nums) sumAll += num;
        return 2 * sumUnique - sumAll;
    }
};
```

- **时间复杂度**：$O(n)$
- **空间复杂度**：$O(n)$，需要存储去重集合
- **优点**：公式优美，代码简洁
- **缺点**：存在**整数溢出风险**（如果数组很大且数值很大）；需要额外空间

---

### 方法三：排序后遍历

**思路**：先对数组排序，让相同的元素相邻，然后两两比较，找出不成对的那一个。

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        for (int i = 0; i < nums.size() - 1; i += 2) {
            if (nums[i] != nums[i + 1]) {
                return nums[i];
            }
        }
        return nums.back(); // 单独的元素在末尾
    }
};
```

- **时间复杂度**：$O(n \log n)$，主要是排序开销
- **空间复杂度**：$O(1)$ 或 $O(\log n)$，取决于排序算法（`std::sort` 通常是 $O(\log n)$ 的栈空间）
- **优点**：不需要哈希表等额外数据结构
- **缺点**：**修改了原数组**；时间复杂度不如异或解法；需要处理边界情况（单独元素在末尾）

---

## 四、解法对比总结

| 解法 | 时间复杂度 | 空间复杂度 | 是否修改原数组 | 核心思想 |
|------|-----------|-----------|---------------|---------|
| **异或（最优）** | $O(n)$ | $O(1)$ | ❌ 否 | 自反性抵消成对元素 |
| 哈希表计数 | $O(n)$ | $O(n)$ | ❌ 否 | 统计出现频率 |
| 数学公式 | $O(n)$ | $O(n)$ | ❌ 否 | $2 \times$ 去重和 $-$ 总和 |
| 排序遍历 | $O(n \log n)$ | $O(\log n)$ | ✅ 是 | 排序后相邻比较 |

---

## 五、关键收获

1. **异或运算是处理"成对抵消"问题的利器**。只要看到"除了一个元素外其余都出现两次"，第一反应就应该是异或。
2. **空间换时间 vs 时间换空间**：哈希表用空间换时间，排序用时间换空间，而异或是两者兼顾的最优解。
3. **扩展思考**：如果题目改为"其余元素都出现 **三次**"，异或就不再适用，此时需要**位计数**（统计每一位上 1 出现的次数，模 3）或**哈希表**来解决。
