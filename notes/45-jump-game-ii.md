## 一、核心思想：BFS 分层 + 贪心选最远

### 1.1 为什么不是"每次跳最远"？
很多人第一反应是："站在当前位置，选能跳最远的那个不就行了？"  
但这样是**局部贪心**，不一定全局最优：

```
nums = [2, 3, 1, 1, 4]

站在下标 0（值 2）：
- 可以跳到 1（值 3）或 2（值 1）
- "每次跳最远"：0 → 2（跳 2 步，最远）
- 下标 2 的值是 1，只能到 3
- 下标 3 的值是 1，只能到 4
- 总共 3 跳：0→2→3→4 ❌

但最优解是：
- 0 → 1（跳 1 步，不是最远）
- 下标 1 的值是 3，可以直接到 4
- 总共 2 跳：0→1→4 ✓
```

**关键洞察**："当前跳最远"不等于"全局步数最少"。有时候"少跳一点"反而能踏上"跳板"，下一步跳得更远。

### 1.2 正确的贪心策略：按"跳数"分层（BFS 思想）

把问题转化为**图的最短路径**：每个下标是一个节点，从 `i` 可以到达 `[i+1, i+nums[i]]` 的所有节点。求从 0 到 n-1 的最短路径（边权为 1）。

用 BFS 的思想，但不用队列，而是用**区间**来表示每一层：

```
第 0 层（起点）: [0, 1)      → 只有下标 0，跳跃次数 0
第 1 层:         [1, 4)      → 从下标 0 能到达的范围，跳跃次数 1
第 2 层:         [4, 8)      → 从第 1 层能到达的范围，跳跃次数 2
...
```

每一层内，我们**贪心**地找下一层能到达的最远位置，然后直接跳到那一层。

### 1.3 代码的核心逻辑

```
维护两个指针：
- start: 当前这一层（第 jumptimes 跳）的起始下标
- end:   当前这一层的结束下标（开区间，不包含 end）

每次循环：
1. 在 [start, end) 范围内，枚举每个位置 i，计算 i + nums[i]（从 i 能跳到的最远距离）
2. 取这些最远距离中的最大值 maxPos
3. 下一层的范围就是 [end, maxPos+1)
4. 跳跃次数 +1
5. 重复直到 end >= n（覆盖到终点）
```

## 二、代码实现（带完整注释）

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        // ========== 贪心 + BFS 分层思想 ==========
        // 把"第 k 次跳跃能到达的所有位置"看作第 k 层
        // 每次在当前层内找"下一层能到达的最远位置"，然后直接跳到下一层

        int jumptimes = 0;   // 记录最小跳跃次数

        // start 和 end 界定"下一次起跳的范围"[start, end)
        // 这是一个左闭右开区间
        int start = 0;       // 当前层（第 jumptimes 跳能到达的范围）的起始下标
        int end = 1;         // 当前层的结束下标（开区间，不包含 end）
                             // 初始为 1，表示第 0 层只有下标 0（范围 [0, 1)）

        // ========== 主循环：只要还没覆盖到数组末尾，就继续跳 ==========
        while (end < nums.size()) {

            int maxPos = 0;  // 记录从当前层所有位置起跳，能到达的最远距离

            // 遍历当前层内的每一个位置 i
            // 站在这些位置上，看看各自能跳多远，取最远的那个
            for (int i = start; i < end; i++) {
                // 从下标 i 起跳，最远可以到达 i + nums[i]
                // 更新 maxPos 为当前层所有位置能跳到的最远距离
                maxPos = max(maxPos, nums[i] + i);
            }

            // ========== 进入下一层 ==========
            start = end;           // 下一层的起点 = 当前层的终点
                                   //（当前层最远只能到 end-1，下一层从 end 开始）

            end = maxPos + 1;      // 下一层的终点 = 最远距离 + 1（保持开区间）
                                   // +1 是因为区间是左闭右开 [start, end)

            jumptimes++;           // 完成了一次跳跃，次数 +1
        }

        return jumptimes;
    }
};
```

## 三、逐步推演示例

### 示例 1：标准情况
```
nums = [2, 3, 1, 1, 4]
```

**初始状态**: `start=0, end=1, jumptimes=0`（第 0 层：[0, 1)，只有下标 0）

**第 1 轮循环**（`end=1 < 5`，继续）：

| i | nums[i] | i + nums[i] | maxPos | 说明 |
|:-:|:-------:|:-----------:|:------:|:----:|
| 0 | 2 | 0 + 2 = 2 | 2 | 下标 0 最远跳到 2 |

- `maxPos = 2`
- 更新：`start = 1`, `end = 2 + 1 = 3`, `jumptimes = 1`
- 第 1 层范围：`[1, 3)`，即下标 1, 2，跳跃次数 1

**第 2 轮循环**（`end=3 < 5`，继续）：

| i | nums[i] | i + nums[i] | maxPos | 说明 |
|:-:|:-------:|:-----------:|:------:|:----:|
| 1 | 3 | 1 + 3 = 4 | 4 | 下标 1 最远跳到 4 |
| 2 | 1 | 2 + 1 = 3 | 4 | 下标 2 最远跳到 3 |

- `maxPos = 4`
- 更新：`start = 3`, `end = 4 + 1 = 5`, `jumptimes = 2`
- 第 2 层范围：`[3, 5)`，即下标 3, 4，跳跃次数 2

**第 3 轮循环**（`end=5 >= 5`，退出）：

- 循环结束，`end = 5` 已经覆盖到数组末尾（下标 4）

**结果**: `jumptimes = 2` ✓

> 路径：第 1 跳从下标 0 跳到 [1,2] 范围内，第 2 跳从下标 1 直接跳到 4。

## 四、关键机制深度解析

### 4.1 为什么用左闭右开区间 `[start, end)`？

```
第 k 层: [start, end)
表示：经过 k 次跳跃，能够到达的所有下标范围

例如第 1 层 [1, 4) 表示：
- 经过 1 次跳跃，可以到达下标 1, 2, 3
- 下标 4 还到不了（需要 2 次跳跃）
```

使用左闭右开的好处：
- `end - start` 直接就是当前层的元素个数；
- 下一层的 `start` 直接等于上一层的 `end`，无需 `+1` 或 `-1` 调整。

### 4.2 为什么 `end = maxPos + 1`？

`maxPos` 是当前层所有位置能跳到的**最远下标**。下一层应该覆盖 `[end, maxPos]` 这个闭区间。为了统一用左闭右开表示，终点设为 `maxPos + 1`。

```
当前层结束于 end（不包含）
下一层从 end 开始
下一层最远到 maxPos（包含）
所以下一层范围：[end, maxPos + 1)
```

### 4.3 为什么这是最小跳跃次数？

这本质上是**BFS 求最短路径**：
- 每一层对应"跳跃 k 次能到达的所有位置"；
- BFS 按层扩展，第一次到达终点时，层数就是最少步数；
- 我们在每一层内**贪心**地找下一层的最远边界，相当于一次性扩展了整层，而不是逐个节点入队出队。

因此这个算法既保证了最优性（BFS），又保证了效率（$O(n)$）。

### 4.4 为什么循环条件是 `end < nums.size()`？

`end` 是下一层的开区间终点。当 `end >= nums.size()` 时，说明当前层（或之前某层）已经能够覆盖到数组的最后一个下标 `n-1`，无需再跳了。

```
nums.size() = 5，最后一个下标是 4

当 end = 5 时，区间 [3, 5) 包含下标 3, 4
下标 4 就是终点，已经覆盖到了，可以结束
```

## 五、与 LeetCode 55（跳跃游戏 I）的区别 ⭐⭐⭐

| 对比维度 | LeetCode 55（跳跃游戏 I） | LeetCode 45（跳跃游戏 II） |
|:--------:|:------------------------:|:--------------------------:|
| **问题** | **能否**到达最后一个下标？ | 到达最后一个下标的**最少跳跃次数**？ |
| **返回值** | `bool`（能/不能） | `int`（最少步数） |
| **核心变量** | `range`：全局最远可达距离 | `start/end`：当前层范围，`maxPos`：下一层最远边界 |
| **遍历方式** | 单次线性扫描 | 分层扫描，每层内部再枚举 |
| **贪心策略** | 维护全局最远距离 | 每层内找最远的下一层边界 |
| **时间复杂度** | $O(n)$ | $O(n)$（每个元素只被访问一次） |
| **空间复杂度** | $O(1)$ | $O(1)$ |
| **关键代码** | `range = max(range, i + nums[i])` | `maxPos = max(maxPos, i + nums[i])`，然后更新区间 |
| **本质** | 覆盖问题 | **BFS 最短路径问题** |

### 形象对比

```
55 题（能否到达）：
"我只关心最远能摸到哪里，一路摸过去，摸不到就完蛋"

45 题（最少步数）：
"我每一步都要精打细算，在当前能走的所有路里，选一条能让下一步走得最远的"
```

### 代码结构对比

```cpp
// ========== 55 题：能否到达 ==========
int range = 0;
for (int i = 0; i < n; i++) {
    if (range < i) return false;      // 走不到当前位置
    range = max(range, i + nums[i]);  // 更新全局最远
}
return true;

// ========== 45 题：最少步数 ==========
int start = 0, end = 1, jumptimes = 0;
while (end < n) {
    int maxPos = 0;
    for (int i = start; i < end; i++) {  // 在当前层内枚举
        maxPos = max(maxPos, i + nums[i]);
    }
    start = end;
    end = maxPos + 1;
    jumptimes++;
}
return jumptimes;
```

**核心区别**：
- 55 题是**一维扫描**，每个位置只处理一次；
- 45 题是**二维分层**，外层是"层数"，内层是"当前层内的所有位置"。

## 六、复杂度分析

| 维度 | 结果 |
|------|------|
| **时间复杂度** | $O(n)$ —— 每个元素最多被访问一次（在某层的内层循环中） |
| **空间复杂度** | $O(1)$ —— 只用了 `start, end, maxPos, jumptimes` 四个变量 |

**为什么是 $O(n)$ 而不是 $O(n^2)$？**

虽然有两层循环，但**每个下标 i 只会出现在某一层的内层循环中**。外层循环每轮都会把 `start` 推进到上一轮的 `end`，不会重复访问已经处理过的元素。因此总的时间复杂度是线性的。

## 七、易错点与面试 Tips

### ❌ 错误 1：`end` 初始化为 0
```cpp
int end = 0;  // ❌ 错误！第 0 层应该是 [0, 1)，只包含下标 0
// 正确
int end = 1;  // ✅ 左闭右开，[0, 1) 只包含下标 0
```

### ❌ 错误 2：`end = maxPos` 漏了 +1
```cpp
end = maxPos;      // ❌ 错误！maxPos 是闭区间的最远下标
end = maxPos + 1;  // ✅ 正确！保持左闭右开
```

### ❌ 错误 3：循环条件写成 `start < nums.size()`
```cpp
while (start < nums.size())  // ❌ 错误！应该判断 end
```

### ❌ 错误 4：内层循环范围写错
```cpp
for (int i = start; i <= end; i++)  // ❌ end 是开区间，不能包含
for (int i = start; i < end; i++)   // ✅ 正确
```

### ❌ 错误 5：`maxPos` 初始化为 `start` 或 `end`
```cpp
int maxPos = start;  // ❌ 不对，应该从 0 开始取 max
int maxPos = 0;      // ✅ 正确
```

### ✅ 面试回答框架
1. **思路**：BFS 分层思想，把"第 k 跳能到达的范围"作为一层；
2. **每层操作**：在当前层 `[start, end)` 内枚举每个位置，找能跳到的最远距离 `maxPos`；
3. **进入下一层**：`start = end`, `end = maxPos + 1`，跳跃次数 +1；
4. **终止**：`end >= n` 时说明已覆盖终点；
5. **复杂度**：时间 $O(n)$，空间 $O(1)$；
6. **与 55 题区别**：55 问"能否到"（维护全局最远距离），45 问"最少几步"（BFS 分层）。

### ✅ 追问准备
- **问**：如果要求输出具体的路径（每一步跳到哪里）？  
  **答**：在内层循环中，不仅记录 `maxPos`，还记录达到 `maxPos` 的那个下标 `bestIdx`，然后把它加入路径数组。

- **问**：如果不能保证一定能到达终点呢？  
  **答**：可以在循环内加判断，如果 `maxPos < end`（下一层无法扩展），返回 `-1` 表示不可达。

## 八、一句话总结

> **把"第 k 跳能到达的所有位置"圈成一层，在这一层里挨家挨户问"你们最远能跳到哪"，取最远的那个作为下一层的边界。一层一层往外扩，扩到覆盖终点时，层数就是最少跳跃次数。**

| 要点 | 内容 |
|------|------|
| 核心策略 | BFS 分层 + 每层贪心选最远 |
| 区间定义 | `[start, end)` 左闭右开，表示当前层范围 |
| 内层循环 | 遍历当前层所有位置，计算 `i + nums[i]` 取最大值 |
| 下一层更新 | `start = end`, `end = maxPos + 1` |
| 终止条件 | `end >= nums.size()` |
| 与 55 题区别 | 55 是"能否到"（一维扫描），45 是"最少几步"（二维分层） |
| 时间复杂度 | $O(n)$ |
| 空间复杂度 | $O(1)$ |
