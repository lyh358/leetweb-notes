# 力扣 300. 最长递增子序列 — 学习笔记

> **题目**：给你一个整数数组 `nums`，找到其中**最长严格递增子序列**的长度。  
> **子序列**：由数组派生而来，删除（或不删除）数组中的元素而不改变其余元素的顺序。  
> **难度**：中等  
> **标签**：数组、二分查找、动态规划

---

## 一、题目理解

**示例**：
```
输入: nums = [10, 9, 2, 5, 3, 7, 101, 18]
输出: 4
解释: 最长的递增子序列是 [2, 3, 7, 101]，长度为 4
```

**注意**：
- 递增 = **严格递增**，后面必须比前面大（不能相等）
- 子序列**不要求连续**，中间可以跳过元素
- 顺序不能改变

---
### dp[i] = 以 nums[i] 结尾的最长递增子序列有多长。
###遍历每个位置 i 时，回头看所有比它小的数 j，挑一个结尾最长的接上去：dp[i] = max(dp[i], dp[j] + 1)。
答案就是所有 dp[i] 里的最大值。
```
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n=nums.size();
        vector<int> dp(n,1);
        int ans=0;
        for(int i=0;i<n;i++)
        {
            for(int j=0;j<i;j++)
            {
                if(nums[j]<nums[i])
                {
                    dp[i]=max(dp[i],dp[j]+1);
                }
                ans=max(ans,dp[i]);
            }
        }
        return ans;
    }
};
```
