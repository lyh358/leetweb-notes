# LeetCode 15 三数之和 学习笔记

> 题目链接：https://leetcode.cn/problems/3sum/

> 难度：中等

> 标签：数组、双指针、排序、去重

---

## 1. 题目分析

### 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。

请你返回所有和为 0 且**不重复**的三元组。

> 答案中不可以包含重复的三元组。

### 示例

```

输入：nums = [-1,0,1,2,-1,-4]

输出：[[-1,-1,2],[-1,0,1]]

```

```

输入：nums = [0,1,1]

输出：[]

```

```

输入：nums = [0,0,0]

输出：[[0,0,0]]

```

### 核心难点

1. **去重**：不能有重复的三元组，是本题最大的坑。

2. **效率**：暴力三层循环 O(n³) 会超时，需要优化。

---

## 2. 思路梳理

### 暴力解法（超时）

三层循环枚举所有三元组，时间 O(n³)，n 最大 3×10³，约 2.7×10¹⁰ 次操作，必超时。

### 排序 + 双指针（标准解法）

**核心思想：降维，把三数之和变成两数之和。**

1. **先排序数组**（排序是去重和双指针的基础）。

2. **固定第一个数 nums[i]**，把问题转化为：在 i 后面的子数组中找两个数，使它们的和等于 `-nums[i]`。

3. **用左右双指针**在有序子数组中找两数之和：

- 左指针 j = i + 1，右指针 k = n - 1

- 和小了 j++（向右移，增大和），和大了 k--（向左移，减小和）

- 等于目标值就记录结果，同时跳过重复值

4. 遍历每个 i 作为第一个数，重复上述过程。

## 3. 我的代码（已通过）

```cpp

class Solution {

public:

vector> threeSum(vector& nums) {

//先做一个答案数组

vector> ans;

//边界条件

int n = nums.size();

//如果都凑不够三个数，返回空数组

if (n < 3) {

return ans;

}

//核心：排序+双指针->将三重循环压缩为双重循环，同时要对于每个数要去重（题目要求）

//排序：从小到大，便于双指针找值

sort(nums.begin(), nums.end());

for (int i = 0; i < n; i++) {

//处理边界条件:如果i>0了，后面的数肯定都大于0，不可能三数之和为0

if (nums[i] > 0) break;

//去重：跳过后面的相同元素

if (i > 0 && nums[i] == nums[i - 1]) { //要先i>0，保证可以进行去重判断，不然越界

continue; //重复元素跳过本轮

}

//进行第二重循环

//配置指针

int j = i + 1;

int k = n - 1;

//循环

while (j < k) {

int sum = nums[i] + nums[j] + nums[k]; //判断值

if (sum == 0) { //找到了和为零的三个数

ans.push_back({nums[i], nums[j], nums[k]}); //用{}隐式初始化vector，加入ans

//核心2：指针元素去重

while (j < k && nums[j] == nums[j + 1]) { //先防止jk越界，当j当下一个元素(向右)相同

j++; //去重：跳过下一个相同元素

}

while (j < k && nums[k] == nums[k - 1]) { //先防止jk越界，当k当下一个元素（向左）相同

k--; //去重：跳过下一个相同元素

}

//正常推进；继续找其他组合

j++;

k--;

}

else if (sum < 0) { //和小于0，因为已排序，j++，将sum增大

j++;

}

else { //和大于0，因为已排序，k--，将sum减小

k--;

}

}

}

return ans;

}

};

```

## 4. 代码逐段解析

### 4.1 边界条件

```cpp

if (n < 3) return ans;

```

数组长度不足3，不可能凑出三元组，直接返回空。

### 4.2 排序

```cpp

sort(nums.begin(), nums.end());

```

排序是整个算法的基础：

- 排序后才能用双指针（有序数组才能通过移动指针调整和的大小）

- 排序后相同元素挨在一起，才能高效去重

### 4.3 外层循环：固定第一个数 i

```cpp

for (int i = 0; i < n; i++) {

if (nums[i] > 0) break; // 优化：第一个数>0，后面不可能凑出0

if (i > 0 && nums[i] == nums[i - 1]) continue; // i的去重

// ...

}

```

**nums[i] > 0 break 优化**：

- 数组已排序，第一个数都大于0了，后面两个数更大，三数之和肯定大于0，直接break。

**i 的去重（if + continue）**：

- 当前数和前一个数相同，跳过。

- 前一个相同的数已经把所有包含它的三元组都找过了，再找一遍就是重复。

- 必须先判断 `i > 0`，否则 `nums[i-1]` 越界。

### 4.4 内层循环：双指针 j、k

```cpp

int j = i + 1; // 左指针：i的下一个

int k = n - 1; // 右指针：数组末尾

while (j < k) {

int sum = nums[i] + nums[j] + nums[k];


if (sum == 0) {

// 找到一组解

ans.push_back({nums[i], nums[j], nums[k]});

// 去重 + 指针推进

// ...

} else if (sum < 0) {

j++; // 和太小，左指针右移，增大和

} else {

k--; // 和太大，右指针左移，减小和

}

}

```

### 4.5 内层指针去重（while）

```cpp

while (j < k && nums[j] == nums[j + 1]) j++; // 左指针去重

while (j < k && nums[k] == nums[k - 1]) k--; // 右指针去重

j++;

k--;

```

**为什么用 while 而不是 if？**

- 可能有一长串连续重复值（比如 `[2,2,2,2,2]`），if 只能跳过一个，while 一次性全部跳完。

**为什么去重要放在找到解之后？**

- 如果还没找到解就去重，可能会漏掉正确的组合。

- 找到一组解之后，相同的值不可能再产生新的有效组合，直接跳过。

**j < k 的边界判断**：

- 去重过程中 j 和 k 可能相遇甚至交叉，必须每次都判断 `j < k`，防止越界。

## 6. 涉及知识点

### 6.1 排序

- `sort(nums.begin(), nums.end())`，时间 O(n log n)

- 排序是双指针和去重的前提

### 6.2 对撞双指针

- 在有序数组上，左右指针从两端向中间移动

- 通过移动指针调整两数之和的大小

- 把 O(n²) 的两数枚举降到 O(n)

### 6.3 降维思想

- 三数之和 → 固定一个数 → 两数之和

- 四数之和 → 固定两个数 → 两数之和

- 推广：k 数之和都可以用排序 + 双指针，时间 O(n^(k-1))

### 6.4 隐式初始化

```cpp

ans.push_back({nums[i], nums[j], nums[k]});

```

- C++11 起支持用 `{}` 隐式构造 vector，简洁方便。

## 7. 时间、空间复杂度

设 n 为数组长度。

| 复杂度 | 分析 |

|--------|------|

| **时间 O(n²)** | 排序 O(n log n) + 外层循环 n 次 × 内层双指针 O(n) = O(n²) |

| **空间 O(log n) ~ O(n)** | 取决于排序算法的空间开销；结果数组不计入 |

> 相比暴力 O(n³)，双指针将复杂度降了一个量级。

## 8. 易错点总结

1. **忘记去重**：直接输出会有重复三元组，WA。

2. **去重时机错**：找到解之后再去重，不要在移动指针前去重，否则可能漏掉解。

3. **i 的去重和后一个比**：应该和前一个比 `nums[i] == nums[i-1]`，和后一个比会漏掉解。

4. **不排序直接双指针**：双指针只在有序数组上有效。

5. **去重时不加 j < k 边界**：去重过程中指针可能交叉，必须每次都判断。

6. **找到解后忘记 j++ 和 k--**：只去重不推进指针，会死循环。

7. **nums[i] > 0 不 break**：可以优化但不是必须，加上能提速。

## 9. 与两数之和的对比

| 题目 | 解法 | 时间 | 特点 |

|------|------|------|------|

| 两数之和 | 哈希表 | O(n) | 返回下标，不能排序（会打乱下标） |

| 三数之和 | 排序 + 双指针 | O(n²) | 返回值，需要去重，可以排序 |

> 两数之和如果返回值而不是下标，也可以用排序+双指针。

## 10. 拓展：四数之和

四数之和的思路完全一样，再套一层循环：

- 固定第一个数 i

- 固定第二个数 j（j = i + 1）

- 双指针找后两个数

- 每层都要去重

时间复杂度 O(n³)。
