# LeetCode 56. 合并区间 —— 排序 + 贪心扫描解法学习笔记

> **题目**: [56. Merge Intervals](https://leetcode.cn/problems/merge-intervals/)  
> **核心**: 给定一组区间，合并所有重叠的区间。  
> **示例**: `intervals = [[1,3],[2,6],[8,10],[15,18]]` → `[[1,6],[8,10],[15,18]]`  
> **关键约束**: 区间可能无序，需要先排序。

---

## 一、核心思想：排序定序 + 贪心合并

### 1.1 为什么必须先排序？
区间问题如果不排序，每个区间都可能与任意其他区间重叠，需要 $O(n^2)$ 两两比较。  
**按左端点升序排序后**，所有可能重叠的区间必然在数组中连续出现。这样只需**线性扫描一次**即可合并。

```
排序前: [3,5] [1,4] [2,6] [8,10]
        ↑ 无法确定谁和谁可能重叠

排序后: [1,4] [2,6] [3,5] [8,10]
        ↑ 重叠的区间一定相邻，只需从左到右扫描
```

### 1.2 贪心合并策略
排序后，维护一个**当前合并区间** `[left, right]`：
- 如果下一个区间的左端点 `≤` 当前合并区间的右端点 → **重叠**，扩展右边界；
- 如果下一个区间的左端点 `>` 当前合并区间的右端点 → **不重叠**，保存当前合并区间，开启新区间。

## 二、代码实现

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        int n = intervals.size();
        sort(intervals.begin(), intervals.end());  // 按左端点升序排序
        vector<vector<int>> merged;                // 存储合并后的区间

        for (int i = 0; i < n; i++) {
            // 用当前区间初始化合并区间的左右边界
            int left = intervals[i][0];
            int right = intervals[i][1];

            // 融合逻辑：循环合并所有与当前区间重叠的后续区间
            // 条件1：还有下一个区间 (i+1 < n)
            // 条件2：下一个区间与当前合并区间重叠 (intervals[i+1][0] <= right)
            while (i + 1 < n && intervals[i + 1][0] <= right) {
                right = max(intervals[i + 1][1], right);  // 扩展右边界
                i++;                                       // 跳过已合并的区间
            }

            // 当前合并区间已完成，加入结果
            merged.push_back({left, right});
        }
        return merged;
    }
};
```

## 三、逐步推演示例

### 示例 1：基础情况
`intervals = [[1,3], [2,6], [8,10], [15,18]]`

**Step 1 — 排序**（已按左端点有序）：
```
[[1,3], [2,6], [8,10], [15,18]]
```

**Step 2 — 扫描合并**：

| i | 当前区间 | left | right | while 条件 | 操作 | 合并后 right | 最终区间 |
|:-:|:--------:|:----:|:-----:|:-----------|:-----|:------------:|:--------:|
| 0 | [1,3] | 1 | 3 | i+1=1<4, [2,6]左=2 ≤ 3 ✓ | 扩展右边界 | max(6,3)=6 | — |
| — | — | 1 | 6 | i+1=2<4, [8,10]左=8 ≤ 6 ✗ | 退出 while | — | [1,6] |
| 2 | [8,10] | 8 | 10 | i+1=3<4, [15,18]左=15 ≤ 10 ✗ | 退出 while | — | [8,10] |
| 3 | [15,18] | 15 | 18 | i+1=4<4 ✗ | 退出 while | — | [15,18] |

**结果**: `[[1,6], [8,10], [15,18]]` ✓

---

### 示例 2：连续重叠
`intervals = [[1,4], [2,3], [3,5], [6,7]]`

**排序后**: `[[1,4], [2,3], [3,5], [6,7]]`

| i | 当前区间 | left | right | while 过程 | 最终区间 |
|:-:|:--------:|:----:|:-----:|:-----------|:--------:|
| 0 | [1,4] | 1 | 4 | [2,3]左=2≤4 → right=max(3,4)=4, i=1  <br> [3,5]左=3≤4 → right=max(5,4)=5, i=2  <br> [6,7]左=6≤5 ✗ | [1,5] |
| 3 | [6,7] | 6 | 7 | 无下一个区间 | [6,7] |

**结果**: `[[1,5], [6,7]]` ✓

> 注意：`[2,3]` 被完全包含在 `[1,4]` 内，但算法依然正确工作——`max(3,4)` 保持右边界为 4，不会缩小。

---

### 示例 3：端点相接
`intervals = [[1,4], [4,5]]`

**排序后**: `[[1,4], [4,5]]`

| i | 当前区间 | left | right | while 过程 | 最终区间 |
|:-:|:--------:|:----:|:-----:|:-----------|:--------:|
| 0 | [1,4] | 1 | 4 | [4,5]左=4≤4 ✓ → right=max(5,4)=5, i=1 | [1,5] |

**结果**: `[[1,5]]` ✓

> 端点相接（`[1,4]` 和 `[4,5]`）也算重叠，这是由 `<=` 条件保证的。

---

### 示例 4：完全无序
`intervals = [[3,5], [1,4], [0,0], [2,6]]`

**Step 1 — 排序**: `[[0,0], [1,4], [2,6], [3,5]]`

| i | 当前区间 | left | right | while 过程 | 最终区间 |
|:-:|:--------:|:----:|:-----:|:-----------|:--------:|
| 0 | [0,0] | 0 | 0 | [1,4]左=1≤0 ✗ | [0,0] |
| 1 | [1,4] | 1 | 4 | [2,6]左=2≤4 → right=max(6,4)=6, i=2 <br> [3,5]左=3≤6 → right=max(5,6)=6, i=3 | [1,6] |

**结果**: `[[0,0], [1,6]]` ✓

## 四、关键机制解析

### 4.1 双重 i++ 的协作
这是本写法最精妙（也最容易困惑）的地方：

```cpp
for (int i = 0; i < n; i++) {      // ① 外层 for 每次 i++
    // ...
    while (...) {
        i++;                          // ② 内层 while 也 i++
    }
    // ...
}
```

**协作逻辑**：
- `while` 内部的 `i++` 负责**跳过所有已被合并进当前大区间的小区间**；
- `for` 尾部的 `i++` 负责**跳到下一个尚未处理的新区间头部**。

以 `[[1,3], [2,6], [8,10]]` 为例：
1. `i=0` 进入 for，`while` 内 `i++` 到 `1`（`[2,6]` 被合并）；
2. `while` 结束，for 尾部 `i++` 到 `2`（直接跳到 `[8,10]`）；
3. 无需手动维护额外指针，两个 `i++` 完美配合。

### 4.2 为什么用 `max` 更新 right？
```cpp
right = max(intervals[i+1][1], right);
```

下一个区间的右端点可能比当前合并区间的右端点**更大**或**更小**：
- **更大**：如 `[1,3]` 和 `[2,6]` → 需要扩展到 6；
- **更小**：如 `[1,4]` 和 `[2,3]` → 保持 4（被包含，无需缩小）。

`max` 确保右边界始终取并集的最右端。

### 4.3 排序的比较规则
```cpp
sort(intervals.begin(), intervals.end());
```

`vector<vector<int>>` 的默认排序规则是**字典序**：先比较第一个元素，若相同再比较第二个。  
对于区间 `[a,b]` 和 `[c,d]`，默认排序等价于：
- 先按左端点 `a` vs `c` 升序；
- 若左端点相同，再按右端点 `b` vs `d` 升序。

这恰好满足我们的需求：左端点有序即可保证重叠区间相邻。

## 五、与另一种常见写法的对比

### 写法 A：本题解（while 内合并）
```cpp
for (int i = 0; i < n; i++) {
    int left = intervals[i][0], right = intervals[i][1];
    while (i + 1 < n && intervals[i+1][0] <= right) {
        right = max(intervals[i+1][1], right);
        i++;
    }
    merged.push_back({left, right});
}
```

### 写法 B：更常见的 if 判断写法
```cpp
for (int i = 0; i < n; i++) {
    if (merged.empty() || merged.back()[1] < intervals[i][0]) {
        // 不重叠，直接加入
        merged.push_back(intervals[i]);
    } else {
        // 重叠，扩展最后一个区间的右边界
        merged.back()[1] = max(merged.back()[1], intervals[i][1]);
    }
}
```

| 对比维度 | 写法 A（本题解） | 写法 B（常见写法） |
|:--------:|:---------------:|:-----------------:|
| 辅助变量 | `left, right` 临时保存 | 直接操作 `merged` 尾部 |
| 循环结构 | for + while 嵌套 | 单层 for |
| 可读性 | 需理解双重 i++ | ⭐ 更直观 |
| 空间效率 | 相同 | 相同 |
| 推荐场景 | 展示指针技巧 | 面试首选，更易解释 |

> **面试建议**：先写写法 B（逻辑清晰，不易出错），如果时间充裕再提及写法 A 的优化思路。

## 六、复杂度分析

| 维度 | 结果 |
|------|------|
| **时间复杂度** | $O(n \log n)$ —— 排序占主导；扫描合并是 $O(n)$ |
| **空间复杂度** | $O(1)$ —— 只使用了常数额外变量（不考虑输出数组） |

> 如果输入已排序，可以优化到 $O(n)$，但通常题目不保证有序。

## 七、易错点与面试 Tips

### ❌ 错误 1：忘记排序
```cpp
// 如果 intervals 无序，直接扫描会漏掉非相邻的重叠区间
intervals = [[3,5], [1,4]];  // 不排序 → 无法合并
```
**排序是前提**，没有排序就没有"重叠区间必相邻"的保证。

### ❌ 错误 2：重叠条件写成 `<` 而非 `<=`
```cpp
while (intervals[i+1][0] < right)  // 错误！漏了端点相接的情况
```
`[1,4]` 和 `[4,5]` 应该合并为 `[1,5]`，必须用 `<=`。

### ❌ 错误 3：right 更新时不用 max
```cpp
right = intervals[i+1][1];  // 错误！如果下一个区间被包含，会缩小边界
```
例如 `[1,10]` 和 `[2,3]`，错误写法会把 right 改成 3，导致后续区间 `[4,5]` 无法被合并。

### ❌ 错误 4：while 内 i++ 导致数组越界
```cpp
while (i + 1 < n && intervals[i+1][0] <= right)  // ✅ 先检查 i+1 < n
```
条件顺序不能颠倒，必须先检查下标合法性，再访问 `intervals[i+1]`。

### ✅ 面试回答框架
1. **先排序**：按左端点升序，$O(n \log n)$；
2. **线性扫描**：维护当前合并区间，遇到重叠就扩展右边界；
3. **保存结果**：遇到不重叠的，把当前合并区间加入答案，开启新区间；
4. **复杂度**：时间 $O(n \log n)$，空间 $O(1)$。

---

## 八、一句话总结

> **先按左端点排序，让重叠区间排排坐；然后从左到右贪心扫描，能扩就扩、能合就合，遇到断层就存档开启新区间。**

| 要点 | 内容 |
|------|------|
| 核心技巧 | 排序 + 贪心线性扫描 |
| 关键条件 | `intervals[i+1][0] <= right`（端点相接也算重叠） |
| 更新规则 | `right = max(right, next_right)`（只扩不缩） |
| 指针协作 | for 的 i++ + while 的 i++ 共同跳过已合并区间 |
| 复杂度 | $O(n \log n)$ 时间，$O(1)$ 额外空间 |
