## 二、核心思路：区间动态规划

### 2.1 状态定义

```cpp
vector<vector<bool>> dp(n, vector<bool>(n, false));
// dp[i][j] = true  表示子串 s[i..j]（从 i 到 j，包含两端）是回文串
// dp[i][j] = false 表示子串 s[i..j] 不是回文串
```

### 2.2 状态转移方程

```
s[i..j] 是回文串  ↔  s[i] == s[j] 且 s[i+1..j-1] 是回文串

即：
dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]
```

**解释**：
- 先看首尾字符是否相同（`s[i] == s[j]`）
- 再看去掉首尾后的中间部分是否也是回文（`dp[i+1][j-1]`）
- 两者同时满足，`s[i..j]` 才是回文

### 2.3 边界情况：为什么需要 `j - i <= 2`？

当子串很短时，中间部分可能为空或只有一个字符，不需要再检查 `dp[i+1][j-1]`：

| 子串长度 | 例子 | 条件 | 说明 |
|---------|------|------|------|
| 1 | `"a"` | `j - i = 0 <= 2` | 单个字符，一定是回文 |
| 2 | `"aa"` | `j - i = 1 <= 2` | 两个相同字符，是回文 |
| 3 | `"aba"` | `j - i = 2 <= 2` | 首尾相同，中间只有一个字符，一定是回文 |
| 4+ | `"abba"` | `j - i = 3 > 2` | 需要检查中间 `dp[i+1][j-1]` |

所以代码中写成：
```cpp
if (j - i <= 2 || dp[i + 1][j - 1]) {
    dp[i][j] = true;
}
```

> `j - i <= 2` 是**边界条件**，表示子串长度 `<= 3` 时，只要首尾相同就是回文，不需要递归检查中间。

## 三、最终通过的代码

```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();

        // 边界处理：当只有一个字母或者空，返回自己
        if (n < 2) return s;

        // 二维标记 bool 数组：dp[i][j] 标记从 i 到 j 的串是不是回文
        vector<vector<bool>> dp(n, vector<bool>(n, false));

        // 初始化：记录最长回文子串的位置和长度
        // 最后通过它俩返回具体的子串内容
        int start = 0;
        int maxlen = 0;

        // 反向遍历所有子串：先枚举右端点 j，再枚举左端点 i
        for (int j = 0; j < n; j++) {
            for (int i = 0; i <= j; i++) {

                // 当左右外侧字母相同，才有可能是回文串
                if (s[i] == s[j]) {

                    // 判断内部是不是回文串：
                    // 1. 串只有 2/3 个字符，只要最外层回文肯定就是回文串
                    // 2. 内层是回文串 dp[i+1][j-1] == true
                    // 必须先判断 1，防止 2 越界
                    if (j - i <= 2 || dp[i + 1][j - 1]) {

                        // 将当前子串标记为回文
                        dp[i][j] = true;

                        // 计算当前回文串长度
                        int len = j - i + 1;

                        // 维护最长子串长度和起始位置
                        if (len >= maxlen) {
                            maxlen = len;
                            start = i;
                        }
                    }
                }
            }
        }

        // 根据起点和长度截取最长回文子串输出
        // 从 start 位置开始向后截取 maxlen 个字符（包括 start 处字符）
        return s.substr(start, maxlen);
    }
};
```

## 四、代码中的关键技巧详解

### 4.1 为什么外层枚举右端点 j，内层枚举左端点 i？

```cpp
for (int j = 0; j < n; j++) {      // 外层：右端点从小到大
    for (int i = 0; i <= j; i++) {  // 内层：左端点从 0 到 j
```

**原因**：计算 `dp[i][j]` 时，需要用到 `dp[i+1][j-1]`。

- `j-1 < j`，所以按 `j` 从小到大枚举时，`dp[i+1][j-1]` 已经计算过了
- 如果反过来按 `i` 枚举，可能会出现 `dp[i+1][j-1]` 还没算的情况

**记忆口诀**：区间 DP 通常**先枚举右端点，再枚举左端点**（或先枚举区间长度）。

### 4.2 `j - i <= 2` 的数学含义

```
子串长度 = j - i + 1
j - i <= 2  →  子串长度 <= 3
```

| j-i | 长度 | 中间部分 | 是否需检查 dp[i+1][j-1] |
|-----|------|---------|------------------------|
| 0 | 1 | 空 | ❌ 不需要 |
| 1 | 2 | 空 | ❌ 不需要 |
| 2 | 3 | 1个字符 | ❌ 不需要（单个字符一定是回文） |
| 3+ | 4+ | 2+个字符 | ✅ 需要检查 |

### 4.3 为什么 `if` 条件要先写 `j - i <= 2`？

```cpp
if (j - i <= 2 || dp[i + 1][j - 1])
```

这是**短路求值**：
- 如果 `j - i <= 2` 为 `true`，后面的 `dp[i+1][j-1]` **不会执行**
- 这样可以避免当 `i+1 > j-1`（即子串长度 <= 2）时访问 `dp` 的越界或逻辑错误

### 4.4 `maxlen` 初始化为 0，用 `>=` 更新

```cpp
int maxlen = 0;
// ...
if (len >= maxlen) {
    maxlen = len;
    start = i;
}
```

**分析**：
- `maxlen = 0`，第一个回文子串（长度至少为 1）一定能满足 `len >= 0`
- 使用 `>=` 而不是 `>`，确保至少会更新一次
- 效果等价于 `maxlen = 1` + `len > maxlen`，只是写法不同

### 4.5 `s.substr(start, maxlen)`

C++ 的 `substr(pos, len)`：
- 第一个参数 `pos`：起始位置（包含）
- 第二个参数 `len`：要截取的**长度**

```cpp
// 示例：s = "babad", start = 0, maxlen = 3
s.substr(0, 3);  // 从 0 开始，截取 3 个字符 → "bab"
```

## 五、踩过的坑

### ❌ 坑：`substr` 的第二个参数传成了结束位置

```cpp
// ❌ 错误写法（把 C++ 和 Java 搞混了）
return s.substr(start, start + maxlen);
// 第二个参数变成了 start + maxlen（这是"结束位置"的写法）

// 反例：s = "babad", start = 1, maxlen = 3
// s.substr(1, 1 + 3) = s.substr(1, 4) → 截取了 4 个字符 "abad"，越界了！

// ✅ 正确写法
return s.substr(start, maxlen);
// 第二个参数是"长度"，不是"结束位置"
```

> 💡 **记忆口诀**：C++ 的 `substr(pos, len)` 第二个参数是**长度**；Java 的 `substring(begin, end)` 是左闭右开区间。

## 八、与其他方法的对比

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| **区间 DP** | O(n²) | O(n²) | 思路清晰，代码简洁，适合理解回文性质 |
| **中心扩展** | O(n²) | O(1) | 空间更优，面试推荐 |
| **Manacher** | O(n) | O(n) | 最优，但代码复杂，面试一般不考 |

### 中心扩展法（面试推荐）

```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int start = 0, maxLen = 0;
        for (int i = 0; i < s.length(); i++) {
            // 奇数长度回文（中心是一个字符）
            int len1 = expand(s, i, i);
            // 偶数长度回文（中心是两个字符）
            int len2 = expand(s, i, i + 1);
            int len = max(len1, len2);
            if (len > maxLen) {
                maxLen = len;
                start = i - (len - 1) / 2;
            }
        }
        return s.substr(start, maxLen);
    }

private:
    int expand(string& s, int left, int right) {
        while (left >= 0 && right < s.length() && s[left] == s[right]) {
            left--;
            right++;
        }
        return right - left - 1;  // 回文串长度
    }
};
```

> 中心扩展利用了回文串的**对称性**，从中心向两边扩展，直到不再对称。

## 九、常见错误

### ❌ 错误 1：遍历顺序错误

```cpp
// ❌ 错误：先枚举 i，再枚举 j
for (int i = 0; i < n; i++) {
    for (int j = i; j < n; j++) {
        // dp[i+1][j-1] 可能还没计算！
    }
}

// ✅ 正确：先枚举 j（右端点），再枚举 i（左端点）
for (int j = 0; j < n; j++) {
    for (int i = 0; i <= j; i++) {
        // dp[i+1][j-1] 的 j-1 < j，已经计算过了
    }
}
```

### ❌ 错误 2：忘记 `j - i <= 2` 的边界条件

```cpp
// ❌ 错误：直接检查 dp[i+1][j-1]，当 i+1 > j-1 时数组越界或逻辑错误
if (s[i] == s[j] && dp[i + 1][j - 1]) {
    dp[i][j] = true;
}

// ✅ 正确：短子串不需要检查中间
if (j - i <= 2 || dp[i + 1][j - 1]) {
    dp[i][j] = true;
}
```

### ❌ 错误 3：`substr` 参数传错

```cpp
// ❌ 错误：把第二个参数当成了结束位置
return s.substr(start, start + maxlen);

// ✅ 正确：第二个参数是长度
return s.substr(start, maxlen);
```

### ❌ 错误 4：C++ 和 Java 的截取函数混淆

| 语言 | 函数 | 参数含义 | 示例 |
|------|------|---------|------|
| Java | `substring(begin, end)` | 左闭右开区间 | `"abc".substring(0, 2)` → `"ab"` |
| C++ | `substr(pos, len)` | 起始位置 + 长度 | `"abc".substr(0, 2)` → `"ab"` |

## 十一、一句话总结

> **一个串是回文串，当且仅当首尾相同且中间也是回文串。从短到长逐个检查所有子串，记录最长的那个。**

```cpp
// 核心代码就这几行
if (s[i] == s[j]) {
    if (j - i <= 2 || dp[i + 1][j - 1]) {
        dp[i][j] = true;
        // 更新最长回文
    }
}
```
