## 二、核心思路：以每个元素结尾的最长递增子序列

### 2.1 关键问题

最长递增子序列可能以**任意一个元素结尾**，不一定在数组末尾。

比如 `nums = [1, 3, 2, 4]`：
- 以 `1` 结尾：`[1]`，长度 1
- 以 `3` 结尾：`[1, 3]`，长度 2
- 以 `2` 结尾：`[1, 2]`，长度 2
- 以 `4` 结尾：`[1, 3, 4]` 或 `[1, 2, 4]`，长度 3

最终答案是这些"以某个元素结尾"的长度中的**最大值**。

### 2.2 状态定义

```cpp
// dp[i] = 以 nums[i] 结尾的最长递增子序列的长度
```

> 注意：不是"前 i 个元素中的最长递增子序列"，而是**必须以 nums[i] 结尾**。

### 2.3 状态转移

对于 `dp[i]`，我们要找所有在 `i` **前面**且**比 nums[i] 小**的元素 `nums[j]`：

```
如果 nums[j] < nums[i]：
    说明 nums[i] 可以接在 nums[j] 后面，形成更长的递增子序列
    dp[i] = max(dp[i], dp[j] + 1)
```

**为什么初始化为 1？**

```cpp
dp[i] = 1;
```

因为每个元素**自身**就是一个长度为 1 的递增子序列（哪怕前面没有更小的元素）。

## 三、代码实现（O(n²) 动态规划）

```cpp
#include <vector>
#include <algorithm>

class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = (int)nums.size();
        if (n == 0) {
            return 0;
        }

        // dp[i] = 以 nums[i] 结尾的最长递增子序列的长度
        vector<int> dp(n, 0);

        for (int i = 0; i < n; ++i) {
            // 初始值：每个元素自身构成长度为1的递增子序列
            dp[i] = 1;

            // 枚举 i 前面的所有元素 j
            for (int j = 0; j < i; ++j) {
                // 如果 nums[j] < nums[i]，说明可以接在后面
                if (nums[j] < nums[i]) {
                    // 尝试用 dp[j] + 1 更新 dp[i]
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
        }

        // 答案：dp 数组中的最大值
        // 因为最长递增子序列可能以任意位置结尾
        return *max_element(dp.begin(), dp.end());
    }
};
```
另一种普通方法记录dp[i
```
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int ans = 0;
        int n = nums.size();

        vector<int> dp(n,1);

        for(int i = 0;i<n;i++){
            for(int j = 0;j<i;j++){
                if(nums[i]>nums[j]){
                    dp[i]= max(dp[i],dp[j]+1);
                }
            }
            ans = max(ans,dp[i]);
        }
        return ans;
    }
};
```

## 四、代码逐行解析

| 代码 | 含义 |
|------|------|
| `vector<int> dp(n, 0)` | 创建 dp 数组，长度 n |
| `dp[i] = 1` | 初始化：每个元素自身构成长度为 1 的递增子序列 |
| `for (int j = 0; j < i; ++j)` | 枚举 i 前面的所有元素 |
| `if (nums[j] < nums[i])` | 只有前面更小的元素才能接在后面 |
| `dp[i] = max(dp[i], dp[j] + 1)` | 状态转移：接在 j 后面，长度 +1 |
| `*max_element(dp.begin(), dp.end())` | 最终答案是 dp 数组中的最大值 |

## 七、进阶：O(n log n) 贪心 + 二分查找优化

### 7.1 核心思想

维护一个数组 `tails`，其中 `tails[k]` 表示**长度为 k+1 的递增子序列的最小末尾元素**。

```
nums = [10, 9, 2, 5, 3, 7, 101, 18]

处理 10: tails = [10]
处理 9:  9 < 10，替换 tails[0] = 9      → tails = [9]
处理 2:  2 < 9，替换 tails[0] = 2       → tails = [2]
处理 5:  5 > 2，接在后面               → tails = [2, 5]
处理 3:  3 < 5，替换 tails[1] = 3       → tails = [2, 3]
处理 7:  7 > 3，接在后面               → tails = [2, 3, 7]
处理 101: 101 > 7，接在后面            → tails = [2, 3, 7, 101]
处理 18: 18 < 101，替换 tails[3] = 18   → tails = [2, 3, 7, 18]

最终长度 = tails.size() = 4
```

> 为什么替换？因为末尾越小，后面越有可能接更多元素。

### 7.2 代码

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;

        vector<int> tails;  // tails[k] = 长度为 k+1 的递增子序列的最小末尾
        tails.push_back(nums[0]);

        for (int i = 1; i < n; i++) {
            if (nums[i] > tails.back()) {
                // 比 tails 最后一个还大，直接接在后面
                tails.push_back(nums[i]);
            } else {
                // 二分查找：找到第一个 >= nums[i] 的位置，替换它
                auto it = lower_bound(tails.begin(), tails.end(), nums[i]);
                *it = nums[i];
            }
        }

        return tails.size();
    }
};
```

### 7.3 两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| **DP** | O(n²) | O(n) | 思路直观，代码简单，能求出具体序列 |
| **贪心+二分** | **O(n log n)** | O(n) | 更快，但只能求长度，不能直接求序列 |

> 💡 **面试建议**：先写 O(n²) 的 DP 版本确保正确，然后提一下 O(n log n) 的优化。

## 八、常见错误

### ❌ 错误 1：dp 数组含义理解错

```cpp
// ❌ 错误理解：dp[i] = 前 i 个元素中的最长递增子序列长度
// 这样定义状态转移非常困难

// ✅ 正确定义：dp[i] = 以 nums[i] 结尾的最长递增子序列长度
// 这样转移很清晰：找前面比 nums[i] 小的，接在后面
```

### ❌ 错误 2：忘记初始化为 1

```cpp
// ❌ 错误：dp[i] 默认为 0
// 即使前面没有更小的元素，自身也是长度为 1 的子序列

// ✅ 正确
dp[i] = 1;
```

### ❌ 错误 3：返回 dp[n-1]

```cpp
// ❌ 错误：返回最后一个元素的 dp 值
return dp[n - 1];
// 最长递增子序列不一定以最后一个元素结尾！

// ✅ 正确：返回 dp 数组中的最大值
return *max_element(dp.begin(), dp.end());
```

### ❌ 错误 4：判断条件写成 `<=`

```cpp
// ❌ 错误：允许相等
if (nums[j] <= nums[i])  // 题目要求严格递增！

// ✅ 正确：必须严格小于
if (nums[j] < nums[i])
```

## 十、一句话总结

> **以每个元素结尾，找前面所有比它小的元素，接在后面形成更长的递增子序列。最后取所有结尾位置的最大值。**

```cpp
// 核心代码
for (int i = 0; i < n; i++) {
    dp[i] = 1;
    for (int j = 0; j < i; j++) {
        if (nums[j] < nums[i]) {
            dp[i] = max(dp[i], dp[j] + 1);
        }
    }
}
return *max_element(dp.begin(), dp.end());
```
