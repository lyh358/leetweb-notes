## 二、解题思路

### 2.1 观察规律

| 行号 i | 元素个数 | 构造方式 |
|--------|---------|---------|
| 0 | 1 | `[1]` |
| 1 | 2 | `[1, 1]` |
| 2 | 3 | `[1, 2, 1]`（2 = 1+1） |
| 3 | 4 | `[1, 3, 3, 1]`（3 = 1+2, 3 = 2+1） |
| 4 | 5 | `[1, 4, 6, 4, 1]`（4=1+3, 6=3+3, 4=3+1） |

### 2.2 状态定义

用二维数组 `ans[i][j]` 表示第 `i` 行第 `j` 列的元素值。

### 2.3 状态转移方程

```
ans[i][j] = ans[i-1][j-1] + ans[i-1][j]    // 中间元素
ans[i][0] = 1                              // 行首
ans[i][i] = 1                              // 行尾
```

### 2.4 关键细节：不规则的二维结构

杨辉三角**不是矩形矩阵**，第 `i` 行有 `i+1` 个元素：
- 第 0 行 → 1 个元素
- 第 1 行 → 2 个元素
- ...

因此不能一次性分配固定的列数，需要**逐行动态分配**。

## 三、代码实现

```cpp
class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        // 1. 先只分配外层行数，内层 vector 此时为空
        vector<vector<int>> ans(numRows);

        // 2. 逐行构造
        for (int i = 0; i < numRows; i++) {
            // 关键：给第 i 行分配 i+1 个元素的空间
            // 因为第 0 行有 1 个元素，第 1 行有 2 个元素...
            ans[i].resize(i + 1);

            // 3. 边界条件：每行的首尾元素都是 1
            ans[i][0] = 1;
            ans[i][i] = 1;

            // 4. 内层循环：通过上层元素计算当前行中间元素
            // j 从 1 开始（首元素已初始化），到 i-1 结束（尾元素已初始化）
            for (int j = 1; j < i; j++) {
                // 通项公式：当前元素 = 左上方 + 正上方
                ans[i][j] = ans[i - 1][j - 1] + ans[i - 1][j];
            }
        }

        return ans;
    }
};
```

## 四、代码详解

### 4.1 逐行分析

| 代码 | 作用 |
|------|------|
| `vector<vector<int>> ans(numRows);` | 创建外层 vector，包含 `numRows` 个**空的**内层 vector |
| `ans[i].resize(i + 1);` | **关键修复**：为第 `i` 行分配 `i+1` 个元素的空间 |
| `ans[i][0] = 1;` | 行首元素置 1 |
| `ans[i][i] = 1;` | 行尾元素置 1（当 `i=0` 时，`[0]` 和 `[0]` 是同一位置，赋值两次无影响）|
| `j = 1; j < i; j++` | 内层循环只处理中间元素。当 `i=0` 或 `i=1` 时，循环不执行 |
| `ans[i-1][j-1] + ans[i-1][j]` | 上一行左上方 + 正上方 |

### 4.2 为什么必须 `resize`？

```cpp
// ❌ 错误写法
vector<vector<int>> ans(numRows);
ans[i][0] = 1;   // 崩溃！ans[i] 是空 vector，越界访问

// ✅ 正确写法
ans[i].resize(i + 1);  // 先分配空间
ans[i][0] = 1;         // 安全访问
```

**C++ `vector` 的构造函数行为**：
- `vector<vector<int>> ans(numRows)` 只创建 `numRows` 个空的 `vector<int>`
- 每个内层 vector 的 `size()` 为 0，直接 `[]` 访问是**未定义行为**

## 五、常见错误与踩坑

### ❌ 错误 1：忘记 resize
```cpp
vector<vector<int>> ans(numRows);
ans[i][0] = 1;  // Runtime Error：越界访问
```

### ❌ 错误 2：一次性分配矩形矩阵
```cpp
vector<vector<int>> ans(numRows, vector<int>(numRows));
// 浪费空间，且返回结果包含多余的 0
```

### ❌ 错误 3：内层循环边界写错
```cpp
for (int j = 1; j <= i; j++)  // ❌ j=i 时会覆盖已赋值的 ans[i][i]=1
```

### ❌ 错误 4：行号从 1 开始导致越界
```cpp
for (int i = 1; i <= numRows; i++)  // ❌ 若配合 ans[i-1] 访问需小心边界
```

## 六、复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| **时间复杂度** | O(numRows²) | 第 i 行计算 i 个元素，总计算量 1+2+...+n = n(n+1)/2 |
| **空间复杂度** | O(numRows²) | 需要存储整个三角形的结果，共 1+2+...+n 个整数 |

## 七、拓展思考

### 7.1 如果只要求第 n 行呢？

可以用**滚动数组**优化到 O(n) 空间：
```cpp
vector<int> row(n + 1, 1);
for (int i = 2; i <= n; i++) {
    for (int j = i - 1; j > 0; j--) {  // 倒序更新，防止覆盖
        row[j] = row[j] + row[j - 1];
    }
}
```
对应力扣 **119. 杨辉三角 II**。

### 7.2 与动态规划的关系

杨辉三角是 DP 的入门经典：
- **状态定义**：`dp[i][j]` 表示位置 `(i,j)` 的值
- **状态转移**：`dp[i][j] = dp[i-1][j-1] + dp[i-1][j]`
- **边界条件**：`dp[i][0] = dp[i][i] = 1`

虽然本题可以直接用公式（组合数）求解，但递推法更直观，也更能体现 DP 思想。

| 要点 | 内容 |
|------|------|
| 核心思路 | 逐行构建，每行首尾为 1，中间由上一行推导 |
| 关键代码 | `ans[i].resize(i + 1);` |
| 易错点 | C++ 二维 vector 不会自动分配内层空间 |
