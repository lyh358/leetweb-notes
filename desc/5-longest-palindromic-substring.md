# 力扣 5. 最长回文子串 — 学习笔记（C++ 区间 DP 法）

> **题目**：给你一个字符串 `s`，找到 `s` 中最长的回文子串。  
> **难度**：中等  
> **标签**：字符串、动态规划

---

## 一、什么是回文串？

**回文串**：正着读和反着读完全相同的字符串。

```
"aba" 是回文串
"abba" 是回文串
"abc" 不是回文串
```

**核心性质**：一个字符串是回文串，当且仅当：
1. 它的**首尾字符相同**
2. 去掉首尾后的**中间子串也是回文串**

```
"abba" 是回文串
  ↓ 首字符 a = 尾字符 a
  ↓ 中间 "bb" 也是回文串
    ↓ 首字符 b = 尾字符 b
    ↓ 中间 ""（空串，视为回文）
```

> 这个性质就是区间 DP 的突破口！
