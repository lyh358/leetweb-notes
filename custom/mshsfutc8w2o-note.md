> 重点对比：**原地回溯全排列（交换法）** vs **组合（start 控制法）**

## 📌 一、题目：LeetCode 77. 组合

**题目链接**：[77. 组合](https://leetcode.cn/problems/combinations/)

**题目描述**：给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。你可以按**任何顺序**返回答案。

**示例**：

```
输入: n = 4, k = 2
输出:
[
  [1,2], [1,3], [1,4],
  [2,3], [2,4],
  [3,4]
]
```

**约束**：
- `1 <= n <= 20`
- `1 <= k <= n`

---

## 🧠 二、核心思路：`start` 参数 + `i+1`

组合问题的本质：从 `n` 个数中**无序地**选出 `k` 个。

> **关键约束**：`[1,2]` 和 `[2,1]` 是同一个组合，顺序不重要。

为了避免生成重复组合，我们必须强制规定一个**选取顺序**——只能从小到大选。这样 `[1,2]` 会被生成，但 `[2,1]` 永远不会出现。

### 为什么递归时传 `i+1`，而不是 `start+1`？

```cpp
for(int i = start; i <= n; i++) {
    pack.push_back(i);
    backtracing(n, k, i + 1);  // ← 这里是 i+1，不是 start+1
    pack.pop_back();
}
```

**`i+1` 的含义**：下一层递归时，只能从 **当前选中的数 `i` 的后面** 继续选，保证 `pack` 中的数字**严格递增**。

**如果传 `start+1` 会发生什么？**

假设 `n=4, k=2`，第一层 `start=1`：

| 当前层 | i 的值 | 选了 | 传 `start+1` = **2** | 下一层能选 | 结果 |
|-------|--------|-----|---------------------|-----------|------|
| 第1层 | 1 | `[1]` | 2 | 2, 3, 4 | `[1,2]`, `[1,3]`, `[1,4]` ✅ |
| 第1层 | 2 | `[2]` | **2** | **2, 3, 4** | `[2,2]` ❌, `[2,3]` ✅, `[2,4]` ✅ |
| 第1层 | 3 | `[3]` | **2** | **2, 3, 4** | `[3,2]` ❌, `[3,3]` ❌, `[3,4]` ✅ |

**灾难性后果**：
- 当 `i=2` 时，传 `start+1=2`，下一层从 2 开始，可以选到 `[2,2]`（重复选同一个数！）
- 当 `i=3` 时，传 `start+1=2`，下一层从 2 开始，可以选到 `[3,2]`——这和之前 `i=2` 时选到的 `[2,3]` 是**同一个组合**，只是顺序不同！

**传 `i+1` 的正确效果**：

| 当前层 | i 的值 | 选了 | 传 `i+1` | 下一层能选 | 结果 |
|-------|--------|-----|---------|-----------|------|
| 第1层 | 1 | `[1]` | 2 | 2, 3, 4 | `[1,2]`, `[1,3]`, `[1,4]` ✅ |
| 第1层 | 2 | `[2]` | 3 | 3, 4 | `[2,3]`, `[2,4]` ✅ |
| 第1层 | 3 | `[3]` | 4 | 4 | `[3,4]` ✅ |
| 第1层 | 4 | `[4]` | 5 | 无 | 无法凑齐 k 个，自然剪枝 ✅ |

> **`i+1` 的精髓**：下一层的起始位置取决于**当前具体选了哪个数**，而不是这一层从哪开始循环。这样就保证了「只能往后看，不能回头」。

## 💻 三、完整代码

### 基础版本（你的代码）

```cpp
class Solution {
public:
    vector<vector<int>> ans;
    vector<int> pack;

    void backtracing(int n, int k, int start)
    {
        // 终止条件：已经选了 k 个数
        if(pack.size() == k)
        {
            ans.push_back(pack);
            return;
        }

        // 从 start 开始枚举，保证只往后选
        for(int i = start; i <= n; i++)
        {
            pack.push_back(i);          // 选择 i
            backtracing(n, k, i + 1);   // 递归：只能从 i 后面选
            pack.pop_back();            // 撤销选择（回溯）
        }
    }

    vector<vector<int>> combine(int n, int k) {
        backtracing(n, k, 1);
        return ans;
    }
};
```

### 剪枝优化版本

上面的代码在 `n` 很大时会做很多无用功。比如 `n=20, k=2`，当 `i=20` 时，只剩一个数，不可能凑齐 2 个，但循环还是会执行。

**剪枝思路**：如果剩余的数字不够凑齐 `k` 个，直接跳过。

```cpp
class Solution {
public:
    vector<vector<int>> ans;
    vector<int> pack;

    void backtracing(int n, int k, int start)
    {
        if(pack.size() == k)
        {
            ans.push_back(pack);
            return;
        }

        // 剪枝：i 最大只能到 n - (k - pack.size()) + 1
        // 解释：还需要选 (k - pack.size()) 个数，包括当前位置
        // 所以 i 最多到 n - 还需个数 + 1
        for(int i = start; i <= n - (k - pack.size()) + 1; i++)
        {
            pack.push_back(i);
            backtracing(n, k, i + 1);
            pack.pop_back();
        }
    }

    vector<vector<int>> combine(int n, int k) {
        backtracing(n, k, 1);
        return ans;
    }
};
```

**剪枝公式推导**：
- 已选：`pack.size()` 个
- 还需：`k - pack.size()` 个
- 从位置 `i` 开始，后面至少要有「还需个数」个数字
- 所以 `i <= n - (还需个数) + 1`

## 🌳 四、递归树可视化（以 n=4, k=2 为例）

```
                         开始 []
                        /  |   |   \
                      选1  选2  选3  选4    ← 第1层：start=1，i 从 1 到 4
                     /|   |    |
                   2  3  4    3   4    4   ← 第2层：只能从 i+1 开始
                   ↓  ↓  ↓    ↓   ↓    ↓
                [1,2][1,3][1,4][2,3][2,4][3,4]  ← 满足 pack.size()==k，收集结果
```

**注意**：
- 第1层选 4 后，第2层 `start=5`，循环不执行，直接返回（自然剪枝）
- 剪枝优化后，如果 `k=2`，当 `pack.size()=0` 时，`i <= 4 - 2 + 1 = 3`，所以 `i=4` 这一分支根本不会进入

## ⚔️ 五、核心对比：全排列（交换法）vs 组合（start 法）

这是你最关心的问题。下面从多个维度进行系统对比。

### 5.1 代码对比

| | **全排列（交换法）** | **组合（start 法）** |
|---|-------------------|-------------------|
| **题目** | LeetCode 46 | LeetCode 77 |
| **核心操作** | `swap(nums[start], nums[i])` | `pack.push_back(i)` |
| **递归参数** | `backtrack(nums, start + 1)` | `backtrack(n, k, i + 1)` |
| **遍历范围** | `i` 从 `start` 到末尾 | `i` 从 `start` 到 `n` |
| **回溯操作** | 再 `swap` 回来 | `pop_back()` |

**全排列交换法代码**：
```cpp
void backtrack(vector<int>& nums, int start) {
    if (start == nums.size()) {
        ans.push_back(nums);
        return;
    }
    for (int i = start; i < nums.size(); i++) {
        swap(nums[start], nums[i]);     // 把 nums[i] 放到当前位置
        backtrack(nums, start + 1);     // 递归处理下一个位置
        swap(nums[start], nums[i]);     // 撤销交换（恢复现场）
    }
}
```

**组合 start 法代码**：
```cpp
void backtrack(int n, int k, int start) {
    if (pack.size() == k) {
        ans.push_back(pack);
        return;
    }
    for (int i = start; i <= n; i++) {
        pack.push_back(i);              // 选择 i
        backtrack(n, k, i + 1);         // 只能从 i 后面选
        pack.pop_back();                // 撤销选择（回溯）
    }
}
```

### 5.2 本质区别对比表

| 对比维度 | **全排列（交换法）** | **组合（start 法）** |
|---------|-------------------|-------------------|
| **顺序是否重要** | ✅ **重要**，`[1,2] ≠ [2,1]` | ❌ **不重要**，`[1,2] = [2,1]` |
| **解的个数** | `n!` | `C(n,k)` |
| **防止重复的手段** | 通过**交换位置**枚举所有顺序 | 通过 **`start` 参数**限制只能往后选 |
| **是否原地修改** | ✅ **原地交换**，O(1) 额外空间 | ❌ 需要 `pack` 数组存储当前路径 |
| **遍历方向** | 当前位置可与**后面任意位置**交换 | 只能选**当前位置后面的数** |
| **递归树形状** | 满 `n` 叉树（每个位置有 n-start 种选择） | 递减多叉树（可选范围越来越小） |
| **终止条件** | `start == nums.size()`（所有位置固定） | `pack.size() == k`（选够 k 个） |
| **回溯方式** | `swap` 两次（交换 → 递归 → 交换回来） | `push_back` + `pop_back` |
| **适用场景** | 元素不重复的排列问题 | 组合、子集问题 |

### 5.3 递归树形状对比

**全排列（n=3）**：
```
              [1,2,3]
             /   |   \
           1↔1  1↔2  1↔3
          /     |     \
       [1,2,3] [2,1,3] [3,2,1]
       ...     ...     ...
```
- 第1层有 3 种交换选择
- 第2层有 2 种交换选择
- 第3层有 1 种交换选择
- 叶子节点：3! = 6 个

**组合（n=4, k=2）**：
```
                    []
              /    |    |    \
            1      2     3     4      ← 第1层：4 种选择
          / | |    | |    |     
         2  3 4    3 4    4      ← 第2层：递减的选择
         ↓  ↓ ↓    ↓ ↓    ↓
       [1,2][1,3][1,4][2,3][2,4][3,4]
```
- 第1层有 4 种选择
- 第2层选择数递减（3, 2, 1, 0）
- 叶子节点：C(4,2) = 6 个

### 5.4 一句话总结区别

> **全排列交换法**：通过交换元素位置，原地枚举所有**顺序**，每个位置可以换后面任意元素。  
> **组合 start 法**：通过 `start` 参数限制范围，强制**递增顺序**，每个位置只能选后面的数，从而避免重复组合。

## 📊 六、复杂度分析

### 基础版本

- **时间复杂度**：`O(k × C(n,k))`
  - 共有 `C(n,k)` 个组合
  - 每个组合需要 `O(k)` 时间复制到结果中

- **空间复杂度**：`O(k)`
  - 递归栈深度为 `k`
  - 加上 `pack` 数组

### 剪枝优化版本

- **时间复杂度**：`O(k × C(n,k))`（理论最优，无法更低）
- **空间复杂度**：`O(k)`（同上）

> 剪枝不会降低时间复杂度的上界，但能显著减少实际递归调用次数。

## 💡 八、学习建议

1. **先理解 `start` 参数的作用**
   - 它是组合问题的「灵魂」，决定了「只能往后选」
   - 对比子集问题（78）：子集是「选够任意个数就收集」，组合是「选够 k 个才收集」

2. **对比交换法和 start 法**
   - 排列用交换法（关心顺序）
   - 组合用 start 法（不关心顺序，防重复）
   - 两者都是回溯，但防重机制完全不同

3. **掌握剪枝公式**
   - `i <= n - (k - pack.size()) + 1`
   - 面试时写出剪枝是加分项

4. **从 77 → 39 的进阶**
   - 77 是「每个数只能选一次，选 k 个」
   - 39 是「每个数可以重复选，和为 target」
   - 区别仅在于递归参数是 `i+1` 还是 `i`

## 🎯 核心口诀

> **组合防重往后看，排列求全随便换。**
>
> 组合用 `i+1` 保证递增不回头；排列用交换枚举所有顺序。记住：
> - `i+1` → 组合（不能回头，防重复）
> - `i` → 组合总和（可以重复选同一个数）
> - `0` 开始遍历 + `used[]` → 排列（顺序不同算不同解）
