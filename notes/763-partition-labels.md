# LeetCode 763. 划分字母区间 —— 贪心学习笔记

> **题目**: [763. Partition Labels](https://leetcode.cn/problems/partition-labels/)  
> **核心**: 给你一个字符串 `s`。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。返回一个表示每个字符串片段的长度的列表。  
> **示例**:  
> ```
> s = "ababcbacadefegdehijhklij"
> 输出: [9, 7, 8]
> 
> 划分结果为：
> "ababcbaca" (长度 9)
> "defegde"   (长度 7)
> "hijhklij"  (长度 8)
> ```

---

## 一、核心思想：字母的最后出现位置决定区间边界

### 1.1 问题分析
要把字符串划分成尽可能多的片段，且**同一个字母只能出现在一个片段中**。这意味着：

> **如果某个字母在位置 `i` 出现了，那么包含位置 `i` 的那个片段，必须延伸到该字母最后一次出现的位置。**

例如 `s = "ababcbacadefegdehijhklij"`：
- 字母 `a` 最后出现在下标 8，所以第一个片段至少要到下标 8；
- 字母 `b` 最后出现在下标 5，在 8 之前，不影响；
- 字母 `c` 最后出现在下标 7，在 8 之前，不影响；
- 但字母 `d` 第一次出现在下标 9，所以第一个片段必须在下标 8 结束。

### 1.2 贪心策略
1. **预处理**：先遍历一遍字符串，记录每个字母**最后出现的位置**；
2. **划分区间**：再遍历一遍字符串，维护当前区间的左右边界：
   - `start`：当前片段的起始下标；
   - `end`：当前片段的结束下标（动态更新为当前片段中所有字母最后出现位置的最大值）。
3. 当遍历到的下标 `i == end` 时，说明当前片段内的所有字母都不会在片段外出现了，可以**切割**。

```
s = "ababcbacadefegdehijhklij"

第一步：记录每个字母最后出现的位置
a→8, b→5, c→7, d→14, e→15, f→11, g→13, h→19, i→22, j→23, k→20, l→21

第二步：遍历划分区间
i=0 'a': end=max(0, 8)=8
i=1 'b': end=max(8, 5)=8
i=2 'a': end=max(8, 8)=8
i=3 'b': end=max(8, 5)=8
i=4 'c': end=max(8, 7)=8
i=5 'b': end=max(8, 5)=8
i=6 'a': end=max(8, 8)=8
i=7 'c': end=max(8, 7)=8
i=8 'a': end=max(8, 8)=8
   i==end! 切割：长度 = 8-0+1 = 9，start=9

i=9 'd': end=max(9, 14)=14
i=10 'e': end=max(14, 15)=15
i=11 'f': end=max(15, 11)=15
i=12 'e': end=max(15, 15)=15
i=13 'g': end=max(15, 13)=15
i=14 'd': end=max(15, 14)=15
i=15 'e': end=max(15, 15)=15
   i==end! 切割：长度 = 15-9+1 = 7，start=16

i=16 'h': end=max(16, 19)=19
...
i=23 'j': end=max(22, 23)=23
   i==end! 切割：长度 = 23-16+1 = 8
```

## 二、两种写法对比

### 写法 A：`unordered_map<char, int>` —— 通用写法

```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        // 统计 s 中每个字母最后出现的下标
        unordered_map<char, int> map;   // key: 字母, value: 最后出现位置
        for (int i = 0; i < s.size(); i++) {
            map[s[i]] = i;  // 每次遇到就更新，最终保留的是最后一次出现的位置
        }

        vector<int> ans;
        int start = 0, end = 0;  // 当前片段的左右边界

        for (int i = 0; i < s.size(); i++) {
            // 更新当前片段的右边界：取当前所有字母最后出现位置的最大值
            end = max(end, map[s[i]]);

            // 如果遍历到的下标等于当前右边界，说明可以切割
            if (end == i) {
                ans.push_back(end - start + 1);  // 记录片段长度
                start = end + 1;                  // 下一个片段从左边界+1开始
            }
        }
        return ans;
    }
};
```

**优点**：
- 通用性强，适用于**任意字符**（包括大写字母、数字、Unicode 字符等）；
- 代码直观，容易理解。

**缺点**：
- `unordered_map` 有一定常数开销（哈希计算、内存分配）；
- 空间占用比固定数组稍大。

---

### 写法 B：`int last[26]` —— 固定数组优化写法

```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        int n = s.size();
        int last[26];  // 假设只有小写字母 a-z，用固定大小数组

        // 记录每个字母最后出现的下标
        for (int i = 0; i < n; i++) {
            last[s[i] - 'a'] = i;  // 'a'→0, 'b'→1, ..., 'z'→25
        }

        vector<int> ans;
        int start = 0, end = 0;

        for (int i = 0; i < n; i++) {
            // s[i] - 'a' 得到字母对应的数组下标
            end = max(end, last[s[i] - 'a']);

            if (end == i) {
                ans.push_back(end - start + 1);
                start = end + 1;
            }
        }
        return ans;
    }
};
```

**优点**：
- **速度更快**：数组访问是 $O(1)$ 的直接寻址，比哈希表快（无哈希计算、无冲突处理）；
- **空间更省**：固定 26 个整数，无动态内存分配开销；
- **缓存友好**：小数组大概率在 CPU 缓存中。

**缺点**：
- 仅适用于**小写字母**（或已知有限字符集）；
- 如果字符串包含大写字母、数字或其他字符，需要扩大数组或改用 map。

---

### 两种写法的对比总结

| 对比维度 | 写法 A：`unordered_map` | 写法 B：`int last[26]` |
|:--------:|:----------------------:|:---------------------:|
| **适用字符集** | 任意字符 | 仅限小写字母 a-z |
| **访问速度** | 较快（哈希 $O(1)$） | **更快**（数组直接寻址） |
| **空间占用** | 动态分配，稍大 | 固定 26×4=104 字节 |
| **代码简洁度** | 直观 | 需理解 `s[i] - 'a'` 的映射 |
| **面试推荐** | 通用场景 | ⭐ 本题最优（已知小写字母） |

> **本题选择**：由于题目明确字符串由小写字母组成，`int last[26]` 是更优选择。但两种写法的时间复杂度都是 $O(n)$，空间复杂度都是 $O(1)$（字符集大小固定）。

## 三、关键机制深度解析

### 3.1 为什么 `map[s[i]] = i` 能记录最后出现位置？

因为遍历是从左到右的，同一个字母会被多次遇到，每次都会更新其位置。最终保留的一定是**最后一次**遇到时的下标。

```
s = "abac"

i=0, s[0]='a': map['a']=0
i=1, s[1]='b': map['b']=1
i=2, s[2]='a': map['a']=2  ← 'a' 被更新为 2（最后位置）
i=3, s[3]='c': map['c']=3

最终结果：a→2, b→1, c→3
```

### 3.2 为什么 `end = max(end, last[s[i]])` 是正确的？

当前片段包含字母 `s[i]`，而这个字母最后出现在 `last[s[i]]`。为了让整个字母都在同一个片段内，片段的右边界至少要延伸到 `last[s[i]]`。

但片段中可能有多个字母，每个字母都有自己的最后出现位置。因此右边界要取**所有字母最后位置的最大值**：

```
片段包含字母 a, b, c
a 最后出现在位置 5
b 最后出现在位置 8
c 最后出现在位置 3

则片段右边界必须 >= max(5, 8, 3) = 8
```

遍历过程中不断更新 `end = max(end, ...)`，就是在动态维护这个"所有字母最后位置的最大值"。

### 3.3 为什么 `end == i` 时可以切割？

当遍历到下标 `i` 时，如果 `i == end`，说明：
- 从 `start` 到 `i` 这个区间内，所有字母的最后出现位置都不超过 `i`；
- 也就是说，这个区间内的所有字母都不会在 `i` 之后再次出现；
- 因此可以在 `i` 处安全切割，不会影响后面的片段。

### 3.4 为什么这样能划分出"尽可能多的片段"？

因为一旦满足 `end == i`，我们就**立即切割**，不会无谓地扩大片段。这种"能切就切"的策略保证了片段数量最大化。

## 六、易错点与面试 Tips

### ❌ 错误 1：`last` 数组未初始化
```cpp
int last[26];  // ❌ 未初始化，可能是随机值
// 正确：如果只用一次赋值覆盖，不需要初始化
// 但严谨写法可以：int last[26] = {0};
```

### ❌ 错误 2：`s[i] - 'a'` 越界
```cpp
// 如果字符串包含大写字母或数字：
last[s[i] - 'a'];  // ❌ 'A' - 'a' = -32，数组越界！

// 应改用 unordered_map 或扩大数组范围
```

### ❌ 错误 3：切割长度计算错误
```cpp
ans.push_back(end - start);       // ❌ 漏了 +1
ans.push_back(end - start + 1);   // ✅ 长度 = 右边界 - 左边界 + 1
```

### ❌ 错误 4：`start` 更新错误
```cpp
start = end;      // ❌ 下一个片段会和当前片段重叠
start = end + 1;  // ✅ 下一个片段从当前片段的下一个位置开始
```

### ❌ 错误 5：只遍历一次字符串
```cpp
// 错误：试图在第一次遍历时就划分
// 必须先知道所有字母的最后位置，才能正确划分
```

### ✅ 面试回答框架
1. **思路**：先预处理每个字母的最后出现位置；再遍历字符串，维护当前片段的右边界；
2. **右边界更新**：`end = max(end, last[s[i]])`；
3. **切割条件**：当 `i == end` 时，说明当前片段内所有字母都不会再出现了；
4. **复杂度**：时间 $O(n)$，空间 $O(1)$；
5. **实现选择**：小写字母用 `int last[26]`，通用场景用 `unordered_map`。

## 七、一句话总结

> **先摸清每个字母的"老巢"（最后出现位置），然后一路走一路扩地盘（更新右边界），走到自己地盘的边界时（i == end），一刀切下去——这块地里的字母都跑不出去了。**

| 要点 | 内容 |
|------|------|
| 核心策略 | 贪心：字母最后出现位置决定片段右边界 |
| 预处理 | 记录每个字母最后出现的位置 |
| 遍历过程 | `end = max(end, last[s[i]])` |
| 切割条件 | `i == end` |
| 片段长度 | `end - start + 1` |
| 时间复杂度 | $O(n)$ |
| 空间复杂度 | $O(1)$（字符集大小固定） |
| 写法选择 | 小写字母用 `last[26]`，通用字符用 `unordered_map` |
