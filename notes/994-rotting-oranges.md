# 994.腐烂的橘子

# 题目描述

在给定的 `m x n` 网格 `grid` 中，每个单元格可以有以下三个值之一：

- 值 `0` 代表空单元格；
- 值 `1` 代表新鲜橘子；
- 值 `2` 代表腐烂的橘子。

每分钟，腐烂的橘子 **周围 4 个方向上相邻** 的新鲜橘子都会腐烂。

返回 *直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 `-1`* 。

**示例 1：**

**![img](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2019/02/16/oranges.png)**

```
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4
```

**示例 2：**

```
输入：grid = [[2,1,1],[0,1,1],[1,0,1]]
输出：-1
解释：左下角的橘子（第 2 行， 第 0 列）永远不会腐烂，因为腐烂只会发生在 4 个方向上。
```

**示例 3：**

```
输入：grid = [[0,2]]
输出：0
解释：因为 0 分钟时已经没有新鲜橘子了，所以答案就是 0 。
```

**提示：**

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 10`
- `grid[i][j]` 仅为 `0`、`1` 或 `2`

# 核心思路：多起点BFS（**多源同时扩散**）

### 核心数据结构：

### 队列`queue<pair<int, int>> q;`（存pair<int,int>:坏橘子的坐标）

# part1 : 初始化基本变量和数据

- ### 初始化行数：`int m = grid.size();`

- ### 初始化列数：`int n = grid[0].size();`

- ### 创建BFS队列：

  ### 	存烂橘子的坐标（行，列）：`queue<pair<int, int>> q; `

- ### 初始化好橘子数量：`int fresh = 0`

- ### 初始化时间（分钟）：

  ### 	从-1开始，因为第0轮要算0分钟，` int minutes = -1;`

```c++
int orangesRotting(vector<vector<int>>& grid) {
        int m = grid.size();      // 行数
        int n = grid[0].size();   // 列数
        
        queue<pair<int, int>> q;  // BFS队列，存腐烂橘子的坐标 (行,列)
        int fresh = 0;            // 统计好橘子数量

```

# part2 : 双层for循环 (m,n)

## 	找到 ==所有坏橘子的位置== 加入队列，并统计 ==好橘子数量==



- ### 判断为坏橘子的条件：`if (grid[i][j] == 2)`

  - #### 坏橘子的处理：加入队列`q.push({i, j});`

- ### 判断为好橘子的条件：`else if (grid[i][j] == 1)`

  - #### 好橘子的处理：`fresh++; `

  

- ### 如果循环结束后没有好橘子`if (fresh == 0) `：直接return

```c++
 	for (int i = 0; i < m; i++) 
 	{
    	for (int j = 0; j < n; j++) 
        {
        	if (grid[i][j] == 2) 
            {
                q.push({i, j});  // 坏橘子入队（传染源）
             } 
             else if (grid[i][j] == 1)
             {
                fresh++;          // 好橘子计数
             }
         }
    }

	// 如果没有好橘子，直接返回0（不用等）
	if (fresh == 0) 
    {
        return 0;
    }
```

# part3 : BFS扩散

- ### 构建方向数组：上下左右

```c++
 int dirs[4][2] = {{-1,0}, {1,0}, {0,-1}, {0,1}};
```

---



- ### 最外层：while循环，只要有新传染源（不是只要有坏橘子），就继续扩散

  - #### 统计这一分钟的传染源`int  = q.size(); `

  - #### 更新时间`minutes++;`

  ```c++
  while (!q.empty()) 
  {
      int cur_bad = q.size();  // 当前这一层有多少个坏橘子（同时腐烂）
  	minutes++;            // 过一分钟
  }
  ```

  

  - #### 为什么用`while (!q.empty())`？

    ```
    队列q = 待处理的坏橘子（传染源）
    
    只要队列里还有坏橘子 → 还能继续传染 → 继续循环
    队列空了 → 没有传染源了 → 结束
    ```

  - #### 设计逻辑：队列是"工作清单"

    ```
    初始：把初始坏橘子加入队列（第一批传染源）
    
    while (队列不空) {
        取出当前所有坏橘子（for循环那一层）
        让它们传染邻居
        新变烂的橘子加入队列（新的传染源）
    }
    
    直到没有新传染源，自然结束
    ```

    ---

    

- ## for循环对当前感染源进行遍历感染（循环这一层所有的感染源）

- ### 依次拿出当前队列中的一个感染源

  - #### 获取其坐标`auto [x, y] = q.front();`

  - #### 将其从队列中弹出`q.pop();`

- ### for循环向四个方向扩散

  - #### 每次扩散检查是否越界：越界直接`continue`

  - #### 如果是好橘子`if (grid[nextx][nexty] == 1) `

    - ##### 将其腐烂`grid[nextx][nexty] = 2; `

    - ##### 好橘子计数-1`fresh--; `

    - ##### 将新感染源加入队列，下一层继续感染`q.push({nextx, nexty});`

- ### 处理完所有的感染源后，queue中上一层的感染源都被弹出，现在存的是新一轮感染源

```c++
for (int i = 0; i < cur_bad; i++) 
{
	auto [x, y] = q.front(); //拿出一个当前层的烂橘子，获取它的坐标x,y
    q.pop();  // 从队列里消除它
                
	// 四个方向检查邻居
	for (int i = 0; i<4; i++) 
    {
		int nextx = x + dir[i][0];  // 新行
		int nexty = y + dir[i][1];  // 新列
                    
		// 越界检查
		if (nextx < 0 || nextx >= m || nexty < 0 || nexty >= n) 
        {
            continue;
        }
        
		// 如果是好橘子，让它腐烂
		if (grid[nextx][nexty] == 1) 
    	{
			grid[nextx][nexty] = 2;   // 变烂！
			fresh--;             // 好橘子少一个
			q.push({nextx, nexty});    // 新变烂的入队，下次传染别人
		}
	}
}
```

---

- ## 后处理：判断是否还有没被感染的好橘子

  - ### 如果有，说明被隔离，返回-1

  - ### 如果没有，返回感染全部所需的时间minutes

```c++
if(fresh==0)
{
	return -1;
}
else
{
	return minutes;
}
```

# 完整代码

```c++
class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        // ==================== Part 1: 数据预处理 ====================
        
        int m = grid.size();        // 网格行数（高度）
        int n = grid[0].size();     // 网格列数（宽度）
        int fresh = 0;              // 统计好橘子（新鲜橘子）的数量
        int minutes = -1;           // 分钟计数器，从-1开始是因为第0轮要算0分钟
        queue<pair<int,int>> q;      // BFS队列，存腐烂橘子的坐标(行,列)
        
        // ==================== Part 2: 初始化扫描 ====================
        // 遍历整个网格，找到所有初始腐烂橘子和好橘子
        
        for(int i = 0; i < m; i++)          // 遍历每一行
        {
            for(int j = 0; j < n; j++)      // 遍历每一列
            {
                if(grid[i][j] == 2)         // 发现腐烂橘子（传染源）
                {
                    q.push({i, j});           // 加入队列，作为BFS起点
                }
                else if(grid[i][j] == 1)    // 发现好橘子（待感染目标）
                {
                    fresh++;                  // 计数，最后检查是否全部感染
                }
            }
        }
        
        // 特殊情况：如果没有好橘子，直接返回0分钟（不需要等待）
        if(fresh == 0) 
        {
            return 0;
        }
        
        // ==================== Part 3: BFS层序扩散 ====================
        
        // 四个方向：右、下、上、左（顺序无所谓，覆盖四个方向即可）
        int dir[4][2] = {{0, 1}, {1, 0}, {-1, 0}, {0, -1}};
        
        // BFS主循环：只要还有腐烂橘子能传染，就继续
        while(!q.empty())
        {
            int cur_bad = q.size();     // 当前这一层（这一分钟）有多少个腐烂橘子
                                        // 这些橘子会同时向四周传染
            
            minutes++;                  // 时间推进1分钟（第0轮从0开始）
            
            // 处理当前这一层的所有腐烂橘子（同时腐烂，同时传染）
            for(int i = 0; i < cur_bad; i++)
            {
                // 从队列取出一个腐烂橘子
                auto [x, y] = q.front();    // 结构化绑定：x=行坐标，y=列坐标
                q.pop();                      // 取出后从队列删除
                
                // 向四个方向尝试传染
                for(int j = 0; j < 4; j++)    // j遍历四个方向
                {
                    // 计算邻居坐标
                    int nextx = x + dir[j][0];    // 邻居的行
                    int nexty = y + dir[j][1];    // 邻居的列
                    
                    // 边界检查：超出网格范围就跳过
                    if(nextx < 0 || nextx >= m || nexty < 0 || nexty >= n)
                    {
                        continue;                 // 越界，不处理
                    }
                    
                    // 发现好橘子，让它腐烂
                    if(grid[nextx][nexty] == 1)
                    {
                        grid[nextx][nexty] = 2;   // 标记为腐烂（感染）
                        fresh--;                   // 好橘子数量减1
                        q.push({nextx, nexty});    // 新腐烂的橘子加入队列
                                                   // 它会在下一分钟（下一轮）传染别人
                    }
                }               
            }
        }
        
        // ==================== Part 4: 检查结果 ====================
        
        // BFS结束后，检查是否还有好橘子没被感染
        // 如果有，说明被隔离了（周围没有腐烂橘子能传过来），返回-1
        if(fresh != 0)
        {
            return -1;          // 有橘子永远烂不了
        }
        else
        {
            return minutes;     // 全部腐烂，返回总时间
        }
    }
};
```

# 注意事项

## 1.腐烂的橘子是多源头BFS，相较于岛屿数量这种单源头BFS，需要==在主循环while里面加一层for循环，遍历所有源（在这层for里再四向走），才是一层==，时间的增加也要在这层for外面
