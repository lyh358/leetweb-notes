## 二、核心思路推导

### 2.1 观察规律

以 `m = 3, n = 3` 为例，在网格上标出到达每个位置的路径数：

```
    0   1   2
  ┌───┬───┬───┐
0 │ 1 │ 1 │ 1 │   ← 第一行：只能一直向右走，每条路径数都是 1
  ├───┼───┼───┤
1 │ 1 │ 2 │ 3 │   ← (1,1)=2: 从上方(0,1)来 或 从左方(1,0)来
  ├───┼───┼───┤
2 │ 1 │ 3 │ 6 │   ← (2,2)=6: 从上方(1,2)=3 来 + 从左方(2,1)=3 来
  └───┴───┴───┘
    ↑
    第一列：只能一直向下走，每条路径数都是 1
```

**发现规律**：
- 第一行和第一列的所有位置，都只有 **1 条路径**（只能一直向右或一直向下）
- 其他位置 `(i, j)` 的路径数 = 从上方来的路径数 + 从左方来的路径数

### 2.2 状态定义

```cpp
dp[i][j] = 从起点 (0,0) 到达位置 (i,j) 的不同路径总数
```

### 2.3 状态转移方程

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
           ↑从上方来    ↑从左方来
```

**解释**：
- 机器人要到达 `(i, j)`，最后一步只能从 `(i-1, j)`（上方）或 `(i, j-1)`（左方）过来
- 所以到达 `(i, j)` 的路径总数 = 到达上方的路径数 + 到达左方的路径数

### 2.4 边界条件

```cpp
dp[i][0] = 1    // 第一列：只能一直向下走，1 条路径
dp[0][j] = 1    // 第一行：只能一直向右走，1 条路径
```

## 三、代码实现（二维 DP）

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        // 创建 m x n 的二维动态数组，储存每个位置可达的路径数
        vector<vector<int>> dp(m, vector<int>(n));

        // 初始化边界条件：第一列的所有位置都只有 1 条路径
        for (int i = 0; i < m; i++) {
            dp[i][0] = 1;
        }

        // 初始化边界条件：第一行的所有位置都只有 1 条路径
        for (int j = 0; j < n; j++) {
            dp[0][j] = 1;
        }

        // 双重循环填表：
        // dp[i][j] = dp[i-1][j] + dp[i][j-1]
        // 每个位置只有两种到达方法：从上面来 或 从左边来
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }

        // 返回到达右下角的路径总数
        return dp[m - 1][n - 1];
    }
};
```

## 四、代码逐行解析

| 代码 | 含义 |
|------|------|
| `vector<vector<int>> dp(m, vector<int>(n))` | 创建 `m` 行 `n` 列的二维数组，初始值为 0 |
| `dp[i][0] = 1` | 第一列初始化：只能从上往下走，每条路径唯一 |
| `dp[0][j] = 1` | 第一行初始化：只能从左往右走，每条路径唯一 |
| `i = 1; i < m; i++` | 从第 1 行开始（第 0 行已初始化） |
| `j = 1; j < n; j++` | 从第 1 列开始（第 0 列已初始化） |
| `dp[i][j] = dp[i-1][j] + dp[i][j-1]` | **状态转移**：上方路径数 + 左方路径数 |
| `return dp[m-1][n-1]` | 返回到达右下角的总路径数 |

## 五、填表演示（m = 3, n = 3）

**初始化后**：

```
      j=0   j=1   j=2
    ┌─────┬─────┬─────┐
i=0 │  1  │  1  │  1  │   ← 第一行初始化
    ├─────┼─────┼─────┤
i=1 │  1  │  ?  │  ?  │   ← 第一列初始化
    ├─────┼─────┼─────┤
i=2 │  1  │  ?  │  ?  │   ← 第一列初始化
    └─────┴─────┴─────┘
```

**计算过程**：

| i | j | dp[i-1][j] | dp[i][j-1] | dp[i][j] = 上方 + 左方 |
|---|---|-----------|-----------|----------------------|
| 1 | 1 | dp[0][1]=1 | dp[1][0]=1 | **2** |
| 1 | 2 | dp[0][2]=1 | dp[1][1]=2 | **3** |

| 2 | 2 | dp[1][2]=3 | dp[2][1]=3 | **6** |

**最终结果**：`dp[2][2] = 6` ✅

## 六、空间优化：一维 DP（O(n) 空间）

### 6.1 优化思路

观察状态转移方程：`dp[i][j]` 只依赖于**上一行同一列**和**当前行前一列**。

也就是说，计算第 `i` 行时，只需要知道第 `i-1` 行的数据，更前面的行不再需要。

因此可以用**一维数组**代替二维数组，只保留"上一行"的信息。

### 6.2 代码

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        // 只用一维数组：dp[j] 表示当前行第 j 列的路径数
        // 初始时代表第 0 行，全部初始化为 1
        vector<int> dp(n, 1);

        // 从第 1 行开始遍历
        for (int i = 1; i < m; i++) {
            // 从第 1 列开始遍历（第 0 列永远是 1，不需要更新）
            for (int j = 1; j < n; j++) {
                // dp[j] 原来存的是上一行第 j 列的值（相当于 dp[i-1][j]）
                // dp[j-1] 已经被更新为当前行第 j-1 列的值（相当于 dp[i][j-1]）
                dp[j] = dp[j] + dp[j - 1];
            }
        }

        return dp[n - 1];
    }
};
```

### 6.3 为什么内层循环不能倒序？

```cpp
// ✅ 正确：正序遍历
for (int j = 1; j < n; j++) {
    dp[j] = dp[j] + dp[j - 1];
    // dp[j] 是旧的（上一行），dp[j-1] 是新的（当前行）
}

// ❌ 错误：倒序遍历
for (int j = n - 1; j >= 1; j--) {
    dp[j] = dp[j] + dp[j - 1];
    // dp[j-1] 还是旧的（上一行），但我们需要的是当前行的 dp[j-1]
}
```

**正序时**：
- `dp[j]` 还没被更新，存的是**上一行**的值（`dp[i-1][j]`）
- `dp[j-1]` 已经被更新，存的是**当前行**的值（`dp[i][j-1]`）
- 正好对应 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`

## 七、数学解法：组合数公式

### 7.1 思路

从左上角到右下角，总共需要走：
- 向下 `m - 1` 步
- 向右 `n - 1` 步
- 总共 `m + n - 2` 步

问题转化为：在 `m + n - 2` 步中，选择 `m - 1` 步向下（或 `n - 1` 步向右），有多少种选法？

答案就是组合数：

```
C(m+n-2, m-1) = C(m+n-2, n-1) = (m+n-2)! / ((m-1)! * (n-1)!)
```

### 7.2 代码

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        long long ans = 1;
        int k = min(m - 1, n - 1);  // 选较小的那个，减少计算量

        // 计算组合数 C(m+n-2, k)
        // 用递推方式：C(n, k) = n * (n-1) * ... * (n-k+1) / (k * (k-1) * ... * 1)
        for (int i = 1; i <= k; i++) {
            ans = ans * (m + n - 1 - i) / i;
        }

        return (int)ans;
    }
};
```

> 💡 **注意**：用 `long long` 防止中间结果溢出，除法在每一步都做（保证能整除）。

## 八、三种解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| **二维 DP** | O(m × n) | O(m × n) | 最直观，容易理解 |
| **一维 DP** | O(m × n) | **O(n)** ⭐ | 空间优化，面试推荐 |
| **组合数公式** | **O(min(m,n))** | **O(1)** | 最快，但需要数学推导 |

> 💡 **面试建议**：先写一维 DP 版本，然后提一下组合数公式作为拓展。

## 十、常见错误

### ❌ 错误 1：忘记初始化边界
```cpp
// ❌ 错误：没有给第一行/第一列赋值为 1
// 默认全是 0，导致后续计算全是 0

// ✅ 正确：第一行和第一列必须初始化为 1
for (int i = 0; i < m; i++) dp[i][0] = 1;
for (int j = 0; j < n; j++) dp[0][j] = 1;
```

### ❌ 错误 2：循环从 0 开始，覆盖了边界
```cpp
// ❌ 错误：
for (int i = 0; i < m; i++)      // i=0 时，dp[-1][j] 越界！
    for (int j = 0; j < n; j++)
        dp[i][j] = dp[i-1][j] + dp[i][j-1];

// ✅ 正确：从 1 开始，因为第 0 行/第 0 列已经初始化
for (int i = 1; i < m; i++)
    for (int j = 1; j < n; j++)
        dp[i][j] = dp[i-1][j] + dp[i][j-1];
```

### ❌ 错误 3：一维 DP 内层倒序遍历
```cpp
// ❌ 错误：倒序时 dp[j-1] 还是上一行的值
for (int j = n - 1; j >= 1; j--)
    dp[j] += dp[j - 1];

// ✅ 正确：正序，dp[j-1] 已经是当前行的值
for (int j = 1; j < n; j++)
    dp[j] += dp[j - 1];
```

## 十三、一句话总结

> **每个格子的路径数 = 上面格子的路径数 + 左边格子的路径数。第一行和第一列只有一条路，全是 1。**

```cpp
// 核心代码就一行
dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
```

这是**二维 DP 的入门经典题**，掌握它后，很多网格类 DP（如最小路径和、三角形最小路径和）都能举一反三。
