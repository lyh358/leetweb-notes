# 64.最小路径和

给定一个包含非负整数的 `*m* x *n*` 网格 `grid` ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明：**每次只能向下或者向右移动一步。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2020/11/05/minpath.jpg)

```
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：因为路径 1→3→1→1→1 的总和最小。
```

**示例 2：**

```
输入：grid = [[1,2,3],[4,5,6]]
输出：12
```

**提示：**

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`

---

# 核心方法：动态规划（DP）

## 问题分析

- **目标**：从左上角 `(0,0)` 走到右下角 `(m-1,n-1)`，每次只能**向右**或**向下**移动
- **约束**：路径经过的数字总和要最小
- **关键**：每个位置的最优解依赖于**上方**和**左方**的最优解（无后效性）

------

## 核心思路：DP 三要素

### 1. 状态定义

#### `dp[i][j]` 表示从起点 `(0,0)` 到达位置 `(i,j)` 的**最小路径和**

### 2. 状态转移方程

#### 对于位置 `(i,j)`，只有两种来源：

- ##### 从上方来：`(i-1,j)` → 代价 `dp[i-1][j]`

- ##### 从左方来：`(i,j-1)` → 代价 `dp[i][j-1]`

![image-20260415003130164](C:/Users/Administrator/AppData/Roaming/Typora/typora-user-images/image-20260415003130164.png)

#### **边界处理**：

- ##### **第一行** (`i=0`)：只能从左来，`dp[0][j] = dp[0][j-1] + grid[0][j]`

- ##### **第一列** (`j=0`)：只能从上来，`dp[i][0] = dp[i-1][0] + grid[i][0]`

- ##### **起点** (`0,0`)：`dp[0][0] = grid[0][0]`

### 3. 初始状态

```
dp[0][0] = grid[0][0]
```

# 完整代码（原地修改，空间 O(1)）

```c++
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size();        // 行数
        int n = grid[0].size();     // 列数
        
        // 初始化第一行：只能从左往右走，累加
        for (int j = 1; j < n; j++) /从1开始，因为边界的[0]的值就是原值
        {
            grid[0][j] += grid[0][j-1];
        }
        
        // 初始化第一列：只能从上往下走，累加
        for (int i = 1; i < m; i++)//从1开始，因为边界的[0]的值就是原值
        {
            grid[i][0] += grid[i-1][0];
        }
        
        // 填充其余位置
        for (int i = 1; i < m; i++) /从1开始，因为边界的[0]的值就是原值
        {
            for (int j = 1; j < n; j++) /从1开始，因为边界的[0]的值就是原值
            {
                // 当前格子的值 + min(上方最小和, 左方最小和)
                grid[i][j] += min(grid[i-1][j], grid[i][j-1]);
            }
        }
        
        // 右下角即为答案
        return grid[m-1][n-1];
    }
};
```
