# LeetCode 240. 搜索二维矩阵 II —— 左下角/右上角搜索法学习笔记

> **题目**: [240. Search a 2D Matrix II](https://leetcode.cn/problems/search-a-2d-matrix-ii/)  
> **核心**: 编写一个高效的算法来搜索 `m × n` 矩阵 `matrix` 中的目标值 `target`。该矩阵具有以下特性：  
> - **每行**的元素从左到右升序排列  
> - **每列**的元素从上到下升序排列  
> **示例**:  
> ```
> matrix = [[1,  4,  7, 11, 15],
>           [2,  5,  8, 12, 19],
>           [3,  6,  9, 16, 22],
>           [10, 13, 14, 17, 24],
>           [18, 21, 23, 26, 30]]
> target = 5  → 返回 true
> target = 20 → 返回 false
> ```

---

## 一、核心思想：利用矩阵的单调性，从"特殊点"出发

### 1.1 为什么暴力搜索效率低？
矩阵有 `m × n` 个元素，暴力遍历需要 $O(mn)$ 时间，没有利用"行有序、列有序"的特性。

### 1.2 矩阵的单调性特征
由于每行从左到右递增、每列从上到下递增，矩阵具有以下性质：
- 对于任意元素 `matrix[i][j]`：
  - 它的**左边**和**上边**的所有元素都 **≤** 它；
  - 它的**右边**和**下边**的所有元素都 **≥** 它。

### 1.3 关键洞察：从左下角或右上角出发

如果从**左下角** `(m-1, 0)` 开始搜索：
- 向上移动 (`i--`) → 元素变小；
- 向右移动 (`j++`) → 元素变大。

这意味着：对于当前元素 `matrix[i][j]`，我们可以根据它与 `target` 的大小关系，**确定地排除一整行或一整列**！

```
从左下角 (m-1, 0) 出发:

    当前值 > target ? 向上走 (i--)     当前值 < target ? 向右走 (j++)
         ↓                                   ↓
    排除当前行下方所有元素               排除当前列左边所有元素
    (它们都更大)                         (它们都更小)
```

同理，从**右上角** `(0, n-1)` 出发也成立：
- 向下移动 (`i++`) → 元素变大；
- 向左移动 (`j--`) → 元素变小。

> ⚠️ **为什么不能从左上角或右下角出发？**  
> 从左上角出发时，向下和向右都是变大，无法确定该往哪边走；从右下角出发时，向上和向左都是变小，同样无法确定方向。只有**左下角和右上角**具有"一个方向变大、一个方向变小"的特性。

## 二、代码实现（带完整注释）

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        // ========== 步骤1：从左下角开始 ==========
        // i 指向最后一行（矩阵底部），j 指向第一列（矩阵最左）
        int i = matrix.size() - 1;      // 行指针，初始在最后一行
        int j = 0;                       // 列指针，初始在第一列

        // ========== 步骤2：在有效范围内搜索 ==========
        // 循环条件：行指针不能越过上边界，列指针不能越过右边界
        while (i >= 0 && j < matrix[0].size()) {

            if (matrix[i][j] > target) {
                // 当前值比目标大：说明当前行从 j 开始到最右的所有元素都 ≥ 当前值 > target
                // 因此 target 不可能在当前行（及以下行），向上移动一行
                i--;
            } 
            else if (matrix[i][j] < target) {
                // 当前值比目标小：说明当前列从 0 开始到 i 的所有元素都 ≤ 当前值 < target
                // 因此 target 不可能在当前列（及左边列），向右移动一列
                j++;
            } 
            else {
                // 当前值等于目标值，找到了！
                return true;
            }
        }

        // ========== 步骤3：搜索完毕，未找到 ==========
        // 循环结束时，i 或 j 已经越界，说明 target 不在矩阵中
        return false;
    }
};
```

### 等价写法：从右上角出发

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int i = 0;                              // 从第一行开始
        int j = matrix[0].size() - 1;           // 从最后一列开始

        while (i < matrix.size() && j >= 0) {
            if (matrix[i][j] > target) {
                j--;                            // 当前值太大，向左移动（排除当前列）
            } 
            else if (matrix[i][j] < target) {
                i++;                            // 当前值太小，向下移动（排除当前行）
            } 
            else {
                return true;
            }
        }
        return false;
    }
};
```

> 两种写法完全等价，只是出发点和移动方向不同。面试时写哪一种都可以，但建议固定一种熟练的写法。

## 三、逐步推演示例

### 示例 1：找到目标值
```
matrix = [[1,  4,  7, 11, 15],
          [2,  5,  8, 12, 19],
          [3,  6,  9, 16, 22],
          [10, 13, 14, 17, 24],
          [18, 21, 23, 26, 30]]
target = 5
```

**初始位置**: `i = 4, j = 0`（左下角，值为 18）

| 轮次 | (i, j) | matrix[i][j] | 与 target 比较 | 决策 | 原因 | 排除区域 |
|:----:|:------:|:------------:|:-------------:|:----:|:----:|:--------:|
| 1 | (4, 0) | 18 | 18 > 5 | `i--` | 18太大，当前行下方无更小的 | 第4行全部 |
| 2 | (3, 0) | 10 | 10 > 5 | `i--` | 10太大，向上找更小的 | 第3行全部 |
| 3 | (2, 0) | 3 | 3 < 5 | `j++` | 3太小，向右找更大的 | 第0列第2行及以下 |
| 4 | (2, 1) | 6 | 6 > 5 | `i--` | 6太大，向上找更小的 | 第2行第1列及以右 |
| 5 | (1, 1) | **5** | 5 == 5 | `return true` | **找到了！** | — |

**搜索路径**: `(4,0)=18` → `(3,0)=10` → `(2,0)=3` → `(2,1)=6` → `(1,1)=5` ✓

## 四、正确性证明

### 4.1 为什么每次可以排除一整行或一整列？

以从左下角出发为例：

**情况 A：当前值 `matrix[i][j] > target`**
- 由于第 `j` 列从上到下递增，`matrix[i][j]` 是该列从第 `i` 行到最底行的**最小值**；
- 既然最小值都大于 `target`，那么第 `i` 行从第 `j` 列到最右列的所有元素（都 ≥ `matrix[i][j]`）也必然大于 `target`；
- 同时，第 `i` 行以下的所有元素（在同一列或更右列）也都 ≥ `matrix[i][j]`；
- 因此，**第 `i` 行及以下、第 `j` 列及以右**的区域可以全部排除。

**情况 B：当前值 `matrix[i][j] < target`**
- 由于第 `i` 行从左到右递增，`matrix[i][j]` 是该行从第 0 列到第 `j` 列的**最大值**；
- 既然最大值都小于 `target`，那么第 `j` 列从第 0 行到第 `i` 行的所有元素（都 ≤ `matrix[i][j]`）也必然小于 `target`；
- 同时，第 `j` 列以左的所有元素（在同一行或更上行）也都 ≤ `matrix[i][j]`；
- 因此，**第 `j` 列及以左、第 0 行到第 `i` 行**的区域可以全部排除。

### 4.2 搜索空间的几何解释

```
初始搜索空间: 整个 m×n 矩阵
             ┌─────────────┐
             │             │
             │   搜索区    │
             │             │
             └─────────────┘

matrix[i][j] > target:    matrix[i][j] < target:
排除下方区域              排除左方区域

    ┌─────────┐              ┌────┬──────┐
    │ 搜索区  │              │排  │ 搜索 │
    │ ○ > tar │              │除  │ 区   │
    ├─────────┤              │区  │ ○<tar│
    │  排除   │              └────┴──────┘
    └─────────┘
```

每次移动指针，搜索空间就减少一行或一列，最终要么找到目标，要么搜索空间为空（指针越界）。

## 五、与其他搜索方法的对比

| 方法 | 时间复杂度 | 空间复杂度 | 核心思想 | 适用场景 |
|:----:|:---------:|:---------:|:--------:|:--------:|
| **暴力遍历** | $O(mn)$ | $O(1)$ | 逐个检查 | 不考虑 |
| **逐行二分** | $O(m \log n)$ | $O(1)$ | 每行做二分查找 | 只利用行有序 |
| **逐列二分** | $O(n \log m)$ | $O(1)$ | 每列做二分查找 | 只利用列有序 |
| **左下角/右上角搜索** ⭐ | $O(m + n)$ | $O(1)$ | 利用行列双重有序，逐步排除 | **最优解** |

### 为什么 $O(m+n)$ 比 $O(m \log n)$ 更好？
- 最坏情况下，指针从一角走到对角，最多走 `m + n - 1` 步；
- 二分查找虽然单步更快，但需要 `m` 次二分，总计 $O(m \log n)$；
- 当 `m` 和 `n` 都很大时，$m + n$ 远小于 $m \log n$。

## 六、复杂度分析

| 维度 | 结果 |
|------|------|
| **时间复杂度** | $O(m + n)$ —— 最坏情况下从一角走到对角，最多 `m + n` 步 |
| **空间复杂度** | $O(1)$ —— 只用了 `i` 和 `j` 两个指针 |

## 七、易错点与面试 Tips

### ❌ 错误 1：从左上角或右下角出发
```cpp
// 错误！从左上角出发无法确定方向
int i = 0, j = 0;
// matrix[i][j] < target 时，向下和向右都是变大，不知道该往哪走
```

### ❌ 错误 2：循环条件写错
```cpp
// 左下角出发的正确条件
while (i >= 0 && j < matrix[0].size())

// 右上角出发的正确条件
while (i < matrix.size() && j >= 0)
```

### ❌ 错误 3：matrix 为空或空行的边界情况
```cpp
// 虽然本题通常保证非空，但严谨写法应加上：
if (matrix.empty() || matrix[0].empty()) return false;
```

### ❌ 错误 4：移动方向搞反
```cpp
// 左下角出发：
// 值太大 → 向上（i--）不是向下！
// 值太小 → 向右（j++）不是向左！
if (matrix[i][j] > target) i--;   // ✅ 向上
if (matrix[i][j] < target) j++;   // ✅ 向右
```

### ✅ 面试回答框架
1. **思路**：利用矩阵行列双重有序的特性，从左下角（或右上角）出发；
2. **规则**：当前值大则向上（排除当前行下方），当前值小则向右（排除当前列左方）；
3. **复杂度**：时间 $O(m+n)$，空间 $O(1)$；
4. **为什么最优**：每次排除一行或一列，比逐行二分 $O(m \log n)$ 更优。

### ✅ 追问准备
- **问**：如果矩阵只行有序、列无序怎么办？  
  **答**：只能逐行二分，$O(m \log n)$。
- **问**：如果矩阵是杨氏矩阵（Young Tableau）呢？  
  **答**：左下角搜索法就是杨氏矩阵的标准搜索算法。

## 八、一句话总结

> **从左下角出发，当前值大了就往上走（排除下方所有），当前值小了就往右走（排除左方所有），一路走一路丢，直到找到目标或走出边界。**

| 要点 | 内容 |
|------|------|
| 出发点 | 左下角 `(m-1, 0)` 或 右上角 `(0, n-1)` |
| 核心策略 | 利用行列双重单调性，每次排除一整行或一整列 |
| 移动规则 | `> target` → 向上 (`i--`)；`< target` → 向右 (`j++`) |
| 终止条件 | 找到目标 或 指针越界 |
| 时间复杂度 | $O(m + n)$ |
| 空间复杂度 | $O(1)$ |
| 关键限制 | 必须从"一个方向变大、一个方向变小"的角出发 |
