# 七、数据序列化

## 01 protobuf、json、xml 区别

| 维度     | Protobuf                        | JSON                    | XML                        |
| :------- | :------------------------------ | :---------------------- | :------------------------- |
| 存储格式 | 二进制（不可读）                | 文本键值对（易读）      | 文本标签嵌套（繁琐）       |
| 性能     | 序列化 / 反序列化最快，体积最小 | 中等（文本解析开销）    | 最慢，体积最大（标签冗余） |
| 类型系统 | 强类型（.proto 定义）           | 弱类型（无原生类型）    | 强类型（XSD 定义，复杂）   |
| 兼容性   | 天然支持前后兼容（字段编号）    | 无官方兼容机制          | 兼容但配置复杂             |
| 核心场景 | 后端高性能通信（微服务 / 游戏） | 前后端交互、RESTful API | 传统企业应用、老配置文件   |
