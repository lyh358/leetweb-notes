# LeetCode 53. 最大子数组和 —— 四种解法学习笔记

> **题目**: [53. Maximum Subarray](https://leetcode.cn/problems/maximum-subarray/)  
> **核心**: 给定整数数组 `nums`，找出一个具有最大和的**连续子数组**（子数组最少包含一个元素），返回其最大和。  
> **示例**: `nums = [-2,1,-3,4,-1,2,1,-5,4]` → 最大子数组为 `[4,-1,2,1]`，和为 `6`。

---

## 一、暴力枚举法（Brute Force）

### 核心思想
枚举所有可能的子数组起点 `i` 和终点 `j`，计算每个子数组的和，取最大值。

### 代码实现

```cpp
class Solution {
public:
    int maxSubArray(vector<int> &nums) {
        // 类似寻找最大最小值的题目，初始值一定要定义成理论上的最小最大值
        int max = INT_MIN;
        int numsSize = int(nums.size());
        for (int i = 0; i < numsSize; i++) {
            int sum = 0;
            for (int j = i; j < numsSize; j++) {
                sum += nums[j];
                if (sum > max) {
                    max = sum;
                }
            }
        }
        return max;
    }
};
```

### 关键点
- **外层循环** `i`：确定子数组的起点。
- **内层循环** `j`：从起点 `i` 向后扩展，累加得到 `sum`。
- **初始值** `INT_MIN`：确保任何数组元素都能更新它。

### 复杂度分析
| 维度 | 结果 |
|------|------|
| 时间复杂度 | $O(n^2)$ —— 两层循环，枚举所有子数组 |
| 空间复杂度 | $O(1)$ —— 只用了常数个变量 |

### 适用场景
- 数组长度 $n \leq 10^3$ 时可用。
- 面试中作为基础思路提及，但通常需要优化到 $O(n)$ 或 $O(n \log n)$。

## 二、动态规划法（Dynamic Programming / Kadane's Algorithm）

### 核心思想
定义 `dp[i]` 为**以第 `i` 个元素结尾**的连续子数组的最大和。状态转移方程：

$$dp[i] = \max(dp[i-1] + nums[i], \; nums[i])$$

- 如果 `dp[i-1]` 为正，则接上去更优；
- 如果 `dp[i-1]` 为负，则从 `nums[i]` 重新开始更优。

### 代码实现（空间优化版）

```cpp
class Solution {
public:
    int maxSubArray(vector<int> &nums) {
        int result = INT_MIN;
        int numsSize = int(nums.size());
        // 因为只需要知道dp的前一项，我们用int代替一维数组
        int dp = nums[0];
        result = dp;
        for (int i = 1; i < numsSize; i++) {
            dp = max(dp + nums[i], nums[i]);
            result = max(result, dp);
        }
        return result;
    }
};
```

### 关键点
- **状态压缩**：因为 `dp[i]` 只依赖 `dp[i-1]`，用一个变量 `dp` 滚动更新即可，空间从 $O(n)$ 降到 $O(1)$。
- **`result` 的更新时机**：每次计算完 `dp` 后，立即用 `max(result, dp)` 更新全局最大值。
- **初始化**：`dp = nums[0]`，`result = dp`，从第二个元素开始遍历。

### 复杂度分析
| 维度 | 结果 |
|------|------|
| 时间复杂度 | $O(n)$ —— 只需遍历一次 |
| 空间复杂度 | $O(1)$ —— 仅用两个变量 |

### 与贪心的关系
DP 和贪心在此题中本质上是**同一算法的两种表达**。DP 更强调"状态转移"的视角，贪心更强调"累加和为负则丢弃"的直觉。

## 三、贪心算法（Greedy / 最优子结构）

### 核心思想
从左到右遍历，维护一个**当前累加和 `sum`**：
1. 每次将 `nums[i]` 加入 `sum`；
2. 用 `sum` 更新全局最大值 `result`；
3. **如果 `sum < 0`，则果断将 `sum` 清零**，从下一个位置重新开始累加。

### 代码实现

```cpp
class Solution {
public:
    int maxSubArray(vector<int> &nums) {
        int result = INT_MIN;
        int numsSize = int(nums.size());
        int sum = 0;
        for (int i = 0; i < numsSize; i++) {
            sum += nums[i];
            result = max(result, sum);
            // 如果sum < 0，重新开始找子序串
            if (sum < 0) {
                sum = 0;
            }
        }
        return result;
    }
};
```

### 为什么 `sum < 0` 就要清零？—— 正确性证明

**核心命题**：如果当前累加和 `sum` 已经变为负数，那么**以当前位置结尾的任何子数组，都不可能成为最优解的一部分**（从更后面的位置重新开始一定更优）。

下面分情况讨论，用具体例子说明：

#### 情况一：数组全为正数
**示例**: `nums = [1, 2, 3, 4]`

| i | nums[i] | sum (累加前) | sum += nums[i] | result | sum < 0? |
|---|---------|--------------|----------------|--------|----------|
| 0 | 1 | 0 | 1 | 1 | 否 |
| 1 | 2 | 1 | 3 | 3 | 否 |
| 2 | 3 | 3 | 6 | 6 | 否 |
| 3 | 4 | 6 | 10 | 10 | 否 |

**结论**：`sum` 永远不会变负，一直累加即可，最终得到整个数组的和 `10`，正确。

#### 情况二：数组全为负数
**示例**: `nums = [-3, -2, -5, -1]`

| i | nums[i] | sum (累加前) | sum += nums[i] | result | sum < 0? | 操作 |
|---|---------|--------------|----------------|--------|----------|------|
| 0 | -3 | 0 | -3 | -3 | **是** | sum = 0 |
| 1 | -2 | 0 | -2 | -2 | **是** | sum = 0 |
| 2 | -5 | 0 | -5 | -2 | **是** | sum = 0 |
| 3 | -1 | 0 | -1 | -1 | **是** | sum = 0 |

**结论**：每次加入负数后 `sum` 立即变负，被清零。`result` 记录的是"相对最大"的负数 `-1`（即数组中最大的单个元素），正确。

> ⚠️ **注意**：这里 `sum` 被清零后，下一次循环 `sum` 从 `0` 开始加 `nums[i]`，所以 `result` 能正确捕获每个单独元素。

#### 情况三：正负交替，但累加和始终为正
**示例**: `nums = [1, -2, 3, 4]`

| i | nums[i] | sum (累加前) | sum += nums[i] | result | sum < 0? | 操作 |
|---|---------|--------------|----------------|--------|----------|------|
| 0 | 1 | 0 | 1 | 1 | 否 | — |
| 1 | -2 | 1 | -1 | 1 | **是** | sum = 0 |
| 2 | 3 | 0 | 3 | 3 | 否 | — |
| 3 | 4 | 3 | 7 | 7 | 否 | — |

**过程分析**：
- 到 `i=1` 时，`sum = -1 < 0`。如果不清零，继续往后加：`[-2, 3, 4]` 的和是 `5`；但如果从 `3` 重新开始，`[3, 4]` 的和是 `7`。**显然 `7 > 5`**。
- 原因在于：`-1` 是一个"负担"，带着它只会让后面的正数贡献被抵消。清零相当于"断舍离"，从下一个正数重新开始。

**结论**：清零后得到更优解 `[3, 4]`，和为 `7`，正确。

#### 情况四：正负交替，累加和先正后负
**示例**: `nums = [3, -1, -2, 4, -1, 2]`

| i | nums[i] | sum (累加前) | sum += nums[i] | result | sum < 0? | 操作 |
|---|---------|--------------|----------------|--------|----------|------|
| 0 | 3 | 0 | 3 | 3 | 否 | — |
| 1 | -1 | 3 | 2 | 3 | 否 | — |
| 2 | -2 | 2 | 0 | 3 | 否 | — |
| 3 | 4 | 0 | 4 | 4 | 否 | — |
| 4 | -1 | 4 | 3 | 4 | 否 | — |
| 5 | 2 | 3 | 5 | 5 | 否 | — |

**过程分析**：
- `i=2` 时 `sum = 0`，**不满足 `< 0`**，所以不清零。
- 到 `i=3` 时，`sum = 0 + 4 = 4`。这等价于从 `4` 开始新子数组，与 `[3, -1, -2, 4]` 的和相同（都是 `4`）。
- 如果 `sum` 在 `i=2` 时清零（即把 `0` 也视为负），结果不变，但逻辑上 `0` 不是负担，可以保留。

**结论**：`sum = 0` 时不清零是合理的，因为 `0` 不会拖累后面的和。最终最优解 `[4, -1, 2]` 和为 `5`，正确。

#### 情况五：经典力扣示例
**示例**: `nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]`

| i | nums[i] | sum (累加前) | sum += nums[i] | result | sum < 0? | 操作 |
|---|---------|--------------|----------------|--------|----------|------|
| 0 | -2 | 0 | -2 | -2 | **是** | sum = 0 |
| 1 | 1 | 0 | 1 | 1 | 否 | — |
| 2 | -3 | 1 | -2 | 1 | **是** | sum = 0 |
| 3 | 4 | 0 | 4 | 4 | 否 | — |
| 4 | -1 | 4 | 3 | 4 | 否 | — |
| 5 | 2 | 3 | 5 | 5 | 否 | — |
| 6 | 1 | 5 | 6 | **6** | 否 | — |
| 7 | -5 | 6 | 1 | 6 | 否 | — |
| 8 | 4 | 1 | 5 | 6 | 否 | — |

**最优子数组**: `[4, -1, 2, 1]`，和为 `6`。贪心法正确找到。

### 贪心策略的本质总结

```
当前累加和 sum 就像你手里的"筹码"
├─ sum > 0: 手里有正筹码，继续加注（往后扩展）可能更优
├─ sum = 0: 不赚不亏，可以保留，继续观望
└─ sum < 0: 手里是负筹码，是累赘！果断清零，从下一个位置重新开始
```

**关键洞察**：一个负的 `sum` 对后续元素只有"拖后腿"的作用。假设当前 `sum = -5`，下一个元素是 `x`，那么：
- 带着 `-5` 继续：总贡献 = `-5 + x`
- 清零后重新开始：总贡献 = `0 + x = x`

显然 `x > x - 5`，所以**清零永远更优**。

### 复杂度分析
| 维度 | 结果 |
|------|------|
| 时间复杂度 | $O(n)$ —— 单次遍历 |
| 空间复杂度 | $O(1)$ —— 仅用两个变量 |

## 四、分治法（Divide and Conquer）

### 核心思想
将数组从中间 `mid` 切分，最大子数组和只可能出现在三个位置之一：
1. **完全在左半部分** → 递归求解 `leftSum`
2. **完全在右半部分** → 递归求解 `rightSum`
3. **跨越中点** → 从 `mid` 向左扩展的最大后缀和 + 从 `mid+1` 向右扩展的最大前缀和

最终答案 = `max(leftSum, rightSum, midSum)`

### 代码实现

```cpp
class Solution {
public:
    int maxSubArray(vector<int> &nums) {
        int result = INT_MIN;
        int numsSize = int(nums.size());
        result = maxSubArrayHelper(nums, 0, numsSize - 1);
        return result;
    }

    int maxSubArrayHelper(vector<int> &nums, int left, int right) {
        if (left == right) {
            return nums[left];
        }
        int mid = (left + right) / 2;
        int leftSum = maxSubArrayHelper(nums, left, mid);
        // 注意这里应是mid + 1，否则left + 1 = right时，会无限循环
        int rightSum = maxSubArrayHelper(nums, mid + 1, right);
        int midSum = findMaxCrossingSubarray(nums, left, mid, right);
        int result = max(leftSum, rightSum);
        result = max(result, midSum);
        return result;
    }

    int findMaxCrossingSubarray(vector<int> &nums, int left, int mid, int right) {
        int leftSum = INT_MIN;
        int sum = 0;
        for (int i = mid; i >= left; i--) {
            sum += nums[i];
            leftSum = max(leftSum, sum);
        }

        int rightSum = INT_MIN;
        sum = 0;
        // 注意这里i = mid + 1，避免重复用到nums[i]
        for (int i = mid + 1; i <= right; i++) {
            sum += nums[i];
            rightSum = max(rightSum, sum);
        }
        return (leftSum + rightSum);
    }
};
```

### 关键点
- **递归终止条件**：`left == right` 时返回单个元素。
- **中点分割**：`mid = (left + right) / 2`，右半部分必须从 `mid + 1` 开始，否则当区间长度为 2 时会死循环。
- **跨越中点的子数组**：
  - 左半部分从 `mid` **向左**扫描，找最大后缀和；
  - 右半部分从 `mid + 1` **向右**扫描，找最大前缀和；
  - 两者相加即为跨越中点的最大子数组和。
- **避免重复**：右半部分从 `mid + 1` 开始，确保 `nums[mid]` 不被重复计算。

### 复杂度分析
| 维度 | 结果 |
|------|------|
| 时间复杂度 | $O(n \log n)$ —— 递归树高度 $\log n$，每层 $O(n)$ |
| 空间复杂度 | $O(\log n)$ —— 递归栈深度 |

### 适用场景
- 面试中展示对递归和分治思想的掌握。
- 作为学习**归并排序思想**的延伸练习。
- 实际工程中通常不如 DP/贪心高效，但思想重要。

## 五、四种方法对比总结

| 方法 | 时间复杂度 | 空间复杂度 | 核心思想 | 推荐指数 |
|------|-----------|-----------|----------|----------|
| **暴力枚举** | $O(n^2)$ | $O(1)$ | 枚举所有子数组 | ⭐ 面试提及即可 |
| **动态规划** | $O(n)$ | $O(1)$ | 状态转移：接或不接 | ⭐⭐⭐ 标准解法 |
| **贪心算法** | $O(n)$ | $O(1)$ | 负和清零，断舍离 | ⭐⭐⭐ 最直观 |
| **分治法** | $O(n \log n)$ | $O(\log n)$ | 左/右/跨中点三者取最大 | ⭐⭐ 思想训练 |

### 关于 DP 与贪心的关系
在本题中，**DP 和贪心是等价的**，只是叙述角度不同：
- **DP 视角**：关注"以 `i` 结尾的最大子数组和"这个状态；
- **贪心视角**：关注"当前累加和是否为负"这个决策点。

两者代码几乎相同，只是变量命名和更新顺序略有差异。面试时推荐用 **DP（Kadane's Algorithm）** 表述，因为"状态转移"更容易形式化证明。

## 六、易错点与面试 Tips

1. **初始值设为 `INT_MIN`**  
   不要设为 `0`，否则全负数组会返回 `0` 而错误。

2. **贪心法中 `sum < 0` 才清零，不是 `sum <= 0`**  
   `sum = 0` 时清零不影响正确性，但会多断一次。保留 `sum = 0` 可以连接后面相等的解。

3. **分治法中右递归的起点是 `mid + 1`**  
   写成 `mid` 会导致无限循环或重复计算。

4. **跨越中点的子数组必须包含 `mid` 和 `mid+1`**  
   这是"跨越"的定义，左右扫描不能跳过中点。

5. **面试推荐回答顺序**：先讲暴力 $O(n^2)$ → 优化到 DP/贪心 $O(n)$ → 提一下分治 $O(n \log n)$ 展示广度。
