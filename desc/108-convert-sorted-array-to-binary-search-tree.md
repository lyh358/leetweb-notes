# 力扣 108：将有序数组转换为二叉搜索树学习笔记

## 一、 题目核心解析

**题目描述**：给你一个整数数组 `nums`，其中元素已经按升序排列，请你将其转换为一棵高度平衡的二叉搜索树（BST）。
**核心定义**：
1. **二叉搜索树（BST）**：对于树中的每个节点，左子树的所有节点值都小于它，右子树的所有节点值都大于它。
2. **高度平衡**：一个二叉树每个节点的左右两个子树的高度差的绝对值不超过 1。

**关键示例**：
输入：`nums = [-10,-3,0,5,9]`
为了让树平衡，我们选择中间元素 `0` 作为根节点，左边的 `[-10,-3]` 构成左子树，右边的 `[5,9]` 构成右子树。
