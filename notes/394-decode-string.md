

# 思路：遇到括号匹配->栈

# 方法：双栈法

- ## ==两个栈：分别存左括号前的数字和字母==

- ## ==两个临时变量：如果没遇到左括号就按字符往里存数字和字符==

- ## ==遇到左括号就把字母和数字压入栈，并清空临时变量==

- ## ==遇到右括号就弹出两个栈的栈顶元素，进行翻倍处理==

# 1）数据结构

- ### `stack<int> nums;`储存各层的重复次数（如 3, 2）

- ### `stack<string> strs; `存储各层"["之前的字符串（上下文）

- ### 临时变量

  - #### `string res = "";`当前层正在构建的字符串

  - #### `int num = 0;`当前层累计读取的数字

---

# 2）处理逻辑

## 1.最外层for循环

- ### 处理每一个字符串中的字符

```c++
int len = s.size();

for(int i = 0; i < len; ++ i)
        {
            //其他处理逻辑
        }
return res;
```

## 2.内层处理逻辑

- #### 遇见数字的处理逻辑

  - ##### `num`初始化为0

  - ##### `num*10`用于处理多位数字

  - ##### `s[i] - '0'`用于把字符数字变成整型数字 和 得到首位数字

```c++
 		if(s[i] >= '0' && s[i] <= '9')
            {
                num = num * 10 + s[i] - '0';
            }
```

- #### 遇见字母的处理逻辑

  - ##### 若遇见的是小写字母`(s[i] >= 'a' && s[i] <= 'z')`或者大写字母`(s[i] >= 'A' && s[i] <= 'Z')`

  - ##### 直接把当前字符加入临时字符串res的尾部`res = res + s[i];`

  ```c++
    		else if((s[i] >= 'a' && s[i] <= 'z') ||(s[i] >= 'A' && s[i] <= 'Z'))
              {
                  res = res + s[i];
              }
  ```

- #### 遇见左括号 ’[‘ 的处理逻辑

  - ##### 如果遇见左括号`else if(s[i] == '[') `

  - ##### 将当前的`num`临时变量压入`nums.push(num);`，然后将其清零`num = 0;`

  - ##### 将当前的`res`临时变量压入` strs.push(res); `，然后将其清空`res = "";`

  ```c++
   		 else if(s[i] == '[') 
              {
                  nums.push(num);
                  num = 0;
                  strs.push(res); 
                  res = "";
              }
  ```

- #### 遇见右括号 ’]’ 的处理逻辑

  - ##### 拿出上一个存入栈的倍数`int times = nums.top();`，并将其弹出栈`nums.pop();`

  - ##### 利用for循环，对最内层字符串（也就是该倍数对应的字符串）进行翻倍操作，然后加到`strs`栈中上一层字符串的尾部

  - ##### 这样在遇到右括号时最内层字符串乘完倍数再加到次内层字符串上进行翻倍

  ```c++
   		 else //遇到‘]’时，操作与之相配的‘[’之间的字符，使用分配律
              {
                  int times = nums.top();
                  nums.pop();
                  for(int j = 0; j < times; ++ j)
                  {
  					strs.top() += res;
                  }
               
                  res = strs.top();//res更新为合并后的完整字符串
                  strs.pop();//弹出已用过的字符串
              }        
  ```

# 完整代码

```c++
class Solution {
public:
    string decodeString(string s) 
    {
        //数据结构
        string res = "";
        stack <int> nums;
        stack <string> strs;
        int num = 0;
        int len = s.size();
        
        //处理每个字符
        for(int i = 0; i < len; ++ i)
        {
            //数字处理
            if(s[i] >= '0' && s[i] <= '9')
            {
                num = num * 10 + s[i] - '0';
            }
            
            //字母处理
            else if((s[i] >= 'a' && s[i] <= 'z') ||(s[i] >= 'A' && s[i] <= 'Z'))
            {
                res = res + s[i];
            }
            
            //左括号处理
            else if(s[i] == '[') 
            {
                nums.push(num);
                num = 0;
                strs.push(res); 
                res = "";
            }
            
            //右括号处理
            else 
            {
                int times = nums.top();
                nums.pop();
                for(int j = 0; j < times; ++ j)
                    strs.top() += res;
                res = strs.top(); 
                strs.pop();
            }
        }
        //返回结果字符串
        return res;
    }
};
```

# 详细流程推导

## 完整执行流程

输入：`s = "3[a2[bc]]"`

### 阶段一：遇到第一个 `]` 之前（处理内层 `2[bc]`）

| i    | 字符 | 操作       | nums 栈 | strs 栈    | res    | 说明                      |
| :--- | :--- | :--------- | :------ | :--------- | :----- | :------------------------ |
| 0    | `3`  | `num=3`    | `[]`    | `[]`       | `""`   | 累积数字                  |
| 1    | `[`  | 压栈，重置 | `[3]`   | `[""]`     | `""`   | 保存外层上下文            |
| 2    | `a`  | `res+="a"` | `[3]`   | `[""]`     | `"a"`  | 累积字母                  |
| 3    | `2`  | `num=2`    | `[3]`   | `[""]`     | `"a"`  | 新数字（内层）            |
| 4    | `[`  | 压栈，重置 | `[3,2]` | `["","a"]` | `""`   | **关键**：`strs`压入`"a"` |
| 5    | `b`  | `res+="b"` | `[3,2]` | `["","a"]` | `"b"`  | 内层字母                  |
| 6    | `c`  | `res+="c"` | `[3,2]` | `["","a"]` | `"bc"` | 内层字母                  |

**此刻状态**：

- `nums = [3, 2]`（3是外层的，2是内层的）
- `strs = ["", "a"]`（`""`是外层`[`前的，`"a"`是内层`[`前的）
- `res = "bc"`（当前`[`和`]`之间的内容）

------

### 阶段二：遇到第一个 `]`（i=7，处理内层 `2[bc]`）

```cpp
else {  // s[i] == ']'
    int times = nums.top();      // times = 2（内层的重复次数）
    nums.pop();                   // nums 变成 [3]
    
    for(int j = 0; j < times; ++j)
        strs.top() += res;        // strs.top()是"a"，res是"bc"
                                  // "a" + "bc" + "bc" = "abcbc"
    
    res = strs.top();             // res = "abcbc"（合并后的结果）
    strs.pop();                   // strs 变成 [""]
}
```

**逐行执行**：

| 代码                     | 执行效果        | 解释                                  |
| :----------------------- | :-------------- | :------------------------------------ |
| `times = nums.top()`     | `times = 2`     | 取内层重复次数                        |
| `nums.pop()`             | `nums = [3]`    | 弹出已用的2                           |
| `strs.top() += res` 循环 | `"a" → "abcbc"` | `"a" + "bc" + "bc"`                   |
| `res = strs.top()`       | `res = "abcbc"` | **关键**：res更新为合并后的完整字符串 |
| `strs.pop()`             | `strs = [""]`   | 弹出已用的`"a"`                       |

**此刻状态**：

- `res = "abcbc"`（内层 `2[bc]` 解码完成，且与前面的 `"a"` 合并）
- 继续遍历...

------

### 阶段三：遇到第二个 `]`（i=8，处理外层 `3[...]`）

此时 `s[7]` 已处理完，继续 `i=8` 遇到 `]`：

**此刻状态**：

- `nums = [3]`（外层的重复次数）
- `strs = [""]`（最外层`[`前是空字符串）
- `res = "abcbc"`（内层解码结果）

```cpp
else {  // 第二个 ]
    int times = nums.top();      // times = 3
    nums.pop();                   // nums 变成 []
    
    for(int j = 0; j < 3; ++j)
        strs.top() += res;        // strs.top()是""，res是"abcbc"
                                  // "" + "abcbc"*3 = "abcbcabcbcabcbc"
    
    res = strs.top();             // res = "abcbcabcbcabcbc"
    strs.pop();                   // strs 变成 []
}
```

**最终结果**：`"abcbcabcbcabcbc"`

------

## 关键逻辑图解

```plain
3[ a 2[bc] ]
│  │ │    │
│  │ │    └── 遇到 ]，弹出 times=2, 前缀="a"
│  │ │         "a" + "bc"*2 = "abcbc"
│  │ │         res = "abcbc"
│  │ │
│  └──┴──────── 遇到 ]，弹出 times=3, 前缀=""
│                "" + "abcbc"*3 = "abcbcabcbcabcbc"
│                res = 最终结果
└────────────── 返回 res
```

------

## 核心要点总结

| 要点               | 解释                                                         |
| :----------------- | :----------------------------------------------------------- |
| **分配律**         | `a2[bc] = a + bc*2`，前缀 `a` 保持不变，只重复括号内内容     |
| **res 的双重身份** | 遇到 `]` 前：`res` 是当前括号内的内容；遇到 `]` 后：`res` 是合并后的完整结果 |
| **strs 的作用**    | 保存"**前缀**"（`[`之前的字符串），等待括号内结果出来后拼接  |
| **同层拼接**       | 注释说的"同一级运算"：`res = "abcbc"` 后，如果后面还有字母如 `d`，会直接变成 `"abcbcd"` |
