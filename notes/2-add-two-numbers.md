# LeetCode 2 - 两数相加（Add Two Numbers）

> **标签**：链表、数学、模拟  
> **难度**：中等  
> **核心考点**：链表遍历、进位处理、虚拟头节点

---

## 一、题目描述

给你两个**非空**的链表，表示两个非负整数。它们每位数字都是按照**逆序**的方式存储的，并且每个节点只能存储**一位**数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

**示例**：
```
输入: l1 = [2, 4, 3], l2 = [5, 6, 4]
输出: [7, 0, 8]
解释: 342 + 465 = 807，逆序存储为 [7, 0, 8]

输入: l1 = [0], l2 = [0]
输出: [0]

输入: l1 = [9, 9, 9, 9, 9, 9, 9], l2 = [9, 9, 9, 9]
输出: [8, 9, 9, 9, 0, 0, 0, 1]
```

---

## 二、核心思路：模拟加法

### 2.1 为什么可以逐位相加？

因为数字是**逆序存储**的，链表头就是**个位**，正好符合加法从低位到高位的顺序。

```
  2 → 4 → 3    表示 342
+ 5 → 6 → 4    表示 465
-----------------
  7 → 0 → 8    表示 807

计算过程:
个位: 2 + 5 = 7
十位: 4 + 6 = 10 → 写 0，进 1
百位: 3 + 4 + 1(进位) = 8
```

### 2.2 关键变量

| 变量 | 作用 |
|------|------|
| `carry` | 进位值（0 或 1，因为 9+9+1=19，最大进位是 1） |
| `x` | 链表 l1 当前节点的值（如果节点存在） |
| `y` | 链表 l2 当前节点的值（如果节点存在） |
| `sum` | 当前位的和：`x + y + carry` |
| `cur` | 新链表的当前节点指针 |

## 三、代码实现

### 3.1 你的代码 ⭐

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy(0);          // 创建哑节点，作为 sum 链表的锚点
        ListNode* cur = &dummy;     // 新链表的移动指针
        int carry = 0;              // 初始化进位值

        // 当 l1/l2/进位 都不为空，就继续创建新节点放数
        while (l1 || l2 || carry) {
            // 创建 x, y 储存两个链表当前节点的 val
            int x = l1 ? l1->val : 0;     // l1 节点是 nullptr 吗？是 x=l1 的 val：不是 x=0
            int y = l2 ? l2->val : 0;

            // 计算当前节点和，用于计算新节点的值和下一位进位值
            int sum = x + y + carry;

            carry = sum / 10;              // 进位值，用于下一位

            // 新链表往后新建节点，储存对应和的个位值
            cur->next = new ListNode(sum % 10);
            cur = cur->next;               // 新链表后移

            // 如果 l1/l2 没走完，继续走；走完了就不走了，没走完的走走完的开头补 0
            if (l1) l1 = l1->next;
            if (l2) l2 = l2->next;
        }

        // 返回新链表的头
        // dummy 是节点（struct）不是指针，要用（.）而不是（->）
        return dummy.next;
    }
};
```

## 四、执行流程可视化

```
l1 = [2, 4, 3], l2 = [5, 6, 4]

初始: dummy(0) → nullptr, cur = &dummy, carry = 0

轮次  x     y     sum   carry  新节点   l1      l2      链表状态
----  ----  ----  ----  -----  -------  ------  ------  ------------------
 1    2     5     7     0      7        4→3     6→4    dummy → 7
 2    4     6     10    1      0        3       4       dummy → 7 → 0
 3    3     4     8     0      8        nullptr nullptr dummy → 7 → 0 → 8

l1=null, l2=null, carry=0，循环结束

返回: dummy.next = [7, 0, 8]
```

### 有最终进位的情况

```
l1 = [9, 9], l2 = [1]

轮次  x     y     sum   carry  新节点
----  ----  ----  ----  -----  -------
 1    9     1     10    1      0
 2    9     0     10    1      0
 3    0     0     1     0      1

返回: [0, 0, 1]
```

> **注意**：最后一轮 `l1=null, l2=null, carry=1`，循环条件 `carry` 为真，继续创建节点！

## 六、关键细节解析

### 6.1 循环条件 `l1 || l2 || carry`

| 情况 | 说明 |
|------|------|
| `l1` 不为空 | l1 还有数字没加完 |
| `l2` 不为空 | l2 还有数字没加完 |
| `carry` 不为 0 | 还有进位需要处理 |

**为什么三个都要判断？**

```
情况1: l1=[1,2], l2=[3] → l1 没走完，继续
情况2: l1=[1], l2=[3,4] → l2 没走完，继续
情况3: l1=[9], l2=[1] → 加完有进位 carry=1，继续创建新节点
```

### 6.2 `l1 ? l1->val : 0` 的三目运算

```cpp
int x = l1 ? l1->val : 0;
```

- 如果 `l1` 不为 `nullptr`，取 `l1->val`
- 如果 `l1` 为 `nullptr`，取 `0`（相当于补 0）

**为什么可以补 0？**

因为链表长度不同时，短的链表高位相当于 0：
```
  1 → 2 → 3
+ 4 → 5
---------
  5 → 7 → 3

等价于:
  1 → 2 → 3
+ 4 → 5 → 0
---------
  5 → 7 → 3
```

### 6.3 `sum / 10` 和 `sum % 10`

```cpp
carry = sum / 10;              // 取十位（进位）
cur->next = new ListNode(sum % 10);  // 取个位（当前位）
```

| sum | sum / 10 (carry) | sum % 10 (当前位) |
|-----|-----------------|------------------|
| 7   | 0               | 7                |
| 10  | 1               | 0                |
| 19  | 1               | 9                |

### 6.4 虚拟头节点 `dummy`

```cpp
ListNode dummy(0);      // 栈上分配，自动释放
ListNode* cur = &dummy; // 取地址

// ...

return dummy.next;      // 用 . 访问成员
```

- `dummy` 是**对象**（不是指针），用 `.` 访问成员
- `cur` 是**指针**，用 `->` 访问成员
- 不需要 `delete dummy`，因为它在栈上

## 七、易错点 & 注意

| 坑点 | 说明 |
|------|------|
| **循环条件** | 必须是 `l1 \|\| l2 \|\| carry`，漏了 `carry` 会丢失最后的进位 |
| **三目运算** | `l1 ? l1->val : 0`，不是 `l1->val`（可能空指针） |
| **指针移动** | `if (l1) l1 = l1->next;`，不是直接 `l1 = l1->next`（可能空指针） |
| **返回方式** | `return dummy.next;`，`dummy` 是对象用 `.` |
| **内存分配** | `new ListNode(...)` 创建节点，LeetCode 会自动回收 |

## 八、常见错误分析

### ❌ 错误 1：循环条件漏了 carry

```cpp
// 错误！
while (l1 || l2) {
    // ...
}

// 正确！
while (l1 || l2 || carry) {
    // ...
}
```

> 如果最后有进位（如 99 + 1 = 100），会丢失最后的 1。

### ❌ 错误 2：空指针访问

```cpp
// 错误！
int x = l1->val;  // l1 可能为 nullptr！

// 正确！
int x = l1 ? l1->val : 0;
```

### ❌ 错误 3：返回 dummy 而不是 dummy.next

```cpp
// 错误！
return &dummy;  // 返回了虚拟头节点

// 正确！
return dummy.next;  // 返回真正的头节点
```

### ❌ 错误 4：三目运算符写法错误，导致变量未初始化

```cpp
// 错误！x 和 y 没有被正确赋值
int x;
int y;
l1 ? x = l1->val : 0;   // 当 l1 为 nullptr 时，x 没有被赋值！
l2 ? y = l2->val : 0;   // 当 l2 为 nullptr 时，y 没有被赋值！

int sum = x + y + carry;  // x, y 是垃圾值，sum 也是垃圾值
// 可能导致无限循环，内存超限！
```

**错误原因**：

三目运算符 `?:` 作为**表达式**使用时，如果条件为假，**赋值操作不会执行**，变量保持未初始化状态。

```cpp
l1 ? x = l1->val : 0;
// 解析为: (l1 ? (x = l1->val) : 0)
// 当 l1 为 false 时，整个表达式值为 0，但 x = l1->val 不会执行！
```

**正确写法 1：三目运算符整体赋值**

```cpp
int x = l1 ? l1->val : 0;  // 无论条件真假，x 一定被赋值
int y = l2 ? l2->val : 0;
```

**正确写法 2：if-else 明确赋值**

```cpp
int x, y;
if (l1) x = l1->val;
else    x = 0;

if (l2) y = l2->val;
else    y = 0;
```

**正确写法 3：初始化时给默认值**

```cpp
int x = 0;  // 先初始化
int y = 0;
l1 ? x = l1->val : 0;  // 即使条件为假，x 也是 0
l2 ? y = l2->val : 0;
```

> ⚠️ **核心原则**：C++ 中局部变量不会自动初始化，必须确保每条代码路径都赋值，否则是**未定义行为**（UB），可能表现为垃圾值、崩溃或内存超限。
