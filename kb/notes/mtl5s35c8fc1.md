# 一、汇川

## =={pink}1. C 语言结构体字节对齐，如何消除填充 (padding)字节==

CPU 默认会按照**自然对齐**给结构体插入填充字节，提升内存访问效率；但有时候做协议、二进制报文、寄存器映射时，我们**不要 padding**，需要**紧凑结构体**。

> ⚠️重要警告：
> 
> 
> 1. 取消对齐会产生**非对齐访问**，ARM、Xtensa (ESP32) 非对齐访问有的会崩溃、有的性能暴跌；只适合：网络协议、flash 存储、二进制序列化，**不要用来定义普通运行时变量**。
> 2. 不同编译器语法不一样：GCC (GCC/ESP‑IDF)、MSVC。

## 1.GCC / ESP‑IDF / ARM‑GCC（最常用）

### =={yellow}方式 1：==`__attribute__((packed))` =={yellow}压缩属性==

```cpp
// 整个结构体取消填充，紧凑排列
typedef struct __attribute__((packed)) {
    uint8_t  a;   // 1字节
    uint32_t b;   // 4字节
    uint16_t c;   // 2字节
}my_pkt_t;
// 总大小 = 1+4+2 =7字节，没有padding
```

=={yellow}也可以写在结构体后面==：

```cpp
typedef struct {
    uint8_t  a;
    uint32_t b;
    uint16_t c;
} __attribute__((packed)) my_pkt_t;
```

> `__attribute__((packed))`=={yellow}：告诉编译器==**=={yellow}不要插入任何填充字节==**=={yellow}。==

### 风险点：非对齐访问！

### =={yellow}方式 2：修改对齐字节== `__attribute__((aligned(N)))`

`aligned(N)` 是设置**整个结构体的起始对齐要求**，不是消除 padding；
packed = 等价于 `aligned(1)`，按 1 字节对齐，不填充。

## =={pink}2. 裸机 C 语言实现简易消息队列==

裸机：无操作系统，=={yellow}单主循环 + 中断==，消息队列用于**中断给主循环传递数据**，=={yellow}核心是环形缓冲区==。

核心：**环形 FIFO 数组 + 头指针 head (写)、尾指针 tail (读)**，裸机多用于中断写、主循环读。

1. 开辟一块固定大小数组作为存储缓冲区；定义 head（写入位置）、tail（读出位置）两个变量。
2. 初始化：head=0，tail=0。
3. 判断满：head 向后走一步等于 tail，则队列满。
4. 判断空：head 等于 tail，则队列空。
5. **入队（写）**：队列没满，把数据放到 head 指向位置，head 下标 + 1，超过数组长度就绕回 0。

> 如果中断和主循环都修改同一指针，访问 head/tail 前后加临界区（关中断）。

1. **出队（读）**：队列不为空，读取 tail 位置的数据，tail 下标 + 1，超过数组长度绕回 0。
2. 使用约束：单生产者单消费者可以不用锁；多生产者 / 多消费者必须临界区保护共享指针；队列尽量短，不要存超大块数据。

## =={pink}3. 裸机实现临界区、原子操作==

裸机没有 OS，=={yellow}临界区本质：==**=={yellow}关闭全局中断==**=={yellow}，防止中断打断共享变量读写==。

### 原子操作两种方案

1. **=={yellow}临界区包裹==**=={yellow}：非原子的运算，包进临界区，裸机最通用。==

```scss
ENTER_CRITICAL();
g_val++;
EXIT_CRITICAL();
```

1. **=={yellow}硬件原子指令==**：Cortex‑M3/M4/M7 支持 LDREX/STREX 独占指令，实现无锁原子加减，CMSIS 提供：

```cpp
#include "cmsis_gcc.h"
uint32_t val = __LDREXW(&g_var);
val++;
__STREXW(val, &g_var);
```

> =={green}裸机一般简单场景直接关中断临界区就够用。==

## =={pink}4. ESP32 WebServer服务==

=={pink}整体流程：**初始化 WiFi → 连接 WiFi → 创建 WebServer 实例 → 注册 URL 路由处理函数 → 启动服务器 → 循环调用处理客户端请求**
**创建 WebServer 对象**，指定监听端口，一般用 80 端口。
**初始化串口（可选）**，用于打印 IP、调试信息。
**启动 WiFi 连接**，填入 WiFi 名称密码，调用 WiFi.begin ()，循环等待 WiFi 连接成功。
WiFi 连接成功后，获取 ESP32 本机 IP 地址，串口打印 IP，浏览器后续就访问这个 IP。
**注册路由**：使用`server.on(路径, 回调函数)`。

当浏览器访问对应 URL 路径时，就会触发绑定的回调函数。
可以注册首页`/`、控制 IO 的`/led_on`等多个不同路径。

调用`server.begin()`，正式启动 Web 服务器，开始监听 80 端口的网络请求。
在`loop()`主循环里，反复调用`server.handleClient()`。

这个函数负责检测有没有浏览器客户端发来 HTTP 请求；
有请求到来就匹配注册好的路由，执行对应的回调函数。

**回调函数内部逻辑**：

组装要返回给浏览器的内容（文本、HTML 网页）；
使用`server.send(状态码,数据类型,内容)`把数据发回浏览器。

浏览器访问 ESP32 的 IP + 路径，就能看到返回的网页，触发对应的业务逻辑。
伪代码定义WebServer对象，端口80

```csharp
setup(){初始化串口WiFi.begin(ssid,密码)等待WiFi连接完成打印本机IP//注册路由
server.on("/", 首页回调);
server.on("/led", led控制回调);

server.begin() //开启web服务
}

loop(){
server.handleClient() //持续处理客户端请求
}

首页回调(){
server.send(200,"text/html","网页内容")
}

led控制回调(){
执行IO操作
server.send(200,"text/plain","执行完成")

}
```

# 二、千恒科技机考

1. 判断大小端序
# 大小端检测题整理

## 一、思路文字叙述（便于理解、面试口述）

### 背景概念

1. 对于`unsigned int val = 0x00000001`（4 字节）：

- 数字的**低字节**：`0x01`（数值权重最小）
- 数字的**高字节**：`0x00 0x00 0x00`（数值权重大）

1. 内存地址：内存编号小叫**低地址**；内存编号大叫**高地址**。
2. 大小端定义：

- **小端模式**：内存**低地址存放数字的低字节**；STM32、ESP32、x86 都是小端。
- **大端模式**：内存**低地址存放数字的高字节**；网络通信默认大端，和人阅读十六进制书写顺序一致。

### 检测原理

把 4 字节 int 变量的地址，强制转换成`char*`字符指针。

> `char*`指针指向变量的**起始内存（也就是最低地址）**，解引用`*p`只会读取低地址上的**1 个字节**。

- 如果`*p == 1`：低地址存放的是低字节`0x01` → **小端，返回 1**
- 如果`*p == 0`：低地址存放的是高字节`0x00`，`0x01`存放到高地址 → **大端，返回 0**

> 关键点：我们只看变量最开始的低地址这一个字节，就可以完成判断，不需要读取全部 4 字节。

### 面试口述话术（可以直接说）

> “我定义一个 unsigned int 赋值为 1，这个数有效低字节是 0x01。把它的地址强转为 char*，char 指针指向变量起始的低地址，解引用拿到低地址的单字节。读到 1 说明低地址存低字节，是小端；读到 0 说明低地址存高字节，是大端。”

## 二、完整带注释代码

```
/**
 * @brief 检测系统大小端
 * @retval 1：小端模式； 0：大端模式
 */
int check_endian(void)
{
    // 4字节无符号整数，值为1，二进制：0x00000001
    unsigned int val = 1;

    // 取val的起始地址，强转为char*
    // char*指向变量的内存最低地址，解引用只读取1个字节
    unsigned char *p = (unsigned char *)&val;

    if (*p == 1)
    {
        // 低地址存放低字节0x01 → 小端
        return 1;
    }
    else
    {
        // 低地址存放高字节0x00 → 大端
        return 0;
    }
}

// 简单测试，打开#if 0可以编译运行测试
#if 0
#include <stdio.h>
int main(void)
{
    int ret = check_endian();
    if(ret == 1)
    {
        printf("小端模式\n");
    }
    else
    {
        printf("大端模式\n");
    }
    return 0;
}
#endif
```

### 易错点提醒

1. 不能强转回`int*`解引用，那样一次性读取 4 字节，无法判断存储顺序。
2. `char *p = (unsigned char *)&val;`，p 保存的是变量**起始最低地址**；想要访问后面字节需要写`*(p+1)`、`*(p+2)`。
3. 本题默认 int 占 4 字节，嵌入式笔试环境都是这个前提。
