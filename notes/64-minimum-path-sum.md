# 力扣 64. 最小路径和 — 学习笔记

> **题目**：给定一个包含非负整数的 `m x n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。说明：每次只能向下或者向右移动一步。  
> **难度**：中等  
> **标签**：数组、动态规划、矩阵

---

## 一、题目理解

与力扣 62（不同路径）非常相似，区别是：
- **62 题**：求路径的**数量**（计数）
- **64 题**：求路径的**数字和最小**（最值）

```
输入: grid = [
  [1, 3, 1],
  [1, 5, 1],
  [4, 2, 1]
]
输出: 7
解释: 路径 1→3→1→1→1 的总和最小，为 7
```

---

## 二、核心思路推导

### 2.1 与 62 题的对比

| 维度 | 62. 不同路径 | 64. 最小路径和 |
|------|-------------|---------------|
| 目标 | 路径总数 | 路径和最小 |
| 状态转移 | `dp[i][j] = dp[i-1][j] + dp[i][j-1]` | `dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]` |
| 操作 | 加法（计数） | 取最小 + 当前格子的值 |
| 边界初始化 | 全为 1 | 累加 grid 的值 |

### 2.2 状态定义

```cpp
dp[i][j] = 从起点 (0,0) 到达 (i,j) 的最小路径和
```

### 2.3 状态转移方程

```
dp[i][j] = min( dp[i-1][j], dp[i][j-1] ) + grid[i][j]
              ↑从上方来      ↑从左方来        ↑加上当前格子的值
```

**解释**：
- 到达 `(i,j)` 只能从上方或左方来
- 选两条路径中**和较小**的那条
- 再加上当前格子 `grid[i][j]` 的值

### 2.4 边界条件（与 62 题不同！）

```cpp
// 第一列：只能从上往下走，一路累加
dp[i][0] = dp[i-1][0] + grid[i][0];

// 第一行：只能从左往右走，一路累加
dp[0][j] = dp[0][j-1] + grid[0][j];
```

> ⚠️ **注意**：不是初始化为 1，而是**累加 grid 的值**！因为要求的是"和"，不是"数量"。

## 三、代码实现（二维 DP）

```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size();        // 行数
        int n = grid[0].size();     // 列数

        // dp[i][j] = 到达 (i,j) 的最小路径和
        vector<vector<int>> dp(m, vector<int>(n));

        // 起点
        dp[0][0] = grid[0][0];

        // 初始化第一列：只能从上往下走
        for (int i = 1; i < m; i++) {
            dp[i][0] = dp[i - 1][0] + grid[i][0];
        }

        // 初始化第一行：只能从左往右走
        for (int j = 1; j < n; j++) {   // ❗ 注意是 j < n，不是 j < m
            dp[0][j] = dp[0][j - 1] + grid[0][j];
        }

        // 填表：从上到下，从左到右
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // 从上方和左方选较小的路径和，再加上当前格子的值
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
            }
        }

        return dp[m - 1][n - 1];
    }
};
```

## 四、踩过的坑

### ❌ 坑：第一行初始化循环条件写错

```cpp
// ❌ 错误写法
for (int j = 1; j < m; j++) {   // 把 n 写成了 m！
    dp[0][j] = dp[0][j-1] + grid[0][j];
}

// ✅ 正确写法
for (int j = 1; j < n; j++) {   // 第一行有 n 个元素
    dp[0][j] = dp[0][j-1] + grid[0][j];
}
```

**后果**：
- 如果 `m < n`：第一行只初始化了部分元素，后面还是默认值 0，结果错误
- 如果 `m > n`：`j` 超过 `grid[0]` 的边界，**数组越界，runtime error**

> 💡 **记忆口诀**：初始化第一行用 `n`（列数），初始化第一列用 `m`（行数），别写混！

## 六、空间优化：一维 DP（O(n)）

### 6.1 优化思路

和 62 题一样，`dp[i][j]` 只依赖上一行和当前行前一列。可以用一维数组滚动更新。

### 6.2 代码

```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size();
        int n = grid[0].size();

        // dp[j] 表示当前行第 j 列的最小路径和
        vector<int> dp(n);

        // 初始化第一行
        dp[0] = grid[0][0];
        for (int j = 1; j < n; j++) {
            dp[j] = dp[j - 1] + grid[0][j];
        }

        // 从第二行开始遍历
        for (int i = 1; i < m; i++) {
            // 第 0 列：只能从上方来
            dp[0] = dp[0] + grid[i][0];

            // 其他列：从上方(dp[j])或左方(dp[j-1])选较小值
            for (int j = 1; j < n; j++) {
                dp[j] = min(dp[j], dp[j - 1]) + grid[i][j];
            }
        }

        return dp[n - 1];
    }
};
```

### 6.3 关键点

- `dp[0] = dp[0] + grid[i][0]`：每行开始时，第 0 列的值需要先更新（只能从上方来）
- `dp[j]` 在更新前存的是**上一行**的值（相当于 `dp[i-1][j]`）
- `dp[j-1]` 已经被更新为**当前行**的值（相当于 `dp[i][j-1]`）

## 七、复杂度分析

| 指标 | 二维 DP | 一维 DP |
|------|---------|---------|
| **时间复杂度** | O(m × n) | O(m × n) |
| **空间复杂度** | O(m × n) | **O(n)** |

## 八、与力扣 62 的详细对比

| 对比项 | 62. 不同路径 | 64. 最小路径和 |
|--------|-------------|---------------|
| **问题类型** | 计数 DP | 最值 DP |
| **状态定义** | `dp[i][j]` = 路径数量 | `dp[i][j]` = 最小路径和 |
| **转移方程** | `dp[i-1][j] + dp[i][j-1]` | `min(dp[i-1][j], dp[i][j-1]) + grid[i][j]` |
| **第一行初始化** | 全为 1 | 累加 `grid[0][j]` |
| **第一列初始化** | 全为 1 | 累加 `grid[i][0]` |
| **返回值** | `dp[m-1][n-1]` | `dp[m-1][n-1]` |
| **核心区别** | 求"有多少种" | 求"哪个最小" |

> 💡 **本质相同**：都是网格 DP，都是只能向下/向右，区别只是"加"变成了"取最小后再加"。

## 九、常见错误

### ❌ 错误 1：边界初始化成 1
```cpp
// ❌ 错误：把 62 题的习惯带过来
dp[i][0] = 1;
dp[0][j] = 1;

// ✅ 正确：累加 grid 的值
dp[i][0] = dp[i-1][0] + grid[i][0];
dp[0][j] = dp[0][j-1] + grid[0][j];
```

### ❌ 错误 2：行列维度写混
```cpp
// ❌ 错误：第一行循环用 m
for (int j = 1; j < m; j++)   // 应该是 n！

// ✅ 正确
for (int j = 1; j < n; j++)
```

### ❌ 错误 3：忘记加 grid[i][j]
```cpp
// ❌ 错误：只取最小，没加当前格子的值
dp[i][j] = min(dp[i-1][j], dp[i][j-1]);

// ✅ 正确：最小值 + 当前格子的值
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j];
```

### ❌ 错误 4：一维 DP 没先更新第 0 列
```cpp
// ❌ 错误：直接进内层循环
for (int j = 1; j < n; j++)
    dp[j] = min(dp[j], dp[j-1]) + grid[i][j];
// 问题：dp[0] 还是上一行的值，没有加上 grid[i][0]

// ✅ 正确：先更新第 0 列
dp[0] = dp[0] + grid[i][0];   // 只能从上方来
for (int j = 1; j < n; j++)
    dp[j] = min(dp[j], dp[j-1]) + grid[i][j];
```

## 十、思路总结

```
┌─────────────────────────────────────────────────────────────┐
│                     动态规划四步法                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 定义状态                                                │
│     dp[i][j] = 从起点到达 (i,j) 的最小路径和                │
│                                                             │
│  2. 找状态转移                                              │
│     到达 (i,j) 只能从上方或左方来，选较小的那条             │
│     dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]   │
│                                                             │
│  3. 确定边界                                                │
│     第一行：一路向右累加 grid[0][j]                        │
│     第一列：一路向下累加 grid[i][0]                        │
│                                                             │
│  4. 遍历顺序                                                │
│     从上到下，从左到右（每个位置依赖上方和左方）          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 十一、一句话总结

> **每个格子的最小路径和 = 上方和左方中较小的那个路径和 + 当前格子的值。第一行和第一列只能一路累加。**

```cpp
// 核心代码
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j];
```

这是**网格类 DP 求最值**的模板题，掌握后可以做 120（三角形最小路径和）、931（下降路径最小和）等变形题。
