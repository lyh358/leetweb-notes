## 📌 一、题目：LeetCode 79. 单词搜索

**题目链接**：[79. 单词搜索](https://leetcode.cn/problems/word-search/)

**题目描述**：给定一个 `m x n` 的二维字符网格 `board` 和一个字符串单词 `word`。如果 `word` 存在于网格中，返回 `true`；否则，返回 `false`。

单词必须按照字母顺序，通过**相邻**的单元格内的字母构成，其中「相邻」单元格是那些**水平相邻或垂直相邻**的单元格。**同一个单元格内的字母不允许被重复使用**。

**示例 1**：

```
输入: board = [["A","B","C","E"],
               ["S","F","C","S"],
               ["A","D","E","E"]], 
      word = "ABCCED"
输出: true
```

**示例 2**：

```
输入: board = [["A","B","C","E"],
               ["S","F","C","S"],
               ["A","D","E","E"]], 
      word = "SEE"
输出: true
```

**示例 3**：

```
输入: board = [["A","B","C","E"],
               ["S","F","C","S"],
               ["A","D","E","E"]], 
      word = "ABCB"
输出: false
解释: 字母不允许被重复使用，"ABCB" 中第二个 B 无法再次使用
```

**约束**：
- `m == board.length`
- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成

## 🧠 二、核心思路：网格上的 DFS 回溯

这道题和之前的回溯题有一个重要区别：

> **搜索空间是二维的，每一步有 4 个方向可选（上、下、左、右）。**

### 解题步骤

1. **找起点**：遍历网格中的每个单元格，如果当前格子的字母等于 `word[0]`，就作为起点开始 DFS
2. **DFS 搜索**：从当前格子出发，向四个方向探索，看能否匹配 `word` 的下一个字符
3. **标记访问**：走过的格子标记为已访问，防止同一条路径中重复使用
4. **回溯恢复**：如果当前方向走不通，撤销标记，尝试其他方向
5. **找到即返回**：一旦找到完整单词，立即返回 `true`，不需要继续搜索

### 为什么需要标记 + 回溯？

想象你在迷宫中找路：
- **标记**：走过的地方画个记号，防止原地打转
- **回溯**：走到死胡同后，擦掉记号往回退，让其他路径还能走这里

> 注意：标记只在**当前路径**中有效，换一条路径时之前的标记要全部清除。

## 💻 三、完整代码（原地标记版，推荐）

```cpp
class Solution {
public:
    // 定义方向数组：右、左、下、上
    int dx[4] = {0, 0, 1, -1};
    int dy[4] = {1, -1, 0, 0};

    // 主函数：执行 DFS 回溯
    bool exist(vector<vector<char>>& board, string word) {
        // 遍历每个单元格：寻找可以作为 DFS 的起点
        for (int i = 0; i < board.size(); i++) {
            for (int j = 0; j < board[0].size(); j++) {
                // 只有首字母匹配才启动 DFS
                if (board[i][j] == word[0]) {
                    // 当 DFS 返回 true，主函数也返回 true，表示找到了
                    if (dfs(board, word, i, j, 0)) {
                        return true;
                    }
                }
            }
        }
        // 循环结束还没找到合适的路径：则找不到
        return false;
    }

    // DFS 回溯函数
    // (x, y): 当前在网格中的位置
    // idx: 当前要匹配 word 的第几个字符
    bool dfs(vector<vector<char>>& board, string word, int x, int y, int idx) {
        // ========== 终止条件：所有字符都成功匹配 ==========
        if (idx == word.size()) {
            return true;
        }

        // ========== 剪枝条件：当前位置不合法 ==========
        // 越界、已访问（被标记为 '#'）、字符不匹配，都直接返回 false
        if (x < 0 || x >= board.size() || 
            y < 0 || y >= board[0].size() || 
            board[x][y] == '#' || 
            word[idx] != board[x][y]) {
            return false;
        }

        // ========== 做选择：标记当前格子为已访问 ==========
        char temp = board[x][y];   // 暂存当前 board 字符，用于回溯
        board[x][y] = '#';         // 标记当前位置为已访问

        // ========== 向四个方向探索并 DFS ==========
        for (int i = 0; i < 4; i++) {
            int nx = x + dx[i];    // 下一个位置的行
            int ny = y + dy[i];    // 下一个位置的列

            // 一直传递 idx+1 四向找匹配位置
            // 如果在某个方向找到了，直接返回 true
            if (dfs(board, word, nx, ny, idx + 1)) {
                return true;
            }
        }

        // 如果四个方向都找不到，退出循环了
        // ========== 撤销选择：恢复当前格子的原字符 ==========
        board[x][y] = temp;        // 回溯，恢复原状
        return false;              // 四个方向都走不通
    }
};
```

## 🔍 五、代码关键细节解析

### 5.1 方向数组

```cpp
int dx[4] = {-1, 0, 1, 0};  // 行变化：上、右、下、左
int dy[4] = {0, 1, 0, -1};  // 列变化：上、右、下、左
```

用两个一维数组表示四个方向的偏移量，配合 `for` 循环遍历：

```cpp
for (int i = 0; i < 4; i++) {
    int nx = x + dx[i];
    int ny = y + dy[i];
    // ...
}
```

> 💡 这样写比写四个 `if` 判断更简洁，且容易扩展（比如八方向）。

### 5.2 为什么用 `'#'` 标记已访问？

```cpp
char temp = board[x][y];   // 先保存原字符
board[x][y] = '#';         // 标记为已访问
// ... 递归搜索 ...
board[x][y] = temp;        // 回溯时恢复原字符
```

**优点**：
- **空间 O(1)**：不需要额外的 `visited` 数组，直接在原数组上标记
- **判断简单**：`board[x][y] == '#'` 就能知道是否已访问

**注意**：题目保证 `board` 中只有字母，`'#'` 不会冲突。

### 5.3 剪枝条件的顺序

```cpp
if (x < 0 || x >= board.size() || 
    y < 0 || y >= board[0].size() || 
    board[x][y] == '#' || 
    board[x][y] != word[idx]) {
    return false;
}
```

四个判断的顺序：
1. **越界判断**：防止数组访问越界（必须最先判断！）
2. **已访问判断**：`board[x][y] == '#'` 说明当前路径已经走过
3. **字符匹配**：当前格子的字母不等于目标字符

> ⚠️ **越界判断必须放在最前面**，否则访问 `board[x][y]` 可能导致数组越界崩溃。

### 5.4 为什么找到就立即返回？

```cpp
if (dfs(board, word, nx, ny, idx + 1)) {
    return true;  // ← 某个方向找到了，直接返回，不再尝试其他方向
}
```

题目只要求判断是否存在，不需要找出所有路径。所以一旦某个方向找到了完整单词，就可以一路返回 `true`，不需要继续搜索。

## ⚔️ 六、两种标记方式对比

### 方式一：原地修改 board（你的代码，推荐）

```cpp
char temp = board[x][y];
board[x][y] = '#';
// ... 递归 ...
board[x][y] = temp;
```

| 优点 | 缺点 |
|-----|------|
| 空间 O(1)，无需额外数组 | 修改了原数组（虽然最后会恢复） |
| 代码简洁 | 如果多线程会有问题（本题不考虑） |

### 方式二：使用 visited 数组

```cpp
vector<vector<bool>> visited(m, vector<bool>(n, false));

// 标记
visited[x][y] = true;
// ... 递归 ...
visited[x][y] = false;
```

| 优点 | 缺点 |
|-----|------|
| 不修改原数组 | 需要 O(m×n) 额外空间 |
| 逻辑更清晰 | 代码稍长 |

> 💡 **面试推荐写法**：原地修改版，代码更简洁，空间更优。

## ⚠️ 七、常见易错点

| 坑点 | 错误写法 | 正确写法 | 后果 |
|-----|---------|---------|------|
| **越界判断放后面** | 先判断 `board[x][y]` | 先判断 `x,y` 越界 | 数组越界，程序崩溃 |
| **忘记回溯恢复** | 只 `board[x][y]='#'` | 必须 `board[x][y]=temp` | 网格被永久破坏，后续起点搜索错误 |
| **idx 传错** | `dfs(..., idx)` | `dfs(..., idx + 1)` | 无限递归，死循环 |
| **方向写错** | `dx={-1,1,0,0}, dy={0,0,-1,1}` | 确保四个方向覆盖上下左右 | 只能走两个方向，漏解 |
| **找到不立即返回** | 继续遍历所有方向 | `if (dfs(...)) return true;` | 效率低，虽然结果正确但浪费时间 |
| **起点判断遗漏** | 直接从 (0,0) 开始 DFS | 先判断 `board[i][j] == word[0]` | 做了很多无用功 |

---

## 📊 八、复杂度分析

- **时间复杂度**：`O(m × n × 3^L)`
  - `m × n`：遍历每个起点
  - `3^L`：从每个起点开始，最多有 3 个方向可选（不能回头），`L` 是单词长度
  - 最坏情况下需要枚举大量路径

- **空间复杂度**：`O(L)`
  - 递归栈深度最多为单词长度 `L`
  - 原地标记不需要额外空间

## 💡 十、学习建议

1. **先理解二维 DFS 与一维的区别**
   - 一维回溯：每次选一个元素（for 循环遍历数组）
   - 二维回溯：每次选一个方向（四个方向探索）
   - 核心思想相同：选 → 探 → 撤

2. **记住方向数组模板**
   ```cpp
   int dx[4] = {-1, 0, 1, 0};
   int dy[4] = {0, 1, 0, -1};
   ```
   这是网格 DFS 的标配，背下来。

3. **越界判断是生命线**
   - 任何访问 `board[x][y]` 之前，必须先确认 `x, y` 在合法范围内
   - 这是网格题最容易 crash 的地方

4. **标记与回溯必须成对**
   - 标记：`board[x][y] = '#'`
   - 回溯：`board[x][y] = temp`
   - 可以类比为「进门脱鞋，出门穿鞋」

---

## 🎯 一句话总结

> **单词搜索 = 二维网格上的 DFS 回溯**
>
> 遍历每个格子作为起点 → 向四个方向探索 → 匹配 word 的下一个字符 → 走过的格子标记 `'#'` 防止重复 → 走不通就恢复原字符回溯 → 找到完整单词立即返回 true。

## 📎 附录：网格 DFS 通用模板

```cpp
// 方向数组
int dx[4] = {-1, 0, 1, 0};
int dy[4] = {0, 1, 0, -1};

bool dfs(vector<vector<char>>& board, int x, int y, ...) {
    // 1. 越界判断（必须最先！）
    if (x < 0 || x >= board.size() || y < 0 || y >= board[0].size())
        return false;

    // 2. 其他剪枝（已访问、不匹配等）
    if (board[x][y] == '#' || ...) 
        return false;

    // 3. 终止条件
    if (满足成功条件) return true;

    // 4. 标记已访问
    char temp = board[x][y];
    board[x][y] = '#';

    // 5. 向四个方向递归
    for (int i = 0; i < 4; i++) {
        int nx = x + dx[i];
        int ny = y + dy[i];
        if (dfs(board, nx, ny, ...)) return true;
    }

    // 6. 回溯恢复
    board[x][y] = temp;
    return false;
}
```
